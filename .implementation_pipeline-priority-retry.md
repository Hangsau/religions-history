# Implementation checklist — pipeline priority, retry, and state reconciliation

> Confirmed through plan-check on 2026-07-20. Publishing UI is explicitly out
> of scope; this checklist covers pipeline correctness and release-oriented
> translation ordering.

## Controlled work window

- [x] W1 `[manual]` Set the local HALT flag so the supervisor cannot start a
  new run; inspect PID, lock, runtime, checkpoint, and active commands.
- [x] W2 `[manual]` Do not migrate shared state while an old worker can still
  write it; wait for a checkpoint-safe boundary or stop at the rollout gate.
- [x] W3 `[manual]` Inventory the dirty worktree into infrastructure, board,
  completed data, incomplete data, and runtime-only groups.

## Failure state and scheduling

- [x] W4 `[manual]` Introduce failed-state schema v2 with atomic persistence,
  v1 migration, retryable/blocked status, attempts, task, error, and retry time.
- [x] W5 `[manual]` Keep quota waiting separate from ordinary failure attempts.
- [x] W6 `[manual]` Apply ordinary-failure backoff of 5/15/30 minutes and block
  after the third failure; provide a validated `--unblock` operation.
- [x] W7 `[manual]` Sort due retries and unfinished work by P0/P1/P2 while
  retaining original/size/slug as deterministic secondary keys.
- [x] W8 `[manual]` Ensure future retries and blocked-only queues do not create
  supervisor busy loops or false completion reports.

## Canonical priority and reconciliation

- [x] W9 `[manual]` Add `00-overview/translation-priority.json` as the single
  canonical priority source, with explicit reasons and stable slugs.
- [x] W10 `[manual]` Audit P0 entries for missing slugs, aliases, duplicates,
  thin sources, and per-religion representation before enabling the order.
- [x] W11 `[manual]` Add an idempotent, dry-run-first reconciliation command.
- [x] W12 `[manual]` Downgrade incomplete `translation_status=done` to
  `needs-review`, reset tag statuses without deleting translations or tag data,
  and never auto-promote an unverified translation.

## Consumers, documentation, and validation

- [x] W13 `[manual]` Synchronize CLI, desktop board, generated status, audit,
  and verifier consumers with P0/retryable/blocked definitions.
- [x] W14 `[manual]` Ignore local runtime state files that must not be committed.
- [x] W15 `[manual]` Update README and HANDOFF with actual counts and policy.
- [x] W16 `[manual]` Test empty/large/partial inputs, malformed and legacy state,
  path rejection, simultaneous writers, lock ownership, backoff, blocking,
  quota separation, P0 ordering, and reconciliation idempotence.
- [x] W17 `[manual]` Run full unit tests, verifier, generated-index/audit checks,
  compilation, and `git diff --check`.

## Rollout and commits

- [x] W18 `[manual]` Commit only explicit verified path groups; inspect staged
  paths before every commit and never use `git add -A`.
- [ ] W19 `[manual]` Push each verified commit; if push fails, keep local commits
  and stop further pushes.
- [ ] W20 `[manual]` Remove HALT, restart the supervisor, and observe one due P0
  or retry item while confirming a single pipeline lock owner.

## Explicit exclusions

- Website and publishing presentation.
- DeepSeek or any non-M3 fallback.
- Repairing translations by hand or deleting incomplete text.
- Reclassifying religions, broad taxonomy work, and project `MAP.md` creation.
