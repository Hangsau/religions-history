=== 7.1 | 第七卷・第一瑜篇 ===

7,1.1 由於產生與目的不可分別，故應如同實有，而為同一法。

7,1.2 或由於動令之附屬存在，因其差別而應分立，因為產生是附屬性故。

7,1.3 若實有存在，由於特相之結合，應被認知為遍一切處。

7,1.4 但由於不可分別，則不應如是。

7,1.5 而且雙重意義是矛盾的。

7,1.6 在產生中若無儀軌，則應在動令中生起運作，因此應有業之差別。

7,1.7 或者，若如同名詞，由於共通性，應為一切法。

7,1.8 但由於事物之不可分別性，在名詞中應如是，因為應用如同先前；業由言聲所成；由於分別，餘者不應生起。

7,1.9 若言：因為記憶？

7,1.10 不，因為如同先前。

7,1.11 由於事物為言聲所成，且以篇章為依託，在其他處應唯從言聲而有其存在。

7,1.12 在共通者中，由於如同先前，已產生的資格應成立。

7,1.13 若言：「因為鷹祀…」

7,1.14 不，由於不在近處。

7,1.15 或者，若由於前所未有，他者應在正義中；從 Jyotiṣṭoma（火祭）式的儀軌，其能詮者應相同。

7,1.16 在五種移動中，意義說明之轉用由於在近處。

7,1.17 由於一切為一言聲。

7,1.18 而且由於標相之可見。

7,1.19 若言：「由於儀軌的傳誦，不應如是？」

7,1.20 不，因為他者意義之故。

7,1.21 而且在 Indrāgna（因陀羅與阿耆尼）的一鉢供中，亦應如是。

7,1.22 一鉢供屬於 Viśvadeva（一切天神）的原形；在先熟祭中，由於未看到所有供養的轉變，而且沐浴祭中雙刀割的單次使用由於經文所說。

7,1.23 對於 Sāman（歌詠），藉由「名稱」一詞，應依所指示而運作。

=== 7.2 | 第七卷・第二瑜篇 ===

7,2.1 然而由於言詞是意義之教令，在不屬於其他意義時不應生起；因為行動的關聯是分離的。

7,2.2 或者，在自己意義中應有目的，行動的支分應被教示。

7,2.3 若言：「唯有言聲？」

7,2.4 不，因為是天生（聲音與意義的關係是固有的）。

7,2.5 而且經典如此則會無意義。

7,2.6 若言：「由於自性（固有語氣）？」

7,2.7 不，由於意義之缺乏，聲聞沒有關聯。

7,2.8 但自性存在於產生中，因為音節與字母不可分別。

7,2.9 而且由於標相之可見。

7,2.10 對於未聽聞的變形，在後續中應依所聽聞。

7,2.11 而且言詞有不契合之處。

7,2.12 然而，業言詞應指存在之意義，因為取用共許；變形與其他並無差別。

7,2.13 而且非實物亦可見。

7,2.14 其行動應為取用之目的，由於在多種意義中呈現不同；這些（言詞的）意義是非世俗的，因為來自儀軌。

7,2.15 在其中，應有特別之名稱，因為變形之差別。

7,2.16 而且（來自）正源者如同相等，由其他（言詞）所規定。

7,2.17 在非正源中亦可見，其源並非如此。

7,2.18 若言：「在單一意義中沒有異相？」

7,2.19 應存在於其他意義中，因為未成就，如同烹煮。

7,2.20 而且言詞的契合成立。

7,2.21 已說行動之表達；在聽聞（之聲）中，他處應為儀軌之指示。

=== 7.3 | 第七卷・第三瑜篇 ===

7,3.1 或者在前所未有中，因為是部分所攝。

7,3.2 但名稱是天生（固定）的。

7,3.3 由於現量與屬性之結合，應為行動之表達；若其不存在，則不應成為共許。

7,3.4 或者，在行祭中，此聲聞應為屬性之目的。

7,3.5 在 Viśvajit（一切勝利祭）一切背祭中，由於以它為先，屬於 Jyotiṣṭoma（火祭）的背祭，而且「背」一詞存在。

7,3.6 或者由於六日，因為那裡有動令。

7,3.7 而且由於標相。

11.1.1　因與目的相連、由善人[之傳統]、由一語（ekaśabda）相會，故當各別成就業一（aikakarmya）。

11.1.2　或如餘（śeṣa）法之例，目的當對每人、每儀軌分別[適用]。

11.1.3　然而因非被指定，故不應如此。

11.1.4　蓋餘法為他法而存、因被指定，故主（pradhāna）法之性當可成立。

11.1.5　然而因支（aṅga）有語言之差別，故如祭（kratu）之例，當不引生果（phala）。

11.1.6　然意義有別，於此中因一義、業一故[為一體]。

11.1.7　若因語言差別而[認為]非[一體]——

11.1.8　因業以意義為目的，故於應用中，由彼目的故，當以彼名而立。

11.1.9　因造作者之規定有多義，故於以德為主之事中。

11.1.10　因發起（ārambha）有語言先行故。

11.1.11　雖以一事亦當完成，因目的已成，如他祭已得時之例，當如後續（uttara）之例。

11.1.12　若因無果而[認為]非[如此]——

11.1.13　不因業之相連，當無目的缺失之過。

11.1.14　若以一語為難——

11.1.15　因意義不異、因同等、因非德故。

【4.10】pavamānahaviḥṣu（pavamāna 祭酥）中 ekatantratva（規則同一）：因 prayoga（應用）之 vacana（誦說）為 ekattva（同一）。

=== 2 | 第十二章第二篇 ===

/Jaim_12,2.15/ 由於時間和說明的分別，應有 tantra（綜合儀式）的分別。

/Jaim_12,2.16/ 由於矛盾，vedi（祭壇）、財物、vrata（誓戒）應為同一。

/Jaim_12,2.17/ 或由於在 tantra 之中被規定，它們屬於該 tantra，如 savanīya（蘇摩祭支）。

/Jaim_12,2.18/ 由於缺陷，idhma（燃料）和 barhis（聖草）不得成就；若 agnyanvādhāna（點火儀式）是為 devatā（神祇）之故。

/Jaim_12,2.19/ agnyanvādhāna 若為 devatā 之故。

/Jaim_12,2.20/ ārambhaṇīya（起始儀式）在 vikṛti（變體）中不應存在，因處於 prakṛti（原型）的時間之中；若已作，則為其目的而重作。

/Jaim_12,2.21/ 因一次 ārambha（起始）的連結。

/Jaim_12,2.22/ 或應存在，因時間的完整性。

/Jaim_12,2.23/ 也因 ārambha 的區分。

/Jaim_12,2.24/ 互相矛盾的性質共存時，多數者應具有相同性質。

/Jaim_12,2.25/ 或主要的，因先前 codanā（教令），如世間。

/Jaim_12,2.26/ 同樣，也見到為他目的者。

/Jaim_12,2.27/ aṅga（支分）與 guṇa（屬性）矛盾時，因目的性。

/Jaim_12,2.28/ 因 paridhi（圍欄）具有雙重意義，應具有雙重性質。

/Jaim_12,2.29/ 但主要者若有矛盾，應從主要者的連續性。

/Jaim_12,2.30/ 或另一者，因它在該處的規定；且兩者與 aṅga 的連結。

/Jaim_12,2.31/ paśu（犧牲）和 savanīya 中應有 vikalpa（選項）；若為變體，因兩者皆非 śruti（所聞）。

/Jaim_12,2.32/ 或 paśu 相關者，因對它的特定傳誦；在 vikalpa 中它將無意義。

/Jaim_12,2.33/ paśu 也有分離，因在 tantra 中被規定。

/Jaim_12,2.34/ apūrva（新穎者）在 prakṛti 中也應無意義，若屬同一 tantra，因非永恆性。

/Jaim_12,2.35/ 額外的 guṇa 在共通者中，因無矛盾，如銅器食者，即使在非主要者中亦同。

/Jaim_12,2.36/ 但透過其運作，tantra 應有確定，如 paśu 透過 sūktapāka（善頌之烹煮）。

/Jaim_12,2.37/ 或不，因無矛盾。

/Jaim_12,2.38/ 也因不具 śāstra（經文）特徵。

=== 3 | 第十二章第三篇 ===

/Jaim_12,3.1/ 在 viśvajit（全勝祭）中，vatsatvac（犢皮）因名稱之故；否則因 tantra 的多數性，應為未破。

/Jaim_12,3.2/ 或無矛盾，因 uparivāsa（上衣）即是犢皮。

/Jaim_12,3.3/ 在 anunirvāpya（追加澆祭）中，因多數性，tantra 的確定應成立；也因 sviṣṭakṛt（善成祭）的見解。

/Jaim_12,3.4/ 或因其偶然性，應有自身性質，因特殊的 śruti；另一者因主要性。

/Jaim_12,3.5/ 也因其所處位置。

/Jaim_12,3.6/ 若說 sviṣṭakṛt 中的 kraya（購買）不應存在，則為 vikāra（變體），如 pavamāna（淨化頌）。

/Jaim_12,3.7/ 或非變體，如 prakṛti；也因相對於 codanā 的性質。

/Jaim_12,3.8/ 因 guṇa 在一儀式中被教示，應適用於所有儀式。

/Jaim_12,3.9/ 但同一目的者應有 vikalpa；在 samuccaya（合併）中，pradhāna（主要者）應有重複。

/Jaim_12,3.10/ 若說應重複，因有用性。

/Jaim_12,3.11/ 不，因非 śruti；如 vikalpa，它顯示在另一時間有用性應成立。

/Jaim_12,3.12/ 在 prāyaścitta（贖罪儀式）中，因目的之一致，完成後連結，因此一切皆消除。

/Jaim_12,3.13/ 但 samuccaya 是為 doṣa（過失）之目的。

/Jaim_12,3.14/ mantra（咒語）與儀式的連結：應依自身性質運用，因 dharma（法）以此為因。

/Jaim_12,3.15/ 或因 vidyā（知識）的規定，一切因的 prayoga（運用）應成立，因 prayoga 以 karma（儀式）為目的。

/Jaim_12,3.16/ 因 bhāṣā（方言）、svara（重音）、upadeśa（教導）等[歧義：airavat 含義待考]，過多話語的禁止。

/Jaim_12,3.17/ 咒語的 upadeśa（教導）而非 bhāṣika（方言）的，因多數的成立；bhāṣika 為 śruti。

/Jaim_12,3.18/ vikāra：在不掌握原因時，因屬於該規則；即使在 dṛṣṭa（所見）中也如此。

/Jaim_12,3.19/ 或因其起源，因以 pravacana（傳承）為特徵。

/Jaim_12,3.20/ 因 mantra 以 karaṇa（工具）為目的，透過另一 mantra，儀式等結合應成立；因一切皆以 vacana（言詞）為目的。

/Jaim_12,3.21/ 因持續的誦念，在 dhārā（流水）中的起始連結。

/Jaim_12,3.22/ 或 karmasaṃtāna（儀式的持續），因不同 karma 的性質；另一者因無能力。

yājya（祭詞）與 vaṣaṭkāra（vaṣaṭ 唱句），聖教亦見 samuccaya，理亦如此。 / Jaim_12,3.27 /
或為 vikalpa，由於 samuccaya 未經聞故。 / Jaim_12,3.28 /
由於教授乃為 guṇa（功德）之義故。 / Jaim_12,3.29 /
於 vaṣaṭkāra，由於多義故為 samuccaya；然 hotṛ（祭官）由義同故行 vikalpa。 / Jaim_12,3.30 /

經教亦明示 samuccaya。 / Jaim_12,3.32 /

經教亦明示 samuccaya。 / Jaim_12,4.2 /
至於 yājya 與 anuvākyā（引述句），可有 vikalpa，由於義乃為標示 devatā（天祀）故。 / Jaim_12,4.3 /

於 kraya（購求）之事，誠可有 vikalpa，由於義同故。 / Jaim_12,4.5 /
或為 samuccaya，由於所用之物（prayogadravya）相連屬故。 / Jaim_12,4.6 /
經教亦明示 samuccaya。 / Jaim_12,4.7 /
於 saṃskāra（儀軌）中亦然，由於此事為主故。 / Jaim_12,4.8 /
至於以數量明定之祭，可有 vikalpa，由 śruti（聖教）所遮止故。 / Jaim_12,4.9 /
由 dravya（物資）之變易故，亦如前，arthakarma（義業）當立；由此 vikalpa，由 niyama（定則）為主故。 / Jaim_12,4.10 /

不然，由於 karma 為 parārtha（為他）故。 / Jaim_12,4.13 /
然而 pratipatti（執行）則（屬祭官），由其為 śeṣa（附屬）故。 / Jaim_12,4.14 /
於 śṛti（煮祭）中亦應如前。 / Jaim_12,4.15 /
為 vikalpyā（可隨取者），由非主業之 niyama 為主故；於 śeṣa 處，由業果之相連，tatsamāt（與彼等齊），由是故為 arthakarma。 / Jaim_12,4.16 /
於 ukhā（炊釜）中，kāmya（願祭）與 nitya（恆常祭）之 samuccaya，由於經教顯示願欲故。 / Jaim_12,4.17 /
若（saṃskāra）未成，於未經 saṃskṛta（完成）者亦可行 karma。 / Jaim_12,4.17* /
由於此事乃為 devatā 之義故。 / Jaim_12,4.18 /
或為 nitya 之火之變易，以 kāmya 之故，所說之因亦爾。 / Jaim_12,4.19 /
由於聖教之語，於未經 saṃskṛta 者，karma 可行。 / Jaim_12,4.20 /
若合會（saṃsarga），亦將有過。 / Jaim_12,4.21 /
若謂「由於聖教之語」，則於另一例，karma 之 utsarga（總說）不取（aparigraha），由其已作故。 / Jaim_12,4.22 /
此應為 āhavanīya（主祭火），由於 āhuti（酥供）之相合故。 / Jaim_12,4.23 /
另一者由於掘起而持來；於其中，saṃskāra-karma（儀軌業），由其為 śiṣṭa（所餘教示）故。 / Jaim_12,4.24 /
由於 sthāna（位置）故，應 parilupta（省略）。 / Jaim_12,4.25 /
於 nitya 之 ādhāraṇa（安置）處，vikalpa 也；遮止不應無因而立。 / Jaim_12,4.26 /
或由於 nitya 之 dhāraṇa（執持），遮止為 gataśri（無所據）。 / Jaim_12,4.27 /
為 parārtha 故，一人即可，如所引者；satra（連祭）闕者，於 yajamāna（祭主）之集，不定，由無別（aviśeṣa）故。 / Jaim_12,4.28 /
或 mukhya（主者）也，由 avidhipratiṣedha（非遮）故。 / Jaim_12,4.29 /
於 satra，gṛhapati（家主）也，由 asaṃyoga（不相連），如 hotṛ；又由 āmnāya（傳承）之語故。 / Jaim_12,4.30 /
或由一切（皆可），由於此乃為彼之義故。 / Jaim_12,4.31 /
於 vipratiṣedha（互遮）處，取後者。 / Jaim_12,4.32 /
於 hotṛ 之職，由 parārtha 故。 / Jaim_12,4.33 /
聖教之語為最上。 / Jaim_12,4.34 /
由 prabhutva（主位）故，一切 varṇa（種姓）之 ārtvijya（祭官職）當成立。 / Jaim_12,4.35 /
或由 smṛti（憶傳）故，於 brāhmaṇa（婆羅門）當成立。 / Jaim_12,4.36 /
由於 phalacamasa（果杯）之明定，其餘者亦爾。 / Jaim_12,4.37 /
於 sānnāyya（Sānnāyya 祭）亦如是遮止，由 saumapīya（飲蘇摩）之因故。 / Jaim_12,4.38 /
於 caturdhākaraṇa（四方祭）亦，由明示故。 / Jaim_12,4.39 /
於 anvāhārya（置後供物）亦，由於經教所見故。 / Jaim_12,4.40 /
