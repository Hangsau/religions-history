=== 1 | sa_vasubandhu-abhidharmakoza ===

oṃ namaḥ buddhāya — 唵，歸命（namaḥ）佛陀（Buddha）。

Abhidharmakośabhāṣyam prathamaṃ kośasthānam
om namo buddhāya

yaḥ sarvathāsarvahatāndhakāraḥ saṃsārapaṅkājjagadujjahāra /
tasmai namaskṛtya yathārthaśāstre śāstraṃ pravakṣyāmyabhidharmakośam // VAkK_1.1 //

彼於一切破壞一切黑暗、從輪迴（saṃsāra）淤泥中拔出世間者，
為彼作禮，我於如實之論（yathārtha-śāstre）中，將說阿毗達磨俱舍（abhidharmakośa）。

prajñāmalā sānucarābhidharmaḥ tatprāptaye yāpi ca yacca śāstram /
tasyārthato 'smin samanupraveśāt sa cā śrayo 'syetyabhidharmakośam // VAkK_1.2 //

清淨智慧（prajñā）及隨行阿毗達磨（abhidharma），為證得彼、亦為彼之論者，
由此隨入其義（artha）於此中，彼亦為此之所依，是故名阿毗達磨俱舍。

dharmāṇāṃ pravicayamantareṇa nāsti kleśānāṃ yata upaśāntaye 'bhyupāyaḥ /
kleśaiśca bhramati bhavārṇave 'tra lokastaddhetorata uditaḥ kilaiṣa śāstrā // VAkK_1.3 //

若無法（dharma）之遍知（pravicaya）則無方便，能寂滅煩惱（kleśa）不可得；
煩惱使有情（loka）於此有海（bhavārṇava）中飄轉；
是故為彼故，此論（śāstra）確從此出。

sāsravānāsravā dharmāḥ saṃskṛtā mārgavarjitāḥ /
sāsravāḥ āsravāsteṣu yasmātsamanuśerate // VAkK_1.4 //

有漏（sāsrava）無漏（anāsrava）諸法，為有為（saṃskṛta）離於道（mārga）；
漏（āsrava）隨行於有漏法，是故彼等名有漏。

anāsravā mārgasatyaṃ trividhaṃ cāpyasaṃskṛtam /
ākāśaṃ dvau nirodhau ca tatrākāśamanāvṛtiḥ // VAkK_1.5 //

無漏即道聖諦（mārga-satya），三種無為（asaṃskṛta）亦爾；
虛空（ākāśa）與二種滅（nirodha）亦然，於中虛空非為礙。

pratisaṃkhyānirodho yo visaṃyogaḥ pṛthak pṛthak /
utpādātyantavighno 'nyo nirodho 'pratisaṃkhyayā // VAkK_1.6 //

擇滅（pratisaṃkhyā-nirodha）者，即是種種離繫（visaṃyoga）；
究竟礙生之餘者，即是非擇（apratisaṃkhyayā）之滅。

te punaḥ saṃskṛtā dharmā rūpādiskandhapañcakam /
sa evādhvā kathāvastu saniḥsārāḥ savastukāḥ // VAkK_1.7 //

彼復有為諸法，即色等五蘊（rūpa-ādi-skandha）；
彼即是三世（adhvā），說有出離（niḥsāra）有事故。

ye sāsravā upādānaskandhāste saraṇā api /
duḥkhaṃ samudayo loko dṛṣṭisthānaṃ bhavaśca te // VAkK_1.8 //

有漏取蘊（upādāna-skandha）彼等，雖有依止；
彼即是苦（duḥkha）、集（samudaya）、世間、見處（dṛṣṭi-sthāna）與有（bhava）。

rūpaṃ pañcendriyāṇyarthāḥ pañcāvijñaptireva ca /
tadvijñānāśrayā rūpaprasādāścakṣurādayaḥ // VAkK_1.9 //

色（rūpa）、五根（indriya）、五境（artha）、五無表色（avijñapti），是即色；
眼等（cakṣuḥ-ādayāḥ）為彼識（vijñāna）之所依，是色之淨（prasāda）。

rūpaṃ dvidhā viṃśatidhā śabdastvaṣṭavidhaḥ rasaḥ /
ṣoḍhā caturvidho gandhaḥ spṛśyamekādaśātmakam // VAkK_1.10 //

色二十種分二；聲八種，味十六，
香四種，觸（spṛśya）十一為性。

vikṣiptācittakasyāpi yo 'nubandhaḥ śubhāśubhaḥ /
mahābhūtānyupādāya sa hyavijñaptirucyate // VAkK_1.11 //

散亂無心者之善惡隨行；
依大種（mahābhūta）故，說為無表色。

bhūtāni pṛthividhāturaptejovāyudhātavaḥ /
dhṛtyādikarmasaṃsiddhā kharasnehoṣṇateraṇāḥ // VAkK_1.12 //

大種（bhūta）者，即地（pṛthivī）、水（ap）、火（tejas）、風（vāyu）四界（dhātu）；
由持（dhṛti）等業成就故，堅、潤（sneha）、暖（uṣṇa）、動（teraṇa）。

pṛthivī varṇasaṃsthānamucyate lokasaṃjñayā /
āpastejaśca vāyustu dhātureva tathāpi ca // VAkK_1.13 //

地由世間共名（saṃjñā），說為色（varṇa）與形（saṃsthāna）；
水（āpa）、火（tejas）亦然；風（vāyu）即是界（dhātu），亦如是。

indriyārthāsta eveṣṭā daśāyatanadhātavaḥ /
vedanānubhavaḥ saṃjñā nimittodgrahaṇātmikā // VAkK_1.14 //

根（indriya）、境（artha）即是此等，是十處（daśa-āyatana）界[歧義:十處／十二處存疑];
受（vedanā）即領受（anubhava），想（saṃjñā）者以取相（nimitta-udgrahaṇa）為性。

caturbhyo 'nye tu saṃskāraskandhaḥ ete punastrayaḥ /
dharmāyatanadhātvākhyāḥ sahāvijñaptyasaṃskṛtai // VAkK_1.15 //

除四外，其餘為行蘊（saṃskāra-skandha）；
此復三者，名法、處、界，與無表色、無為（asaṃskṛta）。

vijñānaṃ prativijñaptiḥ mana āyatanaṃ ca tat /
dhātavaḥ sapta ca matāḥ ṣaḍ vijñānānyatho mahaḥ // VAkK_1.16 //

識（vijñāna）者即是了別（prativijñapti）；
意（manaḥ）與彼為處（āyatana），計七界；
其餘六識（vijñāna）其後廣。

ṣaṇṇāmanantarātītaṃ vijñānaṃ yaddhi tanmanaḥ /
ṣaṣṭhāśrayaprasiddhayarthaṃ dhatavo 'ṣṭādaśa smṛtāḥ // VAkK_1.17 //

六識後次第而生者，即是意（manaḥ）；
為施設第六所依（āśraya）故，說十八界。

sarvasaṃgraha ekena skandhenāyatanena ca /
dhātunā ca svabhāvena parabhāvaviyogataḥ // VAkK_1.18 //

一切總攝（saṃgraha）由一蘊、一處、一界；
自性（svabhāva）離他性（parabhāva）故。

jātigocaravijñānasāmānyādekadhātutā /
dvitve 'pi cakṣurādīnāṃ śobhārtha tu dvayodbhavaḥ // VAkK_1.19 ==

種（jāti）、境（gocara）、識之共，即一界性；
眼等雖二，而二生起為莊嚴義。

rāśyāyadvāragotrārthāḥ skandhāyatanadhātavaḥ /
mohendriyarūcitraidhāttistraḥ skandhādideśanāḥ // VAkK_1.20 //

蘊、處、界，以聚（rāśi）、入（āya）、門（dvāra）、種性（gotra）四義為義；
說蘊等三，依痴（moha）、根（indriya）、染（rūcita）三界之故。

vivādamūlasaṃsārahetutvāt kramakāraṇāt /
caittebhyo vedanāsaṃjñe pṛthakskandhau niveśitau // VAkK_1.21 //

為輪迴諍根本（vivāda-mūla）因、由次第故；
受、想二蘊別（pṛthak）從心所（caitta）法安立。

skandheṣva saṃskṛtaṃ noktamarthāyogāt kramaḥ punaḥ /
yathaudārikasaṃklesabhājanādyarthadhātutaḥ // VAkK_1.22 //

於蘊中不說有為，由義不合故；
次第復如粗（audārika）、染（saṃkleśa）、器（bhājana）等義之界性。

prāk pañca vārttamānārthyāt bhautikārthyāccatuṣṭayam /
dūrāśutaravṛttyānyat yathāsthānaṃ kramo 'thavā // VAkK_1.23 //

由現在義故先說五；由大種所造（bhautika）故四；
餘如遠速疾行者，隨處次第。

viśeṣaṇārthaṃ prādhānyabdahudharmāgrasaṃgrahāt /
ekamāyatanaṃ rūpamekaṃ dharmākhyamucyate // VAkK_1.24 //

由差別（viśeṣaṇa）義、由主（prādhānya）、由攝多法上故；
一處說為色，一名為法。

dharmaskandhasahasrāṇi yānyaśītiṃ jagau muniḥ /
tāni vāṅnāma vetyeṣāṃ rūpasaṃskārasaṃgrahaḥ // VAkK_1.25 //

牟尼（muni）說法蘊（dharmaskandha）千，彼八十；
於此等或名色、或名諸行（saṃskāra）所攝。

uttarottarasaṃprāptinirvāṇādyādhipatyataḥ //
以「非聖」、「聖」、「聖」三根，

心、所依、心所差別、住、雜染，

caturdaśa tathānyāni nivṛtterindriyāṇi vā //
依流轉之「所依生」、「住」、「受用」故，

=== 2.7 ===

duḥkhendriyamaśātā yā kāyikī vedanā sukham /
śātā dhyāne tṛtīye tu caitasī sā sukhendriyaṃ //

=== 2.8 ===

anyatra sā saumanasyaṃ aśātā caitasī punaḥ /

憂（daurmanasya）即心之不安；
捨（upekṣā）為中，二皆離分別。

=== 2.9 ===

dṛgbhāvanāśaikṣapathe nava trīṇi amalaṃ trayam /
rūpīṇi jīvitaṃ duḥkhe sāsravāṇi dvidhā nava //
見、修、學無學道有九、三，
無漏有三，色者有三；
命根於苦；諸有漏根二類各有九。

=== 2.10 ===

vipāko jīvitaṃ dvedhā dvādaśa antyāṣṭakādṛte /

異熟者十二——除最後八——
及憂為十三；

意、彼此、勝解、信等為八善，
分二類；憂、意、慧等之慧分三類，
餘各一類。

kāmāptamamalaṃ hitvā rūpāptaṃ strīpumindriye /
duḥkhe ca hitvā ārūpyāptaṃ sukhe cāpohya rūpi ca //

女根男根；又捨苦得無色界——

nava bhavanayā pañca tvaheyā anyapi na trayam //

bahubhiryukta ekān naviṃśatyā malavarjitaiḥ /

kāyendriyī navadravyaḥ daśadravyo 'parendriyaḥ //
欲界八事、無聲、
極微（parama-aṇu）非根；
身根九事；餘根十事。

=== 2.23 ===

cittaṃ caittāḥ sahāvaśyaṃ sarva saṃskṛtalakṣaṇaiḥ /
prāptyā vā pañcadhā caittā mahābhūmyādibhedataḥ //
心、心所必同時具一切有為相，
或由「得」故五種——依大種等差別。

=== 2.24 ===

vedanā cetanā saṃjñā cchandaḥ sparśo matiḥ smṛtiḥ /
manaskāro 'dhimokṣaśca samādhiḥ sarvacetasi //
受、想、思、欲、觸、慧、念、
作意、勝解、三摩地——此遍一切心。

=== 2.25 ===

śraddhāpramādaḥ praśrabdhirupekṣā hrīrapatrapā /
mūladvayam ahīṃsā ca vīryaṃ ca kuśale sadā //
信、不放逸、輕安、捨、慚、愧、
根二（信、進）、不害、及勤——善中恆有。

=== 2.26 ===

mohaḥ pramādaḥ kauśīdyam āśraddhayaṃ styānamuddhavaḥ /
kliṣṭe sadaiva akuśale tvāhrīkyamanapatrapā //
癡、放逸、懈怠、無信、惛沉、掉舉——
染中恆有；不善中無慚、無愧。

=== 2.27 ===

krodhopanāhaśāṭhyerṣyāpradāsam rakṣamatsarāḥ /
māyāmada-vihiṃsāśca parīttakleśabhūmikāḥ //
忿、恨、諂、嫉、誑、慳、覆——
及詐、慢、害——為輕微煩惱地。

=== 2.28 ===

savitarkavicāratvāt kuśale kāmacetasi /

以有尋有伺故，於善、欲界心，
二十二心所；惡作（kaukṛtya）於其或增。

於欲界（āveṇika）不善、見相應者二十；
以四煩惱（忿等）、以惡作（kaukṛtya）故二十一。

middhaṃ sarvāvirodhitvād yatra syād adhikaṃ hi tat //

=== 1 | 心、心所、不相應行 ===

光（arka）與伺（vicāra）更勝於前者（ataḥ param）。

無慚、無愧、不敬、於無過見過、僅少之畏，
愛、信、尊重、慚：此等（te punaḥ）於欲界、色界。

尋、伺、放逸（auddhatya）、輕蔑（saukṣmyatā）、慢、高舉（unnati），
醉（mada）、於自法貪（rakta）、心之遍取（paryādāna）。

心（citta）、意（manas）、識（vijñāna）同一義（ekārtha），
心與心所有五：所依（āśraya）、所緣（ālambana）、行相（ākāra）、相應（saṃprayukta）、自性（svabhāva）。

不相應行（viprayukta saṃskāra）者：得（prāpti）、非得（aprāpti）、同分（sabhāgata）、
無想定（āsaṃjñika）、滅盡定（nirodha-samāpatti）、命根（jīvita）、相（lakṣaṇa）。

名身等（nāmakāya-ādi）亦是，得、獲（lābha）、隨攝（samanvaya）；
得與非得（prāptyaprāpti）於自相續已斷（patita）離障（nirodha）。

三界繫（traidhātukā）有三種：善、不善、無記（śubhādi）；
自界繫得（svadhātukā āptī），未得者四種（caturvidhā）。

學與無學（śaikṣā-aśaikṣa）有三，已斷（aheya）二種（dvidhā）；
無記得（avyākṛtāpti）俱生（sahajā），除神通（abhijñā）、意成身（māṇika）外。

已離欲之色（nivṛta rūpa），於欲、色之未生者（kāme rūpasya na agrājā）；
非染無記得（akliṣṭāvyākṛtā prāpti）於過去、未來、現在三時（tridhā）。

欲等得為垢（kāmādy-āpti-amala），道之非得（mārgasyāprāpti）說；
凡夫性（pṛthagjanatva）由彼得有修（bhūsaṃcāra）所斷（vihīyate）。

同分（sabhāgatā）為有情平等（sattva-sāmya），於無想定者（āsaṃjñika-asaṃjñiṣu）；
心心所滅（cittacaitta-nirodha）為異熟（vipāka），此等（te）大果（bṛhat-phala）。

無想定（tathā-āsaṃjñi-samāpatti）亦爾，最後定（antye dhyāne）出離（niḥsṛti）欲；
善，唯有生得（upapatti-vedya），非聖者（ārya）得一界繫（ekādhvikā）。

滅定（nirodhākhyā）亦爾，為住（vihāra）故，最勝有（bhavāgra-jā）；
善，二種（dvi-vedya）不定（aniyatā），聖者之得（āpyā）由加行（prayogataḥ）。

覺所證（bodhi-labhyā），於三十四剎那得前（catustriṃśat-kṣaṇāptitaḥ prāk），於人不然；
欲色依地人（kāma-rūpāśraye bhūte nṛṣu），滅定等起（nirodhākhyā-āditaḥ）。

命（āyuḥ）即壽（jīvita），依（ādhāra）煖（ūṣman）與識（vijñāna）；
相（lakṣaṇa）者，生（punar-jāti）、老（jarā）、住（sthiti）、無常（anityatā）。

生（jāti）、生已（jāty-ādi）等（ādaya）於彼（teṣāṃ），
此八法（aṣṭa-dharma）唯一行（eka-vṛtti）；
所生之生（janyasya janikā）為生（jāti），非離因緣（na hetu-pratyayair vinā）。

=== 2 | 名身等同分 ===

名身等（nāmakāyādaya）、想（saṃjñā）、句（vākya）、字（akṣara）和集（samuktaya）；
欲色得有情名（kāma-rūpāpta-sattva-ākhyā）、等流（niṣyanda）、無記（avyākṛta）亦爾。

同分（sabhāgatā）亦為異熟（vipāko 'pi），得二種（āptayo dvidhā）；
相、等流，定、隨攝（samāpatti-samanvayāḥ）。

=== 3 | 六因 ===

能作因（kāraṇa）、俱有因（sahabhū）、同類因（sabhāga）、
相應因（saṃprayuktaka）、遍行因（sarvatraga）、異熟因（vipākākhya）：六種因（ṣaḍvidha hetu）說。

自他之能作因（svataḥ anye kāraṇaṃ hetuḥ），俱有因（sahabhū）互為果（mithaḥ-phala）；
如四大（bhūtavat）、心心所隨轉（citta-cittānuvartin），相與相應（lakṣaṇa-lakṣyavat）。

心所二種攝（caittā dvau saṃvarau），心之相（cetasaḥ lakṣaṇāni）；
心隨轉（cittānuvartin），由時、果、善等（kāla-phala-śubhatā-ādi）。

同類因（sabhāga-hetu）相似（sadṛśa），自部（sva-nikāya）地中初（bhuvi agrajaḥ）；
九地（nava-bhūmi）中互相（anyonyaṃ），道（mārga）等行者（sama-viśiṣṭayoḥ）。

加行（prayoga）、生（jāti），聞（śruta）、思（cintā）所生等（mayādi）；
相應因（saṃprayuktaka-hetu）心心所同所依（samāśrayāḥ）。

遍行因（sarvatraga-ākhya），於染污（kliṣṭa）自地中前遍行（svabhūmau pūrva-sarvagāḥ）；
異熟因（vipāka-hetu）不善（aśubhā）及有漏善（kuśalāḥ sāsravāḥ）。

=== 4 | 四果 ===

遍行（sarvatraga）、同類（sabhāga）二界繫（dvayadhvaga），三界繫三（tryadhvagāḥ trayaḥ）；
有為（saṃskṛta）與離繫（visaṃyoga）為果，彼非（te）無為（asaṃskṛtasya）之果。

異熟果（vipāka-phala）最後（antya），
前者（pūrva）為增上果（adhipati-phala）；
同類、遍行（sabhāga-sarvatraga）之等流果（niṣyanda），士用果（pauruṣa）二者（dvayoḥ）。

異熟（vipāka）為無記法（avyākṛta dharma），
有情數（sattva-ākhya）為有為所生（vyākṛta-udbhava）；
等流（niṣyanda）為因相似（hetu-sadṛśa），
離繫（visaṃyoga）為擇滅（kṣaya）由智（dhiyā）。

如種子所生者（yad-valāt jāyate yat-tat），是士用果（puruṣakārajam）；
未曾得（apūrvaḥ）為有為（saṃskṛta）之果，有為之增上果（adhipateḥ phalaṃ）。

一衝一足，即將入胎前位有之形；

同類清淨天眼可見，具業力猛勢，

住者，又一者；
出者，亦一切；
愚者，復為他，恆為卵生者 (maṇḍaja)。

胎入之三者，輪王、獨覺，
業、智，二者，由順次明顯故。

無我，唯有五蘊 (skandha)，
為煩惱業所成，
由中有相續，似入胎，如燈。

前末各二支，中間八支，圓滿。

前煩惱，二亦十：無明 (avidyā)、行 (saṃskāra)，
前業，識 (vijñāna)，
總蘊：名色 (nāma-rūpa)，此後。

先於六處未生、其前，從三和合，

得，先於淫事；
貪 (tṛṣṇā)，樂淫貪者；

宣說八支，

煩惱三，業二，事七，果亦爾；
因果略攝，二中由比知。

煩惱從煩惱，業亦爾，從是事，從是復；
事與煩惱復生，是生死支之理趣。

此中，能生為因，已生為果；
與智相對之法別有，

（彼）下者，自境；

事 (vastu) 如熟食飲，於此四生 (bhava-catuṣṭaya)。

=== 3 | 第四品 業品（初）===

【4.1】
世間種種差別由業（karma）生，業由思（cetanā）所造。／
思即意業；由思生語業與身業。

【4.2】
此二者為表（vijñapti）與無表（avijñapti），身表（kāya-vijñapti）成立。／
以形（saṃsthāna）非行（gati）故，（身表）是有為、剎那性，由（先念之）滅故（後念生）。

【4.3】
無因（之物）不應生；有滅（之物）應有因。／
（不然）應可二（處）取，於極微則不然。
語表（vāk-vijñapti）即是語音（vāg-dhvani）。

【4.4】
由三類因——mala（身動）、rūpokti（色發）、vṛddhi（增長）、akurvat（不作）、patha（道）等——／
無表從一剎那以上（之時位）有，由欲界、妙（āpta）地、上勝（atīta）地、及大種所生。

【4.5】
取自大種，身語之業為漏（āsrava）。／
無漏（anāsrava）所生處，無表為不執取（anupāttikā）。

【4.6】
等流（naiḥṣyandikī）與有情稱（sattvākhyā），等流所生、執取大種。／
定所生（samādhijā）與燒煮（pacayikī）非執取，非大種所生。

【4.7】
無記（avyākṛta）中無無表；於三門染污（aśubha），（無表）亦有。／
於欲、色界中亦有；有尋伺（savicāra）之定中，表（vijñapti）有。

【4.8】
於欲界，已斷（nivṛta）處、不作處，無表不生。／
究竟善（paramārtha-śubha）是解脫（mokṣa）；自性根本為慚（hṛi）、愧（apatrapā）。

【4.9】
與彼（善）相應，由表等業皆與彼相應。／
與彼相違，於究竟（paramārtha）、不定（avyākṛta）、定（dhruva）中為不善（akuśala）。

【4.10】
表發（samutthāna）二種：因（hetu）與剎那發起（utthāna）之稱。／
此二者中，初為發起者（pravartaka），後為隨行者（anuvartaka）。

【4.11】
發起者為見所斷（dṛṣṭi-heya）之識（vijñāna）—— 二者皆為意業。／
修所斷（bhāvanā-heya）有五品，亦為隨行者（anuvartaka）。

【4.12】
發起者以善等為先；隨行者亦三。／
齊牟尼之善，至二者（亦同）。二者為異熟（vipāka）所生，（而非為善）。

【4.13】
無表三種應知：律儀（saṃvara）、不律儀（asaṃvara）、彼二（itarā）。／
律儀名「別解脫」（prātimokṣa）；定所生、無漏亦然。

【4.14】
別解脫八種（就人而言）；就事（dravyataḥ）則四種。／
就相（liṅgataḥ）、就名轉（nāma-saṃcārāt）則別，彼等不相違。

【4.15】
從五、八、十五（應斷）一切，由於捨離取（virati-grahāt）——／
近事男（upāsaka）、近住（upavāsa）、住（stha）、沙門（śramaṇa）、眾首（uddeśa）、比丘（bhikṣu）等八。

【4.16】
尸羅（śīla）、妙行（sucarita）、業（karma）—— 復說為律儀（saṃvara）。／
於初（事）中表與無表（vijñapti-avijñapti），別解脫業道（kriyāpatha）。

【4.17】
八種隨於別解脫（律儀），定所生亦隨之。／
無漏所攝（anāsraveṇa）為聖者（ārya-sattvāḥ），最後二者為心隨行（cittānuvartin）。

【4.18】
未至定（anāgamya）中，所斷（prahāṇa）二者，亦無間道（anantarya-mārga）所生。／
正智（saṃprajñāna）與念（smṛti）二者，則為意根律儀（mendriya-saṃvara）。

【4.19】
住於別解脫，由現前（vartamānayā）無表所俱，以（彼）不放捨故恆常。／
由（過去、現前之）無表所俱，從剎那以上（皆得），至於過去。

=== 14 | 第五品之四 · 見修所斷與所斷差別 ===

見所斷者已離見，
如序由苦等現觀，
於欲界中彼離欲。

見所斷之四瀑流，及修所斷各四種。
由修所斷四亦爾，非有對故於色無色。

頂者由忍所害，見所斷為其所餘。
由見修所斷不忍所害，唯由修所斷。

我、我所、常、斷、捨、執、不因、不由因，
此五見乃於非因非道見。

於天我等常我顛倒故轉，
於彼執因即是苦見所斷。

由三見顛倒成四，倒轉之理亦爾。
由執取施設故，於名色二心隨轉。

慢有七種九差別，從見修盡所害。
害等至害之邊際，修所斷亦如是。

有部無有慾望生，無有慾望制伏。
由見所斷增長故，無悔亦無不吉。

遍行苦因見所斷，疑及與此共俱，
及相應無明。

此九上緣，離二見，
離已得共生，雖有於彼遍行。

由邪見邪定相應無明獨行，
於滅道見所斷，六非所證境。

自地寂滅為道，六地各有九地。
其境不同異因道。

非貪故非斷，非瞋非害故，
非慢非高舉故，寂靜清淨第一義。

遍行隨眠與相應隨眠，
以自地為緣，自部非遍行。

諸非所證上境非我取故無敵，
彼與何相應彼於是相應故。

上不定一切，欲界薩伽耶見，
邊執見共貪癡，餘此無記。

欲界三不善根，貪瞋癡三。
三非不善根，愛見慢癡，由癡為性故。

一遮遣記別已開已問，
應施設死生勝者異我等。

由貪瞋慢於過去未來生，
未生未斷於彼物相應。

由遍行非至意，自乘他勝非至意，
非生遍行由一切一切相應。

一切時有已說，由二有境果，
由彼有論故，一切有執四種。

彼以有相有體有分施設名，
第三善乘由作者故施設。

何障彼云何非餘，道不與乘相應，
非生非滅，云何深法。

苦見所斷已斷，與餘遍行相應，
前已斷於彼，餘以彼為境垢。

欲界生苦見所斷習所斷，
自界三一一得垢識境。

自下三上一垢，色界生，
無色界三界故，離三非所證境。

滅道見所斷，自乘上境，
非所證三界，離三非所證境。

俱有隨眠染污，無染污非俱

=== 5.32 ===

由無明而起渴愛，由渴愛而起邪見，由薩迦耶見而起諸煩惱。

=== 5.33 ===

由彼而起執取，由執取而起戒禁取，由戒禁取而起見取；
於自所起見生貪與慢，於他所起見生瞋 — 是順次起。

=== 5.34 ===

未斷隨眠、所緣現前、非理作意 — 三緣具足，煩惱方生。

=== 5.35 ===

欲界之隨煩惱即煩惱，欲漏除無明隨眠外，色無色界之煩惱即有漏。

=== 5.36 ===

此（諸煩惱）於定地中一向是內門轉，故說為一整聚；
以此因故，與隨眠合說為「漏」而別說為「隨眠」。

=== 5.37 ===

由與見類合故，亦說有異熟之別；
非諸漏之眷屬，非必皆同類相助。

=== 5.38 ===

如所說之諸漏，由見之差別故分為二；
取蘊即為四，無明則為能取，第五非二者合一。

=== 5.39 ===

此等為微細、隨逐，亦二種隨轉；
以能繫縛有情故，名為「隨眠」。

=== 5.40 ===

此等有流轉、漏落、執取、結合、執受之義 — 是「漏」之種種訓釋。

=== 5.41 ===

從結之差別更分為五；
由見、戒、疑三（為一類），餘四為另一類結。

=== 5.42 ===

嫉、慳二者皆一向是不善、自性二故 — 是為二種別結。

=== 5.43 ===

五種為上首（之結），二種為欲貪結之逾越，
三種為還來之結（惡戒、邪見、薩迦耶見）三者為攝根本。

=== 5.44 ===

謂：於空閑處不樂、於正道迷惑、於正道猶豫 — 此三者障礙解脫之趣向，是為「障礙」之三。

=== 5.45 ===

五種為上首，二種為色、無色界之貪，
傲、慢、無明為智者所說之三縛。

=== 5.46 ===

anutpāda-jñāna（無生智）與 kṣaya-jñāna（盡智）又於最初升起之智中。 // VAkK_7.4 //

para-citta-jñāna（他心智）由 duḥkha-jñāna 與 hetu-jñāna，由四[種]；
已超越 bhūmi（地）、akṣa、pudgala（人）者，失者、已生者——彼不能知。 // VAkK_7.5 //

dharma-jñāna 與 anvaya-dhī（隨行智）於 darśana-kṣaṇa（見之剎那）互為[相]；
śrāvaka（聲聞）能知 khaṅga-sthīn[歧義: 空之相三 / 該處]之一切，buddha（佛）不由 aprayoga（加行）[亦能知一切]。 // VAkK_7.6 //

kṣaya-jñāna 確為於 satya 中 parijñāta（遍了）等之 niścaya（決定）；
na parijñeya（未遍）等之 anutpāda-mati（無生智）所宣說。 // VAkK_7.7 //

由 svabhāva（自性）與 pratipakṣa（對治）、ākāra（行相）與 gocara（所行境）、
由 prayoga（加行）所作之 kṛtyatva（所作性）之方便 upacaya（增長）故為十。 // VAkK_7.8 //

於 dharma-jñāna 之 nirodha（滅）中，於彼 mārga 或 bhāvanā-path（修習道）中——
tri-dhātu（三界）之 pratipakṣa 為彼；[但]於 kāma-dhātu 之對治中無 anvaya（隨行）。 // VAkK_7.9 //

dharma-jñāna 與 anvaya-jñāna 為 ṣoḍaśa-ākāra（十六行相）；
saṃvṛta-jñāna 反之，由各各之 satya-ākāra（諦之行相）為四。 // VAkK_7.10 //

tathā（如是）paramāṇu-jñāna（極微智）nirmala（無垢），sa-mala（有垢）者又以 jñeya-sva-lakṣaṇa（所知之自相）為 ākāra，
gocara 為 ekaika-dravya（一個一個之物）。 // VAkK_7.11 //

śeṣa（其餘）十四 ākāra，除 śūnyatā（空）與 anātman（無我）外；
由十六 ākāra 外，[由] śāstra（經量）有其他之 ākāra。 // VAkK_7.12 //

由 dravyataḥ 十六 ākāra 與 prajñā-ākāra（般若行相）共；
sālambana（有所緣）之行相顯現一切，而 ākāryate（行相顯於）sat（有）者。 // VAkK_7.13 //

tri-dhātu（三界）之初為善，其他者於一切 bhūmi（地）；
dharma-jñāna 於六[地]；而 anvaya-jñāna 於九[地]，tathaiva 亦於六[地]。 // VAkK_7.14 //

dhyāna 中其他之 paramāṇu-jñāna 以 kāma-rūpa（欲界與色界）為 āśraya（所依）；
dharma-jñāna 以 kāma（欲界）為 āśraya，其他以 tri-dhātuka（三界）為 āśraya。 // VAkK_7.15 //

smṛtyupasthāna（念住）所得為一 dhī；
para-citta-dhī 於 nirodha 為 trīṇi（三）catvāri（四）[之數]；其餘為 dharma-dhī 之 gocara—— nava（九）。 // VAkK_7.16 //

mārga-jñāna 與 anvaya-jñāna 為 nava（九）；
duḥkha-dhī 與 hetu-dhī 之 dvi-dhā（二種）由 catuṣṇām（四[者]）；eka（一[智]）非由[四者]；dharmāḥ（法）又為 daśa（十）。 // VAkK_7.17 //

tri-dhātuka-amalā（三界無漏）之 dharmāḥ，akṛta（未造）亦 dvidhā-dvidhā（二種二種）；
saṃvṛta-jñāna 之 sva-kalā（自相之分）亦—— yad-ekaṃ（一[者]）由 anātman（無我）應知。 // VAkK_7.18 //

**VAkK 7.47**

agryam（第一） 由 avyabhicāritvāt（不退轉），為將 hita-iṣṭa-phala（願果）運作於弟子。

**VAkK 7.48**

ṛddhi（神足）、samādhi（等持）、gamana（行）、nirmāṇa（化）——三種 gati（運轉）；
教師的是 manojava（意速行）；其他眾生，還有 ādhīmokṣikī（教化）。

**VAkK 7.49**

kāmāpta（欲界所得）、nirmita（化）、bāhya（外），四 āyatana（無色界）各分二種；
rūpāpta（色界所得）一，加上 nirmāṇacitta（化心）二，總十四種。

**VAkK 7.50**

依序，dhyāna-phala（禪果）二，直至第五，非最高者；
彼之 lābha（得）如 dhyāna——由 śuddhāt（清淨）得、從 sva（自性）得，亦從彼更高者得。

**VAkK 7.51**

以 svabhūmika（自地）之力起 nirmāṇa（化），以 adhara（下地）之力發 bhāṣaṇa（語）；
nirmāṇa（化）心不離教師（śāstuḥ），唯由 adhiṣṭhāna（加持）而轉。

**VAkK 7.52**

mṛta（死者）亦可 adhiṣṭhāna（加持），不堅固者（屍）則無加持（餘師說無）；
adhiṣṭhāna 由最初一願、次第多願；若已 jitā（得勝），反而 viparyaya（倒轉）。

**VAkK 7.53**

avyākṛta（無記）中 bhāvanā-ja（修所生）三、upapatti-ja（投生所生）一；
ṛddhi 由 mantra（咒）、auṣadha（藥）、karma-ja（業生），如是五種。

**VAkK 7.54**

divya-śrotra（天耳）、divya-cakṣus（天眼）、rūpa-praśāda（色淨），皆 dhyāna-bhūmika（依禪那地）；
於 sabhāga（等分）avikala（無缺）之境，nitya（恆常）通達 dūra（遠）、sūkṣma（微細）等 gocara（境）。

**VAkK 7.55**

dūra（遠）、āvṛta（被覆）、sūkṣma（微細），māṃsa-cakṣus（肉眼）皆不能見；
唯 divya-cakṣus（天眼）能見。

dvi-tri-sāhasra（二三千）yojana 由旬之 dṛś（見者）—— arhat（阿羅漢）、khaḍga（犍闥）、daiśika（上師）；
此外亦有 upapatti-āpta（投生所成之得）者——其 dṛś（見者）中無 antara（間隔）。

**VAkK 7.56**

ceto-jñāna（心智智）此三：tarka（思）、vidyā-kṛta（明所作），
最初 nāraka（地獄眾生）亦知；然於 nṛ（人），非 upapatti-labha（投生得）。

**VAkK 8.1**

**VAk K 8.9**

dravyataḥ（就事而言），prasrabdhi（輕安）、sukha-mādaya（樂等）daśa caikaṃ（十與一）；
śraddhā（信）、prasāda（淨信）、prīti（喜）tu，saumanasya（悅）由 dvidhā（兩路）āgama（得來）。

**VAkK 8.10**

kliṣṭeṣu（染污中）sa-prīti-sukha（具喜樂）prasāda（淨信）saṃpradhī（正定）smṛti（念）；
upekṣā-smṛti-śuddhi（捨念淨）ca，kecit（有人說）prasrabdhi-upekṣaṇa（輕安捨）中。

**VAkK 8.11**

由離 aṣṭa-apakṣāla（八支雜染）muktatvāt（解脫故），caturthaka（第四）為 anīñja（不動）；
vitarka（尋）、vicāra（伺）、śvāsa（息），及 sukha-ādi（樂等）catuṣṭaya（四種）。

**VAkK 8.12**

saumanasya（悅）、sukha（樂）、upekṣā（捨）——第二 dhyāna 之特相（upekṣā-sumanaskata）；
於 sukha-upekṣa（樂捨）中，upekṣā 為 dhyāna-upapatti（禪那投生）中之 pravida（最勝）。

**VAkK 8.13**

kāya-vijñāna（身識）、akṣi-vijñāna（眼識）、śrotra-vijñāna（耳識），及 vijñapti-utthāpaka（引發表）者，
dvitīya-ādi（第二禪初）所得；此為 akliṣṭa（無染）、avyākṛta（無記）。

**VAkK 8.14**

離彼者，由 upapatti-taḥ（投生）之 vairāgya（離欲）得 śuddha（淨）；
由 vairāgya 得 anāsrava（無漏）；kliṣṭa（染污）由 hāni-upapatti-taḥ（投生退）得。

**VAkK 8.15**

tṛtīya-ādi（第三以上）、ūrdhva-adhas（上下）anāsrava（無漏）antara（中間）之 śubha（善），
utpadyate（如是生）；kliṣṭa（染）ca api，亦從 śuddhāt（淨）生、svabhūmika（自地）生。

**VAkK 8.16**

kliṣṭāt（從染）生 sva（自地）之 śuddhaka（淨）與 kliṣṭa（染）；
evaṃ ca（如是亦）從 adhara（下地）之 śuddhaka（淨）生；
cyutau tu（若退轉），從 śuddhakāt（淨）生 kliṣṭa（染）；
sarvaṃ kliṣṭāt（一切從染）……

=== 22 | 第八章 攝頌 ===

但（非）最上。〔8.16〕

純淨道分為四：斷、支分等，依其次第。
此依煩惱之生處、自性、上方、無漏而立。〔8.17〕

二、三、三、一，斷與支分等相續，
往來二途，八地相雜相連。〔8.18〕

超越定、非想非非想處（第三行），
唯以下方為所依：四禪、四無色，其下者。〔8.19〕

聖者由有頂之「有少」而漏盡；
有貪者以自性為所緣：具對象之淨禪。〔8.20〕

根本善與無色，以下界為所緣；
由無漏及近分而超越煩惱。〔8.21〕

八近分：純、純苦、純樂；
聖初禪分三：尋、伺等禪與其後。〔8.22〕

純捨三分，大梵果為其後；
下初定有尋有伺，上者無二（無尋無伺）。〔8.23〕

無相定由相似相狀而轉：
空、無我之行相；無願以真實相狀。〔8.24〕

清淨、無垢者：即三解脫門；
空、無相、無願之三三昧。〔8.25〕

二解脫門為不還者所緣：空、無常之行相；
無相由無相行，寂靜由無量行而得滅。〔8.26〕

人之有漏定無瞋者，七近分所離；
三摩地修，初淨定趣向於樂。〔8.27〕

為見、為智、為神通，慧之差別，修行所生；
金剛喻定，最後之禪，修有漏之滅。〔8.28〕

四無量心，以瞋等之敵品為性：
慈、悲、喜、捨。〔8.29〕

捨之相：與貪相違，快樂、痛苦之有情為相，
由有情之喜，於欲界有情為所緣。〔8.30〕

二禪有喜，餘六中或五中無；
彼於人非斷，三定必具。〔8.31〕

八解脫：前二（非色），二禪有之；
第三與最後，無貪，淨與無色；入等至。〔8.32〕

滅盡定，極微、極微之相續後，
由自清淨下位聖者以心而起。〔8.33〕

欲得、所見對象之初變化者；
彼以次第智品、上方、自性、苦等為所緣。〔8.34〕

八勝處：初二如前二解脫，
二者如次二解脫，餘者如淨解脫。〔8.35〕

十遍處：無貪八，後禪為所緣；
欲二，純與無色，於自四蘊為所緣。〔8.36〕

滅定已說，離染加行已得者為餘；
三性所依：無色（之名），餘者人（所生）。〔8.37〕

由因、業、力、界，二無色生；
於色界禪定，亦以彼二及法性。〔8.38〕

正法有二：教、證；
說者、持者、說法者、修行者。〔8.39〕

迦濕彌羅毘婆沙宗所成之阿毗達磨，
我已大略宣說；於難解之處，
若有我等之咎，於正法、毘奈耶中，諸聖者為定量。〔8.40〕

世間眼已閉，證眾亦多已滅，
未見真實、不斷煩惱者，妄以惡辯攪亂此教。〔8.41〕

自生（梵天）已歸最上寂靜，
諸佛正法幢亦然；世無依怙，
惡見之眾離繫，今放縱而行。〔8.42〕

〔「生命已至喉間」——結頌之起，止〕

=== 23 | 第八品結頌 ===

聖者muni（牟尼）之教法、於壯盛之時、於煩惱mala（垢），求解脫者mumukṣu（慕解脫）不應放逸。
