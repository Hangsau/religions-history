Samantabhadra：Āptamīmāṃsā

devāgamanabhoyānacāmarādivibhūtayaḥ /
māyāviṣvapi dṛśyante nātastvamasi no mahān // SAm_1 //

天降、吉祥、拂塵等瑞相，
以及幻術、宇宙皆可見，
故於我等而言汝非偉大。

adhyātmaṃ bahirapyeṣa vigrahādimahodayaḥ /
divyaḥ satyo divaukassvapyasti rāgādimatsu saḥ // SAm_2 //

此身形等之宏大顯現，內在而似外在；
彼乃神聖真實，雖於天界，於我等有貪等者中亦存。

tīrthakṛtsamayānāṃ ca parasparavirodhataḥ /
sarveṣāmāptatā nāsti kaścideva bhavedguruḥ // SAm_3 //

宗祖與教義互相矛盾故，
非一切皆可信，亦無人堪為大師。

doṣāvaraṇayorhānirniḥśeṣāstyatiśāyanāt /
kvacidyathā svahetubhyo bahirantarmalakṣayaḥ // SAm_4 //

過失與遮蔽完全斷滅並已超越，
猶如某些情形下，內外之垢由各自之因而滅。

sūkṣmāntaritadūrārthāḥ pratyakṣāḥ kasyacidyathā /
anumeyatvato 'gnyādiriti sarvajñasaṃsthitiḥ // SAm_5 //

猶如對某人而言，微細、近、遙之對象皆為現量；
由可推知，如火被推知，全知者之安立亦爾。

sa tvamevāsi nirdoṣo yuktiśāstrāvirodhavāk /
avirodho yadiṣṭaṃ te prasiddhena na bādhyate // SAm_6 //

汝正是無過失者，語不違道理與教典；
若所欲立不違已成，則不為已成所破。

tvanmatāmṛtabāhyānāṃ sarvathaikāntavādinām /
āptābhimānadagdhānāṃ sveṣṭaṃ dṛṣṭena bādhyate // SAm_7 //

汝宗之外者、斷滅論者、一概偏執論者，
自負為可信而燒，以其所立之宗見為破。

kuśalākuśalaṃ karma paralokaśca na kvacit /
ekāntagraharakteṣu nātha svaparavairiṣu // SAm_8 //

主啊！於偏執一邊者，於自他之敵中，
善惡業與他世皆不存在。

bhāvaikānte padārthānāmabhāvānāmapahnavāt /
sarvātmakamanādyantamasvarūpamatāvakam // SAm_9 //

於實有之偏執與非有之否定，
遍一切、無始無終、自相不動之性皆被破壞。

kāryadravyamanādi syātprāgabhāvasya nihnave /
pradhvaṃsasya ca dharmasya pracyave 'nantatāṃ vrajet // SAm_10 //

若否定先於非有之果事與法，
則有事之毀滅與壞滅趨於無窮。

sarvātmakaṃ tadekaṃ syādanyāpohavyatikrame /
anyatra samavāyena vyapdiśyeta sarvathā // SAm_11 //

遍一切者應為一，除遣他性時；
唯於異處以和合而說，一切應爾。

abhāvaikāntapakṣe 'pi bhāvāpahnavavādinām /
bodhavākyaṃ pramāṇaṃ na kena sādhanadūṣaṇam // SAm_12 //

於非有偏執宗與有否定論者之邊，
覺了語為量，何以無立量之過失？

virodhānnobhayaikātmyaṃ syādvādanyāyavidviṣām /
avācyataikānte 'pyuktirnāvācyamiti yujyate // SAm_13 //

由於相違，於憎惡離二邊中道者，
二與一之自性皆不可立；
不可說為偏執，亦不得說為不可說。

kathaṃcitte sadeveṣṭaṃ kathañcidasadeva tat /
tathobhayamavācyaṃ ca nayayogānna sarvathā // SAm_14 //

某方面為有、所欲為有，
某方面為非有、為非有，
如是二者皆不可說，由道理之運用，非一切。

sadeva sarvaṃ ko necchetsvarūpādivibhājanāt /
asadeva viparyāsānna cenna vyavatiṣṭhate // SAm_15 //

自相之四種差別故，誰亦不欲一切為有；
由於顛倒，非一切為非有，非此則不成立。

kramārpitadvayād dvaitaṃ sahāvācyamaśaktitaḥ /
avaktavyottarāḥ śeṣāstrayo bhaṅgāḥ svahetutaḥ // SAm_16 //

由次第所立之二，於「俱」不可說，乃無力故；
其餘之三宗（不說之餘）自因而破。

astitvaṃ pratiṣedhyenāvinābhāvyekadharmiṇi /
viśeṣaṇatvātsādharmyaṃ yathā bhedavivakṣayā // SAm_17 //

於與遮遣不可離之一體者，
由差別相故為同體性，如欲說差別。

nāstitvaṃ pratiṣedhyenāvinābhāvyekadharmiṇi /
viśeṣaṇatvādvaidharmyaṃ yathā 'bhedavivakṣayā // SAm_18 //

於與遮遣不可離之一體者，
由差別相故為異體性，如欲說無別。

vidheyapratiṣedhyātmā viśeṣyaḥ śabdagocaraḥ /
sādhyadharmo yathā heturahetuścāpyapekṣayā // SAm_19 //

所立與遮遣之自性，應區別為言所及；
如所成法之因與非因，依觀待而說。

śeṣabhaṅgāśca netavyā yathoktanayayogataḥ /
na ca kaścidvirodho 'sti munīndra tava śāsane // SAm_20 //

其餘之破亦應依所說道理之運用而引；
大王啊！於汝之教中，無有少分相違。

evaṃ vidhiniṣedhābhyāmanavasthitamarthakṛt /
neti cenna yathākāryaṃ bahirantarupādhibhiḥ // SAm_21 //

如是於立與遮，不令義不安立；
若非「非此」，則應如所作，由內外之依。

dharme dharme 'nya evārtho dharmiṇo 'nantadharmaṇaḥ /
aṅgitve 'nyatamāntasya śeṣāntānāṃ tadaṅgatā // SAm_22 //

法法各別，於無量法之持法者，
若一極為主體，其餘皆為其附屬。

ekānekavikalpādāvuttaratrāpi yojayet /
prakriyāṃ bhaṅginīmenāṃ nayairnayaviśāradaḥ // SAm_23 //

於一與多之差別等後，後亦應用；
善巧道理者以此破斥之方法行其論。

advaitākāntapakṣe 'pi dṛṣṭo bhedo virudhyate /
kārakāṇāṃ kriyāyāśca naikaṃ svasmātprajāyate // SAm_24 //

於非一偏執之宗中，所見之差別亦相違；
能作者與所作事非一，非從自生。

karmadvaitaṃ phaladvaitaṃ lokadvaitaṃ ca no bhavet /
vidyāvidyādvayaṃ na syādbandhamokṣadvayaṃ tathā // SAm_25 //

業非一、果非一、世間非一，
明與無明之二不應有，繫與解之二亦爾。

hetoradvaitasiddhiśced dvaitaṃ syāddhetusādhyayoḥ /
hetunā cedvinā siddhirdvaitaṃ vāṅmātrato na kim // SAm_26 //

若由因成非一，則因與所成之二應有；
若由因成而非由因，或僅由言語則無二。

advaitaṃ na vinā dvaitādaheturiva hetunā /
saṃjñinaḥ pratiṣedho na pratiṣedhyādṛte kvacit // SAm_27 //

非一不離二，如因與能作者；
唯遮於能詮者，非於離所遮之任何處。

pṛthaktvaikāntapakṣe 'pi pṛthaktvādapṛthakkṛtau /
pṛthaktve na pṛthaktvaṃ syādanekastho hyasau guṇaḥ // SAm_28 //

於別異偏執之宗中，離別異於非別異，
於別異中別異不應有，以彼功德住於多。

santānaḥ samudāyaśca sādharmyaṃ ca niraṅkuśaḥ /
na syātānekasiddheśca tatsambhavādṛte kvacit // SAm_29 //

相續、總聚、同體性無拘礙，
若不立多，則於一切處不應成。

// SAm_29 //
若去除統一性，過去存在與彼一切皆不應有。

// SAm_30 //
若識以真我為異而從所知，於二邊皆為非有；
識若無，云何有所知？於彼等敵論者，內外俱空。

// SAm_31 //
「他二者」之語以共相為義，別相未曾宣說；
無共相故，彼等一切語言皆為虛妄。

// SAm_32 //
由相違故，二者無同一自性——此於 Vādanyāya 之敵亦然；
於「不可說」之極端，言說亦不能成「不可說」之語。

// SAm_33 //
於無所觀待中，異與同皆非真實，由二理故；
如以自相差別為能證，二者之同與異亦爾。

// SAm_34 //
然以「存在」之共相故，諸法皆同；
以各別事等之差別故，如「不共之因」，為顯異與不異。

// SAm_35 //
於具無量相之所差別，欲說與不欲說；
此中「存在之差別相」非「不存在之差別相」——為達此義者所不取。

// SAm_36 //
二者以現量為境，於一處不相違；
彼等之「異與不異」非世俗，以德與根本之表述故。

// SAm_37 //
於常住獨存之邊執，縱亦變易不可得；
何況無作者？量在何處？其果又何在？

// SAm_38 //
若以量與能作者為令顯了，如根境般顯了；
然彼等若是常住，變易者何在？於善人之教外，何物可得？

// SAm_39 //
若「存在」一切是所作，如人（身）不應再起；
變化之本性，正破常住獨存之執。

// SAm_40 //
則功德與罪業之業不應有；過去之果何從得？
若汝非彼等之主，繫與解俱無。

// SAm_41 //
於剎那獨存之邊執，過去存在等亦不可得；
以無再識等故，事之創起與果皆無從。

// SAm_42 //
若全體為無而作業，願如虛空華不生！
願取著之決定無有！願事之生起中無慰藉！

// SAm_43 //
因果等之存在無——以別異故、無連屬故；
若非一如別相續，具彼者之相續亦別。

// SAm_44 //
於「他」之「非餘」之語；此世俗非虛——云何？
無勝義之世俗不存，離勝義亦無世俗。

// SAm_45 //
四句之戲論，於一切邊皆無可言說故；
真實與異亦不可說——二者之相續與具彼者。

// SAm_46 //
「四句不可說」之戲論，亦不應說；
非法、非周遍之邊、非所差別之差別相。

// SAm_47 //
以內事等之差別故，有名之存在可為遮遣；
於「非有」之別，無實體——是表詮與遮詮之依處。

// SAm_48 //
非法者不可說——由一切邊離故；
然以施設之顛倒故，實事亦成非法。

// SAm_49 //
若一切邊皆不可說，彼等何況可言？
若此世俗不虛，由勝義之顛倒故。

// SAm_50 //
不可說者，以不能故耶？非有者，以無故耶？不覺者，以無知故耶？
若無此初之二說，云何以巧說為明？

// SAm_51 //
無意圖者不害，有意圖者乃害；
離此二之識乃被繫——已繫之識不解脫。

// SAm_52 //
以無因故——非貪欲之害因、非害者；
心相續之滅是解脫——非八支道之所生。

// SAm_53 //
若不善之業起，以因之和合——
於二所依不異，彼如理相應，無別等。

// SAm_54 //
蘊與相續，以世俗故為無為；
其住、起、滅——如驢角，不應有。

// SAm_55 //
由相違故，二者無同一自性——此於 Vādanyāya 之敵亦然；
於「不可說」之極端，言說亦不能成「不可說」之語。

// SAm_56 //
於常住者，以彼再識故——非無因、非斷彼；
於剎那者，以時之差別、覺不流轉之過故。

// SAm_57 //
顯了不從共相之我起，不從連屬而滅；
以自相故滅、以自相故起——彼等於一處共生起，是為存在。

=== 57 | 因果別相 ===

果之生起與壞滅各別有因，由於相狀各別故；
彼等不依 jāti（類）等而住，如虛空之花。

=== 58 | 憂癡捨有因 ===

鉢、臂環、金之壞滅、生起與住存，
世人對此生憂、癡、捨——此皆有其因。

=== 59 | 三真實 ===

許乳為量者不食酪，許酪為量者不飲乳，
二者皆不許者不食此二——由此真實為三。

=== 60 | 果因等異 ===

果與因之異、德與德者之異、
普遍（sāmānya）與其同類之異——若執為各各決定...

=== 61 | 一與遍 ===

一者之遍於多者，非因無分；若因其有分，
彼之一性不可得——遍於之過失不應成立。

=== 62 | 遍於之過 ===

於處時差別中亦應有遍於，如已成者；
形色之因與形色之果不應同處。

=== 63 | 依存無獨立 ===

由所依與能依之關係，samavāyin（依存體）無獨立性；
此關係不成立——與依存體無關。

=== 64 | 普遍與內屬 ===

普遍與 samavāya（內屬）各各單獨完成，
無所依則不存；對非存者何法可說？

=== 65 | 三如虛空花 ===

普遍與內屬終究無關，
由彼二者所詮之義不成；此三如虛空之花。

=== 66 | 原子之破 ===

若原子絕對非異，於集聚中亦應可分，
四元素（bhūtacatuṣka）不應集聚——此僅顛倒。

=== 67 | 果因顛倒 ===

果之顛倒即原子之顛倒，果之相即因，
由二皆無故彼不立；亦不超越 guṇa（德）與 jāti（類）。

=== 68 | 一性與數 ===

於一性中，此一之他者之無、其餘之無非相離者之無，
與數之二不相違——此世俗（saṃvṛti）全為虛妄。

=== 69 | 二非一體 ===

由相違故二者不應一體，此斥非佛教論理者；
雖於絕對不一中說，說為不可說則不應理。

=== 70 | 實與變 ===

dravya（實）與 paryāya（變）之一性，由彼不相離故，
由變異差別故，由有能與無能差別故。

=== 71 | 多性之因 ===

由名與數差別故、由自相差別故、
由作用等差別故——彼等多性非全然。

=== 72 | 二與普遍 ===

若為有觀待之成則二法不住，
於無觀待之成則無 sāmānya（普遍）與 viśeṣa（別性）之別。

=== 73 | 二非一體（重頌）===

由相違故二者不應一體，此斥非佛教論理者；
雖於絕對不一中說，說為不可說則不應理。

=== 74 | 法與法之不相離 ===

dharma（法）與 dharmin（法所依）之 avinābhāva（不相離）由相互觀察而成，
此非自性之自，以知者之肢分為喻。

=== 75 | 因與聖教量 ===

若一切由因而得，則無由現量而起之進路；
若一切由 āgama（聖教）而得，則相違之義亦...

=== 76 | 二非一體（重頌）===

由相違故二者不應一體，此斥非佛教論理者；
雖於絕對不一中說，說為不可說則不應理。

=== 77 | 說者成與未成 ===

說者未成辨者，由彼因所成者為「由因所成」；
說者已成就，由彼言所成者為「由聖教所成」。

=== 78 | 內義與外義 ===

若義絕對為內，心之語言皆為虛妄；
由無 pramāṇa（量）故，離彼量如何得成？

=== 79 | 所成與能成 ===

若所成與能成之識唯是「識之自身」，
則所成與因皆無，以宗與因之過故。

=== 80 | 外義之失 ===

若義絕對為外，由遮 pramāṇa（量）之無，
凡說相違義者皆應成就其果。

=== 81 | 二非一體（重頌）===

由相違故二者不應一體，此斥非佛教論理者；
雖於絕對不一中說，說為不可說則不應理。

=== 82 | 有法與所量 ===

於 bhāva（有）與 prameya（所量）觀待中，遮 pramāṇa（量）之無；
於外部 prameya（所量）觀待中，pramāṇa（量）與其影像...

=== 83 | 命與名 ===

jīva（命）之名為有外義者，由是名稱故，如「因」之名；
māyā（幻）等顛倒之名，亦由彼幻等解說者。

=== 84 | 覺名與覺知 ===

buddhi（覺）之名與義之名，三種為語言之覺等；
覺等之知為平等，三者為其影像。

=== 4 | SAm_86—SAm_114 ===

【SAm_86】
無雲之時，外部所緣之二，與其同類之內所緣，二者俱成。

【SAm_87】
Buddhi（覺）與 śabda（聲）之 pramāṇa（量）性，於外部所緣之有無；如是於 artha（義）之得與不得之處，真實與虛妄之判定乃得成立。

【SAm_88】
若 artha 之成就唯由 daiva（天命），則 pauruṣa（人力）何由而立？

【SAm_89】
若成就唯由 pauruṣa，則 pauruṣa 何由 daiva？若 pauruṣa 非徒然，則於一切有情皆應為 pauruṣa。

【SAm_90】
由於相違，syādvāda（非一概論）之敵所立之兩者同一性不得成立。於「不可說」之 taikānta（一端論）所立，亦屬不當；「不可說」之說，亦不成立。

【SAm_91】
無覺慧之先，所欣所厭，由己之 daiva；有覺慧之先，所欣所厭，由己之 pauruṣa。

【SAm_92】
若 pāpa（罪業）必由他人之苦，puṇya（福業）必由他人之樂，且無心與染著亦繫於有情，則由 nimitta（因緣）而得。

【SAm_93】
若 puṇya 必由己之苦，pāpa 必由己之樂，則離欲之牟尼與智者，不應以二者為 nimitta。

【SAm_94】
由於相違，syādvāda 之敵所立之兩者同一性不得成立。於「不可說」之 taikānta 所立，亦屬不當；「不可說」之說，亦不成立。

【SAm_95】
若清淨與染污之支分，及苦樂，於己與他二處，與 puṇya、pāpa 之漏入相應，則汝之 arhatta（應供性）為徒然。

【SAm_96】
若由 ajñāna（無明）必得 bandha（繫縛），則 kevalī（全知者）所知無量，不得為 kevalī；若由少智而得 vimokṣa（解脫），則由 ajñāna 多者亦應得。

【SAm_97】
由於相違，syādvāda 之敵所立之兩者同一性不得成立。於「不可說」之 taikānta 所立，亦屬不當；「不可說」之說，亦不成立。

【SAm_98】
由 ajñāna 由 moha（癡）得 bandha，不由離 moha 之 ajñāna；由少智與離 moha 得 mokṣa（解脫），由具 moha 者，異於此。

【SAm_99】
由 kāma（貪）等所生之種種，隨 karma（業）繫縛相應。此 karma 由其自因，於 jīva（有情）得清淨或不清淨。

【SAm_100】
清淨與不清淨復為二 śakti（能），如消化與不消化之 śakti。二者之顯現為有始或無始，其 svabhāva（自性）乃思惟所不及。

【SAm_101】
Tattva-jñāna（真實智）為彼之 pramāṇa，一時照耀一切；若此智為次第而生，則由 anaya（非法則）所修。

【SAm_102】
Upekṣā（捨）為其初果，其餘者為攝取與棄捨之慧；或先以智滅 ajñāna，一切皆於其自境。

【SAm_103】
於顯示 anekānta（非一端論）之語句，對所了解者，viśeṣaka（差別相）應有。nipāta（墮處）或有，於汝之 kevalī 亦由 artha-yogitva（義合）故。

【SAm_104】
Syādvāda 若於一切與 ekānta（一端論）相應，則其軌範為何？由 saptabhaṅga-naya（七支論法）所觀，為 heya（應捨）與 ādeya（應取）之 viśeṣaka。

【SAm_105】
於 syādvāda 之 kevala-jñāna，照耀一切 tattva 之時，由 sākṣāt（現量）與 asākṣāt（比量）之別，於 avastu（無實）之某一類即得成立。

【SAm_106】
由 sadharma（同法）能立所立，由同法性不相違故，syādvāda 之 naya（特殊陳述），顯示所差別之義。

【SAm_107】
Naya、upanaya（特殊推論）、ekānta 之 tri-kāla（三時），其 samuccaya（總集）為 bhāva（性）之無混關係；dravya（實體）一而現於多面。

【SAm_108】
虛妄之聚合為 mithyā（虛妄）；若 mithyā 非 mithyā，則一端之 mithyā 屬我；不觀待之 naya 為 mithyā，觀待者乃成就其義。

【SAm_109】
Artha 由語句所限定，由 vidhi（簡別）或 vāraṇa（遮），或由其他方式；若不限定，則必無差別。

【SAm_110】
言語指示「彼、此物、唯此」，若不爾，則如何以真實或虛妄之語，指示 tattva 之義？

【SAm_111】
Vāk（言）之 svabhāva，於排除他 vāk 之義，不受束縛；又說其自義之 sāmānya（共相），如 khapuṣpa（空華）般之 vācya（所說）。

【SAm_112】
若 sāmānya-vāk（共相之語）於 viśeṣa（自相）之中，則彼 śabda-artha（聲義）為虛妄；為達所期之 viśeṣa，kāra（因）乃真實之相。

【SAm_113】
於所欲之義之支分 vidheya（所教），與 pratiṣedha（遮）相違者，彼即 ādeya 與 heya 之性，此 syādvāda 之建立。

【SAm_114】
如是此 āpta-mīmāṃsā（可信者審思），為欲利者所作，為 samyag（正）與 mithyā 教義之差別，令得各別證知。
