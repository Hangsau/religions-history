Pariccheda 1

oṃ namaḥ buddhāya |

禮敬善逝（sugata）連同其子及法身（dharmakāya），敬重禮敬一切應供者；
我當依經典略說善逝子戒律之導入。（Bca_1.1）

此中實無前所未說之語，我亦無組織之巧；
故我此心未曾安置於利他之思惟。（Bca_1.2）

先因此文於我增長修習善法之淨信衝動；
其後與我意樂相似者，亦得見此於彼亦為有益。（Bca_1.3）

此人身剎那易壞而極難得，已獲為成辦人天勝義之方便；
若此處不思惟義利，更得如此會遇更從何來？（Bca_1.4）

譬如夜間密雲昏暗中，雷電剎那顯光明；
如是藉佛威力，世間於具福田中偶爾一念慧生。（Bca_1.5）

故善法常力微弱，惡業之力甚為可畏；
若無菩提心（bodhicitta），更以何善能制伏彼？（Bca_1.6）

無量劫中思惟，諸聖者已見此為唯一利：
由安樂增長安樂，能溢無量眾生之群。（Bca_1.7）

欲度生死百種苦，欲除眾生諸災厄，
欲享百種大安樂，菩提心終不應捨。（Bca_1.8）

彼可憐者為生死流轉之繩所繫，剎那間即名為善逝之子；
唯由菩提心已生，方得堪受人天世間之禮敬。（Bca_1.9）

取此不淨之像，化作無價之勝者寶像；
譬如甘露令人迷醉，當堅固執持菩提心之名。（Bca_1.10）

無量智者已詳審，世間唯一商主視為大價值；
善於道路與旅外之行者，當堅固執取菩提心寶。（Bca_1.11）

譬如芭蕉結果後，一切其餘善根悉歸壞滅；
菩提心樹恆結果，不趨壞滅而復生長。（Bca_1.12）

縱造極重惡業，依此剎那間而得度脫；
譬如依勇士之蔭，大怖畏不復沾身。云何愚癡眾生而不依？（Bca_1.13）

劫末大火等大火，菩提心於剎那間能焚諸大惡業；
其功德彌勒（Maitreya）尊者已向善財童子無盡宣說。（Bca_1.14）

此菩提心略說當知有二：
願菩提心（bodhipranidhicitta）與行菩提心（bodhiprasthanacitta）。（Bca_1.15）

譬如欲往與正行二者之差別可了知，
如是智者應當如其次第了知此二之差別。（Bca_1.16）

願菩提心於輪迴（saṃsāra）中亦有廣大果，
然不如行菩提心之福德相續不斷。（Bca_1.17）

從彼以至一切眾生界究竟解脫之間，
以不還轉之心安置此心。（Bca_1.18）

從彼已來，乃至睡眠放逸之時，
福德之流亦無數次，相續如空而流轉。（Bca_1.19）

此如來（tathāgata）於妙臂請問經（Subāhuparipṛcchā）中，
為樂小法之眾生故，自說此為成就之方便。（Bca_1.20）

「我當銷滅眾生之頭苦」，如是思惟，
以無量福德，利益之心便被攝持。（Bca_1.21）

況且欲滅一一眾生之無量苦，
欲為一一眾生成就無量功德。（Bca_1.22）

此等利他之心，於父母、天、仙或梵天（Brahman），
於誰而有如是？（Bca_1.23）

彼等眾生自利之願，於夢中亦未曾生；
況利他之心，更從何生？（Bca_1.24）

yatparārthā

=== 1 | 第一品 ===

為利他而安息者，安息亦非為自利。

世界喜樂之種子、世界痛苦之良藥、心之寶，所積之福德，如何能計量？

僅以宣說利他之語，供養諸佛已更為超勝，何況為一切眾生之一切安樂而發起精進。

懷出離苦之意願，他們竟奔向苦；由貪求樂、由於愚癡，自壞其樂，如怨敵。

對彼等樂少、受多方逼惱者，以昔樂令其滿足，斷除一切苦。

善人摧滅自之愚癡，從何而有？如此之友從何而有？如此之福德從何而有？

對恩已報者尚且受讚，何況不倦之菩薩乎？

少數 satra 之施主，少時少施，半日受人輕蔑度日，尚被眾人敬為善行；何況以無量數眾生、無量時、盡虛空界般無盡、滿一切願者。

如是，任何人於 sattra 主、勝者之子之自心，生染污者，由染污之數量計，彼當住地獄經劫——護者如此說。

復次，其心趣清淨者，較彼福報更為增上；以由大力故，於勝者子之惡業不熟，善則無勤而成。

我禮彼等之身，彼處生妙心寶；彼處雖作損害，結果為樂；我歸依彼作樂者。

=== 2 | 第二品 ===

所有之花、所有之果、所有之藥類、世間所有之寶、清淨悅意之水；寶山、餘寂靜可意之林苑、花蔓莊嚴、妙果垂枝之樹；天等界中香、如意寶樹、蓮花莊嚴之湖、鴻雁之音極悅意；自然生之穀類等、或餘供莊嚴、遍虛空界如量一切，皆不攝為己有。

我以慧奉獻諸佛及其諸子；最上應供、具大悲者，願慈我而納受此。

我無福德、大貧窮，無餘物可供養；是故為我故，具利他之念諸尊，願以自力納受此。

我以一切諸物獻諸勝者及其諸子；最上眾生啊，請納受於汝等為奴之事，我以信受持。

由汝等納受我，我得無畏，當利眾生；先當超此罪，不更造罪。

寶光明柱悅意處、珠輝帳幔、清淨晶瑩水晶樓閣、香潔浴室；我以多充滿可意香水花之大寶瓶，為如來及其子沐浴，伴有歌樂。

我以極香浣淨無等之衣拭彼等之身，然後獻以色妙香妙之上衣；以柔軟細滑種種莊嚴之天衣、上妙莊嚴……

=== 2.13 ===

sarvatrisāhasravisārigandhair gandhottamaistānanulepayāmi
sūttaptasūnmṛṣṭasudhautahemaprabhojjvalānsarvamunīndrakāyān //

以三千大千世界種種最上妙香塗香，
我塗彼精磨清淨金光朗耀身，
熾然照耀諸大牟尼人王身，
以最勝香塗薰供奉於彼等。

=== 2.14 ===

maṇḍāravendīvaramallikādyaiḥ sarvaiḥ sugandhaiḥ kusumairmanojñaiḥ
abhyarcayāmyarcyatamānmunīndrān sragbhiśca saṃsthānamanoramābhiḥ //

曼陀羅、優鉢羅、茉莉等一切芬馥悅意之妙花，
及以華鬘美麗莊嚴之具，
敬奉供養諸最應敬之大牟尼長老。

=== 2.15 ===

sphītasphuradgandhamanoramaiśca tāndhūpameghairupadhūpayāmi
bhaujyaiśca svādyairvividhaiśca peyais tebhyo nividyaṃ ca nivedayāmi //

廣布芬芳悅意之香雲，
我以香煙騰涌而薰彼，
塗香甘美種種諸飲膳，
沐浴之品我亦奉於彼。

=== 2.16 ===

ratnapradīpāṃśca nivedayāmi suvarṇapadmeṣu niviṣṭapaṅkvīn
gandhopalipteṣu ca kuṭṭimeṣu kirāmi puṣpaprakarānmanojñān //

我以珍寶燈明而奉施，
置於黃金蓮花之上，
於塗香之妙高座上，
散種種悅意之妙花。

=== 2.17 ===

pralambamuktāmaṇihāraśobhān ābhāsvarāndigmukhamaṇḍanāṃstān
vimānameghān stutigītaramyān maitrīmayebhyo 'pi nivedayāmi //

垂懸珍珠瓔珞莊嚴之具，
光明照耀天宮莊嚴妙雲，
讚詠歌詠悅意之宮雲中，
我亦奉於慈悲喜捨諸聖前。

=== 2.18 ===

suvarṇadaṇḍaiḥ kamanīyarūpaiḥ saṃsaktamuktāni samucchritāni
pradhārayāmyeṣa mahāmunīnāṃ ratnātapatrāṇyatiśobhanāni //

黃金為柄悅意之形相，
繫以明珠高擎令起，
我以是而持奉諸大牟尼之，
極妙珍寶傘蓋莊嚴。

=== 2 | 供養雲海 ===

=== 2.19 ===

ataḥ paraṃ pritaṣṭhantāṃ pūjāmeghā manoramāḥ
tūryasaṅgītimeghāśca sarvasattvapraharṣaṇāḥ //

願此外悅意供養之雲，
及伎樂歌詠之妙雲，
恆為一切眾生之歡喜。

=== 2.20 ===

sarvasaddharmaratneṣu caityeṣu pratimāsu ca
puṣparatnādivarṣāśca pravarttantāṃ nirantaram //

於一切正法寶塔聖像之前，
願花雨珍寶等諸妙雲，
無間而恒流轉不息。

=== 2.21 ===

mañjughoṣaprabhṛtayaḥ pūjayanti yathā jinān
tathā tathāgatānnāthān saputrānpūjayāmyaham //

妙音等諸尊者敬奉諸佛（Tathāgata）如是，
諸如來、諸怙主及其弟子，
我亦如是敬奉以諸供養。

=== 2.22 ===

svarāṅgasāgaraiḥ stotraiḥ staumi cāhaṃ guṇodadhīn
stutisaṅgītimeghāśca saṃbhavantveṣvananyathā //

以天音海諸讚詠之辭，
我讚彼功德大海，
讚詠歌詠之妙雲，
願於此中無間而集。

=== 2.23 ===

sarvakṣetrāṇusaṃkhyaiśca praṇāmaiḥ praṇamāmyahaṃ
sarvatrādhvagatānbuddhān sahadharmagaṇottamān //

以等於一切佛國土塵數之禮敬，
我禮遍遊十方之諸佛（Buddha），
及諸上妙法會大眾。

我敬禮諸一切塔廟，

=== 4 | 懺悔罪業 ===

=== 2.27 ===

anādimati saṃsāre janmanyatraiva vā punaḥ
yanmayā paśunā pāpaṃ kṛtaṃ kāritameva vā //

於無始生死輪迴之中，
無論何生或復他生，
凡我此如畜生者所造罪，
或令我造作之諸惡業。

=== 2.28 ===

yaccānumoditaṃ kiṃcid ātmaghātāya mohataḥ
tadatyayaṃ deśayāmi paścāttāpena tāpitaḥ //

或以愚痴所使為自害故而隨喜，
此一切過失事後悔熱所逼，
我發露懺此一切。

=== 2.29 ===

ratnatraye 'pakāro yo mātāpitṛṣu vā mayā
guruṣvanyeṣu vā kṣepāt kāyavāgbuddhibhiḥ kṛtaḥ //

對三寶之侵損過失，
或對父母之過失，
對師長及諸他人，
以身口意所造之罪。

=== 2.30 ===

anekadoṣaduṣṭena mayā pāpena nāyakāḥ
yatkṛtaṃ dāruṇaṃ pāpaṃ tatsarvaṃ deśayāmyaham //

具多染污諸過失者——我，
所作種種兇狠之惡業，
諸怙主！一切我皆發露而懺。

=== 2.31 ===

kathaṃ ca niḥsarāmyasmān nityodvego 'smi nāyakāḥ
mā bhūnme mṛtyuracirād akṣīṇe pāpasaṃcaye //

我將如何從此得解脫？
諸怙主！我常懷憂慮。
願我罪業未盡消前，
死亡勿臨！

=== 2.32 ===

kathaṃ ca niḥsarāmyasmāt paritrāyata satvaraṃ
mā mamākṣīṇapāpasya maraṇaṃ śīghrameṣyati //

我將如何從此得解脫？
諸聖者！願速救拔。
願我罪未消盡之死，
勿速降臨我身！

=== 2.33 ===

kṛtākṛtāparīkṣo 'yaṃ mṛtyurviśrambhaghātakaḥ
svasthāsvasthairaviśvāsya ākasmikamahāśaniḥ //

此死亡作與不作皆不可測，
是破除信賴之殺手，
不論康健與否皆不可恃，
猶如突起之大雷霹靂。

=== 2.34 ===

priyāpriyanimittena pāpaṃ kṛtamanekadhā
sarvamutsṛjya gantavyam iti na jñātamīdṛśam //

因愛憎所使所造諸惡業，
已造無量無數。
「一切皆應棄捨而去」，
如此甚深之理我未曾悟。

=== 2.35 ===

tattatsmaraṇatāṃ yāti yadyadvastvanubhūyate
svapnānubhūtavatsarvaṃ gataṃ na punarīkṣyate //

彼彼事之所以入於記憶，
乃因所歷境物，
皆如夢中所經歷，
已逝則不可重見。

=== 2.36 ===

apriyā na bhaviṣyanti priyo me na bhaviṣyati
ahaṃ ca na bhaviṣyāmi sarvaṃ ca na bhaviṣyati //

不喜者將不復存在，
喜者亦將不復存在，
我亦將不復存在，
一切悉將不復存在。

=== 2.37 ===

ihaiva tiṣṭhatastāvad gatā naike priyāpriyāḥ
tannimittaṃ tu yatpāpaṃ tatsthitaṃ ghoramagrataḥ //

今雖猶在此居住，
愛憎已有多人逝去。
彼等所造之罪業，
於我之前兇猛聳立。

=== 2.38 ===

evamāgantuko 'smīti na mayā pratyavekṣitaṃ
mohānunayavidvaiṣaiḥ kṛtaṃ pāpamanekadhā //

「我僅是此過客」，
我未曾如是省察。
由愚痴、貪、瞋所造惡業，
我已造下無數。

=== 2.39 ===

rātrindivamaviśrāmam āyuṣo vardhate vyayaḥ
āyasya cāgamo nāsti na mariṣyāmi kiṃ nvaham //

日夜無間，
壽命之損耗唯增長。
衰老必然到來，
我豈不將死？

Bca_2.41

縱於親屬環繞之中，唯我獨受此要害割截之痛。

Bca_2.42

為 Yama（閻摩）使者所執之時，親屬何在？善友何在？唯福德是彼時之救護，而我未曾修習。

Bca_2.43

由貪戀無常之生命，不知此怖畏，我放逸者已積眾罪。nātha（救護者）啊！

Bca_2.44

今日為截肢故被牽而行，亦漸枯槁；渴者目光衰羸，瞻望他界。

Bca_2.45

何況為可怖形貌之 Yama 使者所執，大驚怖熱惱逼切，污穢遍身。

Bca_2.46

以怯懼之目光四方覓求救護，誰當為我脫此大怖畏而作救護？

Bca_2.47

見諸方無有救護，重起迷惑，於彼大怖畏之處我當何為？

Bca_2.48

我今即歸依世間救護者之大威力者，為護世間精勤、能息一切怖畏者。

Bca_2.49

亦歸依彼等所證之 dharma（法），能斷 saṃsāra（輪迴）怖畏，並以至誠歸依 bodhisattva（菩薩）之眾。

Bca_2.50

怖畏戰慄，我為一切吉祥故獻自身，亦復以自身獻於 mañjughoṣa（文殊）。

Bca_2.51

彼以悲愍惶然行動之救護者，我哀聲號哭而怖畏：願彼救我罪人。

Bca_2.52

Ārya Ākāśagarbha（聖虛空藏）、Kṣitigarbha（地藏），及一切大悲，覓求救護，我亦號哭。

Bca_2.53

見已，惡 Yama 使者等恐怖而四方逃竄，彼 vajriṇam（金剛手），我頂禮。

Bca_2.54

違越汝等之教言，今因見怖畏，怖畏故歸依於汝；速滅我怖。

Bca_2.55

雖微疾怖者亦不應違越醫師之教，何況為疾百所逼、又為四百疾（[歧義: 數百種 / 四種又四種]）所逼者。

Bca_2.56

因為僅一疾，若其藥方於諸方不可得，亦令 Jambudvīpa（閻浮提）一切人喪亡。

Bca_2.57

於彼違越一切智醫師、能除一切毒箭者之教言，嗟我極為愚癡！

Bca_2.58

我於其他墮處亦極審慎而立，何況於 yojana（由旬）百千之長時墮處。

Bca_2.59

「今日決不死」之安樂想於我不應理；其時必至，當我已不存。

=== 8 | 守護心 5.5–5.35 ===

「波羅蜜多等唯是心」——真實語者說。

誰於地獄努力造作諸兵器？
誰造那燒熱的鐵屋？
彼等女人又從何而生？

牟尼宣說：彼一切皆由惡心所生，
故三界之中，除心之外，無有可畏者。

若布施波羅蜜以世界為貧乏，
則前賢如何稱為布施波羅蜜？

「凡夫捨心連同果報而捨一切」，
被說為布施波羅蜜，故彼即是心。

我從未引彼魚等至何處而殺，
得此不害之心，即說為戒波羅蜜。

如虛空數之惡人，我殺之至何時？
殺此瞋心，則一切怨敵已殺。

覆蓋一切大地的皮，從何得來？
以足下皮之量，即能覆蓋此大地。

外境我確實不能遮止，
然我將遮止自心。其他被遮止，於我何用？

即使長期以語身微劣修行，所得之果，
不及一念心所生之梵天等果。

一切長期所作之念誦與苦行，
以散亂微劣心，皆成徒勞——一切智者說。

彼等如虛空般漫遊，欲滅苦而得樂，
卻未修此祕密法要之心。

故我應作：善自安住之守護心。
除守心之戒外，眾多戒於我何用？

如居於動盪中之傷者，謹慎守護傷口；
如是居於惡人中之瑜伽士，應恆守護心之傷口。

畏傷口裂痛者，謹慎守護傷口；
畏群峰相擊者，豈不守護心之傷口？

以此行止而住，雖處惡人、
放逸人群之中，智者瑜伽士不為所動。

願我利養、恭敬、身命皆滅，
其他善根亦滅，唯願心不滅。

我為欲護心者，合掌作此勸請：
以一切方便守護念與正知。

如人為病所惱，不能成辦一切事業；
如是心為念、正知所惱，不能成辦一切事業。

正念於失念心之聞思修中不住，
如水滴不住於有孔之瓶。

雖多聞、有信、精進者，
由失念之過，染著墮罪之垢。

由失念之盜賊隨逐忘念，
所積之福德亦被奪，往趣惡趣。

此煩惱垢之群體，乃尋求入處之盜賊，
得入處即奪善根，殺善趣之命。

故正念不應捨離心之門戶；
雖已去，亦應以念令現前，憶念惡趣之苦。

由恭敬依止善知識，且畏阿闍梨之教誡，
具福德者易生正念。

諸佛與菩薩，於一切處刹那不亂觀察一切；
我恆住於彼等之前。

如是思惟，應住於羞恥、恭敬、畏懼之中，
其念佛亦應屢屢如是生起。

正念若為守護而立於心門，
則正知來而不復去。

先應如是常令此心現前：
我應如木，無有根門，恆時安住。

無果之目光散亂不應為；
應常時向下凝視，如入定然。

=== 9 | 第五品 36–64 偈 ===

因歇息故，偶爾可觀四方；然僅睹影之時，復應審觀來意。

行路之初，為覺察怖畏故，應屢觀於四方；於四方歇時，復如轉身從後視。

或前行，或退後，先審察前與後；如是於一切處，覺知所作已，當行持之。

「以身如是安住」，如是撇開作意，復應內觀：「身今如何安住？」

應竭盡全力審察其心，猶如將心象繫於正思大柱，被繫而不脫。

應屢內觀：「此心今何所趨？」如是於等持之擔，任一剎那亦不應捨。

於怖畏、慶會等緣，若不能者，可隨緣；然於布施之時，戒之忽失已曾明誡。

已覺知而發起之所作，不應再思其餘；當以專一之心，將其事究竟成辦。

如是則一切皆成善巧；否則二者皆失，失念之煩惱亦將如是增長。

於種種雜語紛起之時，於種種喧囂之中，於一切戲論之內，當斷所起之躁動。

見揉泥、斷草、劃線等徒勞之果，憶念如來之教，當怖畏而捨其時。

若欲動身，或欲言語，先觀自心；智者應以穩固而行。

若見自心下劣受困，不應作，不應說，當如木頭安住。

若心驕慢醉傲、伴以譏弄，虛驕過實、邪曲詭詐之時——

若顯揚自高、謗他，帶諍鬥與憤激之時，當如木頭安住。

若我心希求利養、恭敬、名聲，或希求侍從隨侍——我當如木頭安住。

若心欲以粗語損他，或為自利，或欲集眾——我當如木頭安住。

若心不忍、放逸、驚懼，或大膽饒舌，或偏執自宗——我當如木頭安住。

如是察見擾動或徒勞發起之心，勇士應以對治，恆常堅固調伏。

心應堅決、明朗、穩重，具敬具重、具慚具畏、寂靜、專求利他。

觀有情為相互違逆之童稚欲求所逼惱，「此於彼等皆為煩惱生起之事」，由是生起悲心。

我持如是之心，常於無過失之境，隨順自他，猶如化身。

難得之勝妙剎那，屢屢憶念；我持如是之心，不動如須彌山。

被貪肉之鷲所牽，此身從此至彼，何以不作其他反應？

何以自執此羅剎般之心而起驕慢？若此心別於尊，則尊於此有何失？

「癡者！汝何以不取清淨之木偶，而守護塗以不淨之臭穢機器？」

且先以自慧將此皮囊分離；以般若之劍，從骨籠中解出其肉。

復將諸骨分離，觀其內之髓；「此中有何精要？」自當審思。

=== 12 | 忍耐品（續）===

此修習既然難行，
故由習慣忍小苦，
亦應忍大苦。

蠅、蚊、蚤、虻之苦受，
與飢渴，
以及癤瘡等大苦——
為何你不見其意義？

由寒、熱、雨、風、日、病、繫縛與毆擊，
不應行嬌柔，
否則苦會增長。

有些人見自身之血，
尤其驚倒；
有些人見他人之血亦昏去，
此為何故？

此乃由心之堅固，
亦由怯弱而來；
故於苦之戰鬥中，
當克服苦惱。

即於苦中，
智者不應擾動心之澄明——
蓋有與 kleśa（煩惱）之戰，
戰中苦多易得。

胸鎖受擊而能忍者勝敵——
彼等為勝者、勇士，
餘者乃戰場之死屍。

苦之另一功德：
由迫切，狂亂得退；
於輪迴有情起 kāruṇya（悲愍），
畏 pāpa（罪），於征服起勝欲。

對膽汁等，
縱其為大苦之因，我亦不起瞋；
對有情起瞋何益？
彼等亦為緣所瞋動。

如此之絞痛，
雖不欲亦生；
瞋雖不欲，
亦以強力生起。

人不經思惟「我將瞋」而起瞋，
乃自然而起；
思惟「將生」而瞋反不生。

凡此一切過咎，
種種諸罪，
皆由因緣之力；
自在實不可得。

非於因緣集聚，
有「我將生」之念；
亦非於所生者，
有「我已被生」之念。

主要所欲者，
被計執為我——
彼無「我成為彼」之思惟而起。

未生者則無，
彼時誰能為之？
又因攀緣外境，
亦不能制止。

自我永恆、無覺、如虛空，
明然無作；
即於餘緣和合之時，
無變者有何作為？

於過去作業時所作，
與其作業有何繫屬？
此中何者為其根本？

如是一切隨他轉，
彼隨者亦非自在；
如機關之於所作事，
如是，何處起瞋？

制止亦不相應如此：
「誰制止何？」
應理者即 pratītyasamutpāda（緣起），
故苦可寂滅。

故無論見敵或友行非法，
思惟「此乃其如是之緣」，
應當快樂。

若成就唯由偶然，
則一切有情皆當得之——
無人願受苦，
然苦不因人不願而不生。

由放逸，人以荊棘等自害，
以碎鉢等、以瞋、以貪他人之婦等。

亦由墮坑、服毒等，
及由造惡業，
有人自害其身。

若如是，由煩惱之制，
彼等乃至殺自身之親愛，
何能對彼防其害他人之身？

此等由煩惱而狂，
從事於自害時，
不僅無悲，
瞋何以起？

若愚者之害他乃其本性，
對彼起瞋於我不應理，
如對火之自燃。

然此過失乃後起——
有情本性溫柔；
如不相應之瞋乃妄，
如虛空之幻象。

若捨其本（杖等），
而瞋於驅使者，
彼為瞋所驅；
願我之瞋在於瞋。

我昔亦對有情造如是之苦，
故對有情之害者，
理所應然——

此兵器與我身，
二者皆為苦之因；
因此兵器、我身——

=== 6 | 第六品 忍辱 ===

**6.43**　這瘤狀之相被我這盲目貪欲者把握，不能承受打擊；於彼苦中，何處會生瞋？

**6.44**　我不欲苦卻欲苦因，愚哉！當自招之苦來時，何故向別處發怒？

**6.45**　如利刀之林、如地獄眾生所受，唯由我業所生；如是之苦，何處可瞋？

**6.46**　那些害我者，唯由我業力催生，他們將下地獄；豈非我自害自？

**6.47**　依他們，我的罪大量滅除（忍時）；依我，他們卻去地獄受長久之苦。

**6.48**　我才是害己者，他們反是我的助益者；為何顛倒過來，奸詐之心竟暴怒？

**6.49**　願我具心中之德，不下地獄；若我已自護此身，此間還有何禍可至？

**6.50**　若我反成（報）害者，彼等仍未得護；我的修持亦減，故（真）苦行者（之德）已失。

**6.51**　心無形相故，任何人於任何處皆不能殺；唯因執著於身，故受身苦。

**6.52**　穢語、粗言、惡名等，這些不能傷身；心啊！為何發怒？

**6.53**　他人對我的善意，難道會吞噬我？不論此生或他世，那（瞋以滅之者）為我所不喜。

**6.54**　若那（瞋）為我所不喜，因它能礙其他得益；我的得益必於此盡滅，罪業卻必恆存。

**6.55**　寧願今日即死，不虛偽地苟活長久；因為雖久安住，死苦依然是死苦。

**6.56**　夢中享百年之樂而醒者，與另一享短暫之樂而醒者。

**6.57**　兩者醒時，樂皆歸無；此即長命者與短命者於死時之喻。

**6.58**　縱得多獲，縱久享樂；我將空手赤身而去，如被洗劫者。

**6.59**　若我為滅罪增福而活；那為求利而瞋者，豈非減福增罪？

**6.60**　我為何而活者，若此已失，則此純造惡之生，復有何用？

**6.61**　若說瞋能滅毀我之人，那同理於加惡名於他人者，何以瞋不（亦）生？

**6.62**　於不可愛者，忍隨他轉；於起苦者，忍隨苦轉。然對毀謗者之忍，則非此二者。

**6.63**　於像、塔、破正法者、辱罵者，我不應起瞋；佛等於此無惱故。

**6.64**　於師、父母等之所愛遭侵害時，當如前見因緣生起之理，制伏瞋恚。

**6.65**　有情之苦，由有覺與無覺者決定；於有覺者中見此苦已，故當忍此苦。

**6.66**　由癡故有犯者，由癡故亦有瞋者；於愛欲中，誰無過？我們說，誰是無過者？

**6.67**　為何昔造此業，使今為他人所逼？一切隨業，於此（業報之）中，我豈能別作？

**6.68**　如是知已，我當勤於修善，使一切眾生彼此皆具慈心。

**6.69**　如家屋失火時，火延至他屋；於柴草等可燃處，即拉出移走。

**6.70**　如是心若因執著被瞋火所焚，當下即應捨之——恐其焚燒善根與自。

**6.71**　若斷可殺（之物）而解脫，豈有非福善？若解脫人苦與地獄（之繫），豈有非福善？

故雖由汝願已遂，於彼苦中汝有何樂？
縱如是或有其利，
復有何者更為無義？

亦非我身之安樂。

[6.91]
智者之自利如此而已。
知自利者，欲意安樂，當親近酒、賭等事。

[6.92]
名聲奪財，財復殺身；

[6.93]
如童稚於破茅屋中哀號，
於讚名失時，我心亦爾。

[6.94]
聲無心故，彼不能讚我；
他人實喜於我——此方為歡喜之因。

以助 bodhicaryā（菩提行）故，我敵是可欣求。

=== 6.108 ===

我由彼故已得此 kṣamā（忍）果，
此應先施於彼，以彼為前忍故。

=== 6.109 ===

彼無 kṣamā（忍）成辦意樂，故非應供，
若不應供，敵亦然；
雖為成辦因，saddharma（正法）云何應供？

=== 6.110 ===

彼意樂在於損，若敵不應供，
我云何當忍？如醫為利而說活命。

=== 6.111 ===

故由其惡意樂，kṣamā（忍）由緣而生，
是故彼為忍因，於我應供如 saddharma（正法）。

=== 6.112 ===

「sattva（眾生）田、jina（勝者）田」，
是故 munīndra（大仙）所宣說，
供養彼等，眾生已達 saṃpat（成就）彼岸。

=== 6.113 ===

於 sattva（眾生）與 jina（勝者），於 buddh-dharma（佛法）生中平等，
於 jina（勝者）敬重而不於 sattva（眾生），此何次第？

=== 6.114 ===

意樂之 māhātmya（尊貴）非自性，乃由業故，
由此 sattva（眾生）māhātmya（尊貴）平等，是故彼等平等。

=== 6.115 ===

由 maitrī（慈）意樂故可尊者，即 sattva（眾生）māhātmya（尊貴），
由 buddhaprasāda（信敬於佛）生 puṇya（福）者，即 buddha-māhātmya（佛尊貴）。

athā yadyapy asaṃvedyam anyad duḥkhaṃ mayātmanā
tathāpi tasya tad duḥkhaṃ ātmasnehena duḥsaham //

然而雖他人之苦 我自身不能感受
然以其愛著自我 彼苦亦難堪忍

mayānyaduḥkhaṃ hantavyaṃ duḥkhatvād ātmaduḥkhavat
anugrāhyā mayānye 'pi sattvatvād ātmasattvavat //

他人之苦我應除 因其為苦 如己苦
他人我亦應救護 因其有情 如己有情

yadā mama pareṣāṃ ca tulyam eva sukhaṃ priyam
tadātmanaḥ ko viśeṣo yenātraiva sukhodyamaḥ //

當我與他人之樂 喜愛全然相等
對自身有何差別 使唯於此勤取樂

yadā mama pareṣāṃ ca bhayaṃ duḥkhaṃ ca na priyam
tadātmanaḥ ko viśeṣo yat taṃ rakṣāmi netaram //

當我與他人之畏 及苦皆非所悅
對自身有何差別 令我唯護自不護他

tad duḥkhena na me bādhety ato yadi na rakṣyate
nāgāmikāya duḥkhān me bādhā tat kena rakṣyate //

若言此苦不惱我 故不護此
則來世之苦不惱我 以何理由而護

ahameva tadāpīti mithyeyaṃ pratikalpanā
anya eva mṛto yasmād anya eva prajāyate //

「那仍是我」此分別 純屬虛妄
因甲死之時 唯有乙方受生

yadi yasyaiva yad duḥkhaṃ rakṣyaṃ tasyaiva tan matam
pādaduḥkhaṃ na hastasya kasmāt tat tena rakṣyate //

若執誰之苦 即應護彼自身
則足之苦非手之苦 何故以手而護足

ayuktam api ced etad ahaṃkārāt pravartate
yadayuktaṃ nivartyaṃ tat svam anyacca yathābalam //

即便此不合理 由我慢而轉起
不合理者應止此 如止餘者隨其力

saṃtānaḥ samudāyaśca paṅkti senādivan mṛṣā
yasya duḥkhaṃ sa nāsty asmāt kasya tat svaṃ bhaviṣyati //

相續與蘊聚 亦如軍列等虛妄
誰亦無彼 故何者將為其自性苦

asvāmikāni duḥkhāni sarvāṇy evāviśeṣataḥ
duḥkhatvādeva vāryāṇi niyamastatra kiṃkṛtaḥ //

一切苦皆無主 無有差別
唯因是苦故 即應遮止 何須另立規

duḥkhaṃ kasmān nivāryaṃ cet sarveṣām avivādataḥ
vāryaṃ cet sarvam api evaṃ na ced ātmani sarvavat //

若不遮苦 則於一切無諍
若遮止 則一切亦爾 若非 則於己亦如一切

kṛpayā bahu duḥkhaṃ cet kasmād utpadyate balāt
jagad duḥkhaṃ nirūpya idaṃ kṛpāduḥkhaṃ kathaṃ bahu //

若悲心生多苦 為何強力生起
已審察世間苦 悲心之苦何言多

bahūnām ekaduḥkhena yadi duḥkhaṃ vigacchati
utpādyam eva tad duḥkhaṃ sadayena parātmanoḥ //

若以一己之苦 能消多數之苦
悲憫他者之人 唯應生起此苦

ataḥ supuṣpacandreṇa jānatāpi nṛpāpadam
ātmaduḥkhaṃ na nihataṃ bahūnāṃ duḥkhināṃ vyayāt //

故具美花月菩薩 雖知王位之苦
為眾多苦人所損 自身之苦未斷除

evaṃ bhāvitasaṃtānāḥ paraduḥkhasamapriyāḥ
avīcim avagāhante haṃsāḥ padmavanaṃ yathā //

如是修習相續已 等同欣樂他苦者

mucyamāneṣu sattveṣu ye te prāmodyasāgarāḥ
tair eva nanu paryāptaṃ mokṣeṇārasikena kim //

於有情解脫時 彼等為喜悅海
唯彼已足 何需無貪求於解脫

ataḥ parārthaṃ kṛtvā api na mado na ca vismayaḥ
na vipākaphalākāṅkṣā parārthaikāntatṛṣṇayā //

故為他義而行 亦無慢亦無驚
不求果報之果 唯一味希求他義

tasmād yathāntaśo 'varṇād ātmānaṃ gopayāmy aham
rakṣācittaṃ dayācittaṃ karomi evaṃ pareṣv api //

故如內外下劣族姓 我護自身
如是守護心與悲心 亦應於他人作

abhyāsād anyadīyeṣu śukraśoṇitabinduṣu
bhavaty aham iti jñānam asaty api hi vastuni //

由於串習 於他人精血滴中
亦有「此為我」之智 雖於事為無

tathā kāyo 'nyadīyo 'pi kim ātmeti na gṛhyate
paratvaṃ tu svakāyasya sthitam eva na duṣkaram //

願十方皆悅意，以 kalpadrumodyāna（如意樹苑）莊嚴；佛、pratyekabuddha（緣覺）、bodhisattva（菩薩）充滿，dharma-dhvani（法音）美妙。

願處處大地平坦如掌心，無砂礫等，柔軟皆如 vaidūrya（琉璃）。

願 bodhisattva 大眾會以自莊嚴遍坐十方，莊嚴大地。

願一切有情常聞 dharma-dhvani（法音）不息，自飛鳥、樹林、光線乃至虛空皆出。

願常得與佛、pratyekabuddha、bodhisattva 聚會，以無量供養雲海，敬禮 jagadguru（世間導師）。

=== 3 | 第十章 迴向品（38-45 願世法興盛）===

願天時降雨應時，農產豐盛；世間興盛，君王正法。

願藥物皆具威力，mantra（真言）於持誦者皆得成就；願 ḍākinī（荼吉尼）、rākṣasa（羅剎）等皆具悲心。

願無有情痛苦，無有造惡，無有病患，無有卑下，無有輕蔑，亦無愁惱。

願寺院安固，常浸於誦讀自修；願 saṃgha（僧團）常集，僧事成就。

願 bhikṣu（比丘）得 viveka（寂靜），樂於 śikṣā（修學），心住正業，遠離一切散亂而入定。

願 bhikṣuṇī（比丘尼）得具利養，無諍無倦；願一切 pravrajita（出家者）持戒無缺。

願破戒者常懷慚愧，樂於滅惡；於 sugata（善逝）法得利，於中持戒無缺。

願 paṇḍita（智者）受敬，paiṇḍapātika（乞食者）得利；願彼等 saṃtāna（種姓）清淨，kīrti（聲名）遍十方。

=== 4 | 第十章 迴向品（46-51 願三乘與自成就）===

願不經 āpāyika（惡道）苦、不經苦行，唯以一天身，證得世間 buddhattva（佛位）。

願一切眾生以種種供養敬禮一切諸佛；願彼等以 acintya（難思）佛樂，倍增安樂。

願 bodhisattva 之願皆得成就，饒益世間；諸 nātha（怙主）所念，皆令眾生圓滿。

願 pratyekabuddha、śrāvaka（聲聞）皆得安樂，常受天、人、asura（阿修羅）恭敬供養。

願我常得 jātismaratvam（宿命通）與 pravrajyām（出家）身，乃至 pramuditā bhūmim（歡喜地），皆由 mañjughoṣa（文殊師利）加持。

願我依隨所得座，以具力之身，修習 viveka（寂靜）之資具。

=== 33 | 第十品 迴向品 終 ===

願於一切生中證得。

若我欲見時、或欲問事時，
願見 Mañju-nātha（文殊），無有障礙。

Mañjuśrī（文殊師利）所行，遍至十方虛空邊際，
為成辦一切有情義利者，願我亦如是行。

虛空存住之時、世界存住之時，
願我亦如是存住，摧滅世間諸苦。

世間之一切苦，願皆於我成熟；
依諸菩薩（bodhisattva）一切功德，願世皆得安樂。

為世間苦之良藥、為一切圓滿安樂之生源，
具足利養恭敬，願此教法（śāsana）長久住世。

我敬禮 Mañjughoṣa（文殊），以其加持故我心善妙；
我讚 kalyāṇamitra（善知識），以其加持故功德增長。

《入菩薩行論》（Bodhicaryāvatāra）第十品 迴向品（pariṇāmanā）終。
