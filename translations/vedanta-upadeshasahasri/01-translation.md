=== 1 | sa_zaMkara-upadezasAhasrI ===

Śaṅkara：Upadeśasāhasrī

【1.1】
禮敬覺知者（caitanya）、遍在者、一切者、眾生之內居者，
禮敬越一切所緣者、遍知者（sarvavid）。

【1.2】
婚前火（dārāgni）之儀軌（kriyā）全部完成之後，
此吠陀（Veda）始宣說梵智（brahmavidyā）。

【1.3】
業（karma）為身之結合（dehayoga）之故而起；
於恆處（dhruva）者生貪（rāga）與瞋（dveṣa）；
由貪瞋復生業。

【1.4】
由此生法（dharma）與非法（adharma）；
由此再生身之結合，
如是生死輪（saṃsāra）恆轉不息。

【1.5】
彼生死輪之根本即是無明（ajñāna），
故應破之；
始於梵智，便得究竟善（niḥśreyasa）。

【1.6】
唯智（vidyā）能破無明，
非以違業之力；
若無明未破，貪瞋便不得滅。

【1.7】
貪瞋不滅故，業必生過。
故為究竟利樂計，
於此唯以智為法。

【1.8】
（質難：）然於存活之時，業當恆行；
業於解脫可有助緣之功。

【1.9】
如智之起由勸發（coditatva）無別，
亦以念及除罪（pratyavāya）與憶持（smṛti）之故，
求脫者應行其業。

【1.10】
（答：）然知識決定得果，不依於他，
非如 agniṣṭoma（火祭）雖決定得果而依於他。

【1.11】
如是決定得果之知識，依於恆行之業，
有持此說者，
非與業相違。

【1.12】
然業與知識相違者，以我慢（abhimāna）故；
此中所說之智，乃離變之我慧（ātma-buddhi）。

【1.13】
「我為作者，此屬於我」，
由此我慢，業得流轉；
知識隨真實而轉，
法則隨作者而轉。

【1.14】
智磨滅作者之見，
如智者於鹹地（uṣara）之事 [歧義: 所喻之具體對象有疑]；
彼既獲此真實智，便決意從事於業。

【1.15】
由相違故，
具智之人不能與業並修；
故求脫者應捨業。

【1.16】
對有身者（dehin），因與身等無別之故，
執身等為我、我所為自然之事；
於諸有情，此執由無明起，
便成業教（karma-vidhi）所依之基。

【1.17】
「非此，非此」地（neti neti）排除身等，
唯獨自我（ātman）留存；
為證無別之我，
無明由此已斷。

【1.18】
此已斷之無明，如何依量（pramāṇa）而再生？
蓋於唯獨內我（pratyak ātman）之中，
此無別相實為虛妄。

【1.19】
若不復生，「作者」、「受者」之想如何起？
於「我是真實有」（sad asmi）之現識中，
故知識為其助緣。

【1.20】
所說之「徹底棄捨」（atyarecayat）為捨置（nyāsa），
實依聖教（śruti）而立；
於雄健者（vājin）而言，
從業之滅、意之斷，
如是為足（etāvad iti）。

【1.21】
不死（amṛtatva）已由聖教所說；
故求脫者應捨業；
已說「如 agniṣṭoma」之義，
今於此中當宣說如下。

【1.22】
業非由一作者便能成就，
其果亦有多種；
故以與業相反者比於智，
所引之喻（dṛṣṭānta）實不相當。

【1.23】
如耕作等為求果故，
需輔助之業；
agniṣṭoma 亦有所待，
知識更有何所待？

【1.24】
退失（pratyavāya）唯屬於我慢者；
若以我慢為其目的，
此即在「知」之中，
非「證我者」（ātma-vedin）之事。

【1.25】
故為破無明、斷生死輪，
此名 prārabdhopaniṣat（始業奧義書）之書，
宣說梵智之法。

【1.26】
「sa」之前加「upaniṣad」之語，
於何處皆得為奧義書；
又由遲緩（mandīkaraṇa）之理，
亦由摧破胎藏（garbha）等故。

=== 1 | 意識品（結）===

「（閉）是故意識品終。」

=== 2 | 遮止品 ===

由於不能遮止，故僅以「非此、非此」（neti neti）為結論；
如此確實證得：「此非我，此非我」。

此智、此由自我生起者，屬言語初始所及之境；
由於它是被遮止的自我所生，故不再被確立。

不破前知，則後知不生；
觀者唯一、自成、由於為果，不被破。

超此染有憂、痴等之林；
如犍陀羅人從林出而歸於己，
彼證得自己的自我。

「（閉）是故遮止品終。」

=== 3 | 自在主品 ===

若自在主（īśvara）是非我，則不應持「彼是我」；
若自我是自在主，「我是」（asmīti）此智遣除他者。

若視非粗等德性為自我或他者，
此若不可知，則彼等何用？
然於自我性，則遣除他智。

為遮虛妄執著，故應取非粗等；
若為遮於他處，述說空性即是。

對欲知內在自我者，若於他處求此，
彼言「無息、無心、清淨」，此語無義。

「（閉）是故自在主品終。」

=== 4 | 我慢品 ===

以我慢（ahaṃ-pratyaya）之種、由我慢而立，
以無我之火已燒，業如何萌發？

若如所見般生起，彼非別業而被視為；
於其遮止時，彼如何存？吾人問此，願為說。

由於身等發起之力，於汝有實在對境之智，
彼智勝而作果，業盡時智生。

於已發起（ārabdha）業之果，享與智此二無違，
適合；然於他者則性質有異。

如身我智之智，為破身我智者；
彼若於自我為此，縱不欲亦解脫。

「（閉）是故我慢品終。」

=== 5 | 妄想疑品 ===

如 Udaṅka 牟尼因畏業壞而不取甘露，
眾生之不取自我智亦爾。

住於覺者視自我似動、似禪定；
如乘船者視樹如動，輪迴之錯亂亦爾。

如舟中人視山逆行，
自我之流轉亦爾——彼似禪定，經云如是。

由意識（caitanya）映像周遍故，智（bodha）乃生起；
覺中之聲等顯現，世由彼迷惑。

意識顯現所成之我慢、與其相應者；
於捨此分時，彼岸之彼證不成。

「（閉）是故妄想疑品終。」

=== 6 | 差別相品 ===

以捨之手切斷，自己之自我不被區別；
同樣，以一切所留，種種區別。

故以捨之手，一切差別相（viśeṣaṇa）等同；
由於非我性故，知者從一切差別相解脫。

此一切差別相如好裝飾；
故於自我中，無明滅時，知者一切成非真。

唯自我即知者，常應取，捨所知唯；
「我」（ahaṃ）亦取者，彼如已離之肢，實同。

凡此份者，他自有別之差別相；
於差別相滅處，知者成就，如不思議之師。

此份之「我」（ahaṃ）應捨，智者不執為我；
教誨者云：「我即是梵」（ahaṃ brahma asmi）...

=== 1 | 第六章 識了品（終） ===

…ṃśo bhūtapūrvagater bhavet // 6.6 //

=== 2 | 第七章 覺照為所乘品 ===

一切可見皆覺照所乘，於此於彼；
我故即是至高 Brahman（梵，遍在實在），遍知、遍入。 // 7.1 //

如為自我與覺照運行之見證者，於外亦然；
無能遮、無能奪，是故我為超越。 // 7.2 //

自我無變、無染、非由元素所成；
以為一切覺照之見證故，如覺照而有微感。 // 7.3 //

如紅等諸色與陽光於寶珠之中映現；
如是萬有由我映照，如陽光之由我。 // 7.4 //

若覺照中有可見之物，覺照存時則無顛倒；
以見者恆為見者之故，無 dvaita（二相）。 // 7.5 //

由無分別故，覺照不能了知至高分別；
由分別故，於至高中無別，自體亦不可得。 // 7.6 //

=== 3 | 第八章 意識自性品 ===

依我之見，意識本即其自相；
汝以味（聲色等塵）等相接，皆由無明所驅；
故汝所作於我無果可生，以離一切差別之故。 // 8.1 //

於此捨離幻化（māyā）所作，當息顛倒思惟；
我即是至高 Brahman，恆為解脫者，正如無生、唯一、離於二相。 // 8.2 //

我於諸有情恆為平等，唯我獨存；
如虛空，遍入、不滅、寂靜；
無間、無分、無作、至極；
是故汝之所獻於我無果可生。 // 8.3 //

我即是我，別無他求；
如是於一切中我皆無所繫；
以我為無繫之相故，汝所作於我無干，亦以不二故。 // 8.4 //

既念眾生執著於因與果，我為令其解脫故，
施設此對話，以開顯自相真實之義。 // 8.5 //

若人思惟此對話，即從無明大怖中得解脫；
彼離欲之人，常行無憂、平等、自知、得安樂。 // 8.6 //

=== 4 | 第九章 微細性品 ===

所知之中，愈趨微細，超越香等；
於內自我之究竟處，前前漸除。 // 9.1 //

身體之地，於外可量之量；
微妙之質，亦應如是盡知。 // 9.2 //

如風等生起之前為遍一切之空；
我恆為一、是遍、是 cinmātra（純粹意識）、遍入、無二。 // 9.3 //

自梵天乃至不動之諸有情，皆我之城；
欲、瞋等諸過患，從何處生於我？ // 9.4 //

常住於一切有情之主宰，從不為元素過患所染；
如童子視青天為穢染，有人亦如是邪見於我。 // 9.5 //

以我意識所照明故，常於一切有情之心智中盈滿；
一切有情皆為我——遍知、離過——所充盈。 // 9.6 //

可由認知所識、生滅之智，如夢中所識；
智乃恆常、離對境，故無 dvaita。 // 9.7 //

知者之智，說為恆常；於熟眠中，餘皆空故；
覺時之智，起於無明；其可執取者，當知是虛妄。 // 9.8 //

如具色等者之見等作用，於其無自性故不可得；
如是遍者之識作用，亦不可得。 // 9.9 //

見之自性如虛空，為至極，
一次顯明，無生、唯一、不滅，
無染、遍入、無二，

「此即解脫。om」

dṛśi（見者）畢竟清淨，我是無變異的自性。
於我並無任何對象由自性而有；
前、旁、上、下、一切處，
圓滿境界、aja（無生），安住於 ātman（我）。

[10.3]
無生、不滅，亦不老、不死，
自光明、遍一切處，我是 advaya（無二）。
既非因、亦非果，極為清淨，
常恒滿足，故此解脫。「om」

[10.4]
深睡、覺醒、夢境三者的觀照，
於我皆無一物，如自家之迷執。
自他皆以不有故，
我恆是 turīya（第四），dṛg（見）常 advaya（無二）。

[10.5]
身、慧、感官之苦的相續，

此乃真實：我無變異，

亦無 varṇa（種姓）、āśrama（法期）、身之差別。

無始、無德，故我無業與果。
故我為至上、advaya（無二）。
猶如虛空遍一切而不染，
我雖住於身，以 sūkṣma（微細）故亦爾。

[10.8]
我常於諸有情平等，為 īśvara（自在主），

由 avidyā（無明）、bhāvanā（作意）與業所分別，

jantūnām（有情）之 īkṣitṛtva（觀者性）本自成就，
由此而有「異」。
由 ajñāna（無知）故，此「汝為異」之計執被遮破。

[11.2]
此 amṛtatva（不死）已足，
更無其餘助緣。
「jñāna（智）為此」，如是言，

[11.3]
於一切有情之意行無別而見者，
於我（無變異者）何能有別？

[11.4]
意行與意本身，如夢中所見，
對覺醒之觀照者而言，
於止息中，由二邊不有故，
為 cit-mātra（純覺）、遍一切處、advaya（無二）。

[11.5]
夢由無知故為真，身我見亦爾；
由現量故為量，

=== 11 | 第十一章（續） ===

凡知「我是言說者」者，智、行二者皆失，定為虛無論者，無疑。

dharmā（法）與 adharmā（非法）果報之結合，於 ātman（自我）不可見；由經典知此 Brahmatva（梵性），mokṣa（解脫）以智為因，亦應如是求。

「大王者」等 vāsanā（習氣），夢中所見者之所經驗；故知此外，唯有 dr̥ṣ（觀者）獨存。

如劍自鞘出，離因果之繫，如夢中所見之劍；bodha（覺者）亦然，自具光明。

pratibuddha（已覺）之智者，精勤所達自性之位，經典以「非」等言，為施設之遮遣。

大王與諸世間，於我如夢中所施設；夢中亦然，應知二者——rūpa（色）與 vāsanā 俱是。

以身、相、ātman 為所造，以 vāsanā 為形之 kriyā（行）；ātman 自性故，「非所作」、「非所行」，於我無作亦無行。

由 karma（業）以 ajñāna（無明）為因，無 amṛtatva（不死）之望；mokṣa 以 jñāna（智）為因，不待其餘。

amṛta（不死）且 abhaya（無畏），非苦——ātman 如此，為我所愛；與此相違而有為者，應當棄捨。

itīkṣitṛtvaprakaraṇam ｜ 觀者品終

=== 12 | 第十二章 ===

如住於光明，認取其身與世間；同理，citta（心）為 dr̥ṣ 之映現，便作「我為觀者」之念。

凡世間所見之物，愚人執與 ātman 不二；由是不得 ātman。

如「十」被誤執為「九」，於所見法中，愚凡亦然，非有別途。

「汝作」、「即是汝」——二 pratyaya（分別想）同時，如何能住一巢，互相矛盾？以正理言之。

執身為我者有 duḥkha（苦），然非身之自性故。如睡眠之捐棄，「tat tvam asi（汝即是彼）」為 dr̥ṣ 所說。

dr̥ṣ 之 chāyā（影），依附其上，如鏡中面之影；yogī（瑜伽行者）見此分別想，便作「已見 ātman」之念。

彼與愚人，若別無 pratyaya 於 dr̥ṣ 所知者，yogī 中之最勝者必為此，非其餘，無疑。

vijñātā（能知者）之 vijñātā，由「tat tvam asi」之名，即為 anubhava（證量）；其餘 anubhava 皆虛妄。

於常恒之 dr̥ṣ，「見」與「不見」如何於我可得？是故所欲者，無有餘 anubhava。

日光止於身中之熱，為 dr̥ṣ 所見之 viṣaya（所緣）；同理，住於 sattva（純質）中之，亦為 dr̥ṣ 所見之 viṣaya。

jña（智者）此分已遮遣，如 ākāśa（空），一味無二，常恒解脫，亦復清淨——ahaṃ（我）唯是 Brahman（梵）。

於 vijñātā 別無 vijñātā；故我為至上之 vijñātā，已解脫，於一切有情恆常。

由自身所棄者亦復如是，自身即是未被造作。

=== 3 | SamUpad_I,16.42 ===

由於自性故，無有自相異者能棄離一切；由於無對象性與無分別性，彼為常住故，亦不能被執取。

=== 4 | SamUpad_I,16.43 ===

以自性為一切之義故，常住之自性唯是純一；知解脫者故應與諸方便共棄一切作業。

=== 5 | SamUpad_I,16.44 ===

得自性是至上之得，如是聖教之所成立；得異自性實是失，故應棄離彼無自性。

=== 6 | SamUpad_I,16.45 ===

諸功德平等之破壞，實不合理；以無明等沉眠故，亦不許有其他之因。

=== 7 | SamUpad_I,16.46 ===

若互為他因，則有恆轉，否則無轉；於諸功德或於自性中，諸轉不應有規制。

=== 8 | SamUpad_I,16.47 ===

解脫者與束縛者之差別，及彼等對象相應處皆不合理；求義者與智之關係亦爾，無求者非智，他者亦非。

=== 9 | SamUpad_I,16.48 ===

自性為他故，因神我無變異故，自性為他之義於數論教中亦不成立；於變異中亦不成立。

=== 10 | SamUpad_I,16.49 ===

以自性與神我關係不成立故，彼自性互相為他之義亦不成立；以自性無集起故。

=== 11 | SamUpad_I,16.50 ===

於作業生起時，彼為壞滅性；於智為一境時亦如前；於無因者中，自性之不解脫即墮於過。

=== 12 | SamUpad_I,16.51 ===

如火不以熱性為可顯，如是樂等亦不以智為可顯；以同一巢穴故，於迦旃延等之道中，樂等為不可得。

=== 13 | SamUpad_I,16.52 ===

以樂與其知亦非同時集聚故，以唯意為一緣故，樂之不可得性亦爾。

=== 14 | SamUpad_I,16.53 ===

如是其他亦異類故，不得同時生；諸功德集聚之智，若非由差別性者，則不成立。

=== 15 | SamUpad_I,16.54 ===

由唯以智為差別性故，從記憶中智之不顯亦爾；如是「我已了知樂」之說，以彼由無明為自性故。

=== 16 | SamUpad_I,16.55 ===

以我無變異故，樂等非我之德；若由他者之差別故，則由意之無別異故亦非。

=== 17 | SamUpad_I,16.56 ===

若智至所知位，則可捨離，否則為不可捨之系縛；或同時生亦得，至究竟處亦爾。

=== 18 | SamUpad_I,16.57 ===

以無別異之異狀故，縛不在我中；以不與合故亦無染，由經說「彼是無繫著者」故。

=== 19 | SamUpad_I,16.58 ===

以從微細一境故，「彼不染著」，如經所說；如是則解脫非有，由縛之不存故。

=== 20 | SamUpad_I,16.59 ===

如是則教為無用，不應有覺之迷亂；縛與解脫及彼之壞滅，如所說者，他法則不然。

=== 21 | SamUpad_I,16.60 ===

以覺自性之光照明，於自中認覺為覺；「覺無有餘」即是覺者，此是覺者所行之迷亂。

=== 22 | SamUpad_I,16.61 ===

以覺是我自性故，於彼常住之施設是；此無明是無始，輪迴亦無有餘。

=== 23 | SamUpad_I,16.62 ===

以不可以他法成立故，解脫即是彼之壞滅；執著有別物者，解脫是壞滅。

=== 24 | SamUpad_I,16.63 ===

以彼無變異故，異狀亦不合理；若於變異中，則有覺者性，於彼壞滅如瓶等。

=== 25 | SamUpad_I,16.64 ===

故此迷亂是別有，縛與解脫等之施設是別有；數論、迦旃延、佛教徒之施設，是被彌曼差所破之施設。

=== 26 | SamUpad_I,16.65 ===

以教與理相違故，彼等終不應執；彼等之過失可以百數說，可以千數說。

=== 14 | 第 16-17 章 ===

16.66 智者因此應捨棄其他教派所說，建立堅定之心於 Vedānta（吠檀多）之中。

16.67 以 śraddhā（信）與 bhakti（虔誠）為先，捨棄一切邪曲；於 Vedānta 的真實義中，Vyāsa（廣博仙人）之見亦復如是。

16.63 如是，二元論的施設與無我之說，皆已由正理破除；願 mumukṣu（求解脫者）遠離對他宗的疑惑，堅立於智道之中。

16.69 自証之智極為清淨，與施設相反，是 advaya（不二）；若圓滿得之、確實無疑，便證永恆的寂滅。

16.70 此祕法是至高的歸依；已離過失、斷除我慢者，應恆以正直之心觀察；凡見真實者，無復有自他之見。

16.71 經多生累積功德的人，從無明所造之罪中解脫；了知此至高清淨法，不為諸業所染，譬如虛空。

16.72 此法應恆常授予：心寂靜、已制諸根、斷過失、如教而行、具足功德並恆隨順的求道者。

16.73 觀他身不生我慢，觀至上真實亦復如是；得此極清淨之智，便從一切處解脫。

16.74 此處無有勝過自性之得者；svarūpa（自性）之得不在他處；即使因陀羅的王國，亦不輕率授予未經審察而求自性之得者。

17.1 應知 ātman（我），ātman 至高；除此無他可得；全知、全見、清淨者；敬禮此應知之我。

17.2 以字、句、pramāṇa（量論）知識為燈而照顯吠陀奧義——Brahman（梵）者，我恆常敬禮之。

17.3 其言語如日輪之光，驅除黑暗與垢染；敬禮彼等上師後，我將宣說梵智之決定。

17.4 除 ātman 之得外，無有更殊勝之利可得；吠陀之說與傳承（smārta）的儀軌，皆為此而立。

17.5 凡為自利而求之福樂，終為反覆無常；ātman 之得乃至上，知吠陀者如是宣說，蓋因其常恆。

17.6 彼自得自性故，非從他處得；需依賴他者方得之利，乃由異見而生。

17.7 異見即是 avidyā（無明）；其滅名為解脫；唯由智慧，非由行業，因二者相違。

17.8 業之果無常，由 avidyā 與欲為因；此處，吠陀被視為證得智慧的 pramāṇa。

17.9 因唯以智慧為一義故，彼等知此句為一（內在一致）；ātman 之不二，由句義之悟入而可知。

17.10 由可詮表之別故，其別施設可成立；如是三相——rūpa（相）、nāma（名）、karma（作用）——乃宣說。

17.11 此三（相、名、作用）非實，故互相施設而成；譬如字之音，他處由心聽聞。

17.12 正如所見之形相為心所施設為音聲，如是此一切世界皆為顛倒之智所施設。

17.13 此（世界）非實，故合理者唯是純有純智（saccinmātra），非所施設；吠陀亦即是彼本初者；其餘所知，乃是施設。

17.14 能知者名為智（Veda），夢中一切皆由 māyā（幻）而有；能見者名為眼，能聞者名為耳……

=== 16 | 第十七章 ===

如燈之照明不依待另一盞燈，
意識之自性即是自相，故無他者能如是成就意識。

對象性、變化性、多樣性皆不適用於自性，
自性既非應捨，亦非應取，亦不由他而成。

無外、無內、無老，超越生死衰老者，
凡覺知「我即是自性」者，何從畏懼？

此已於業、種姓等之消除中先說，
由非粗等經教決定：「汝即是彼」。

由捨離前身，種姓等亦滅，
然種姓等屬於身，故彼等亦非我。

「我的」、「我」之執，於身等非我中即是無明，
此由自性之智可斷除，如經中所說之阿修羅事。

十日除穢之儀軌於出家時廢止，
如是於證智之時，種姓等業亦同廢。

愚者隨其所欲而化為相應之祭祀，得所作之果，
然當「視為自性」之欲解脫時，彼即不死（amṛta）。

由自性相之決定，從行為等退出，
自性非所證亦非能證，依經教乃常足滿。

業之果——可生者、不變者、可改作之果，
此處更無他為業之所作，故應連同方便一併捨棄。

彼外物之喜，因苦盡、無常、為自利故，
求真實者當攝此喜於自性，依止於師。

寂靜、具慧、亦解脫、無為、安住於梵者，
依經教，具師者乃知「應知彼」，傳統亦同此說。

具足弟子功德、堪能之弟子，
彼師以梵智之舟，速度自心之黑暗大海。

見、觸、聞、嗅、思、識等諸能，
雖其本性為純識，仍由限定（upādhi）而有差別。

如日恆常照耀，無滅、無生，
遍在、遍觀、清淨，於一切時知一切。

彼（純識）以身安立，視為他者，唯由無明而有，
然其性則以水、月等喻顯示。

見外境已，閉目憶念，捨離彼已，
再睜自性之目，不假程途即得梵。

如是捨離呼吸等三事，度無明大海，
安住自性、無染、清淨、覺悟，自然解脫。

「我無生、無死、不老、無畏，
全知、遍觀、清淨」——覺悟者不再受生。

決定前所說之黑暗種子已不存在，
既無彼，知「梵我一體」者何從受生？

如自乳中取出酥，置於乳中不復為乳，
如是「我」由心等非實中拔出，不復為有身者。

真實、智、無量——超於味等五，
「我即是梵」，無畏，依「不可見等」經教。

語、心、火等之運行，皆因畏（彼）而起，
了知自性即真實法喜者，於任何處不畏。

若安住於超名等之『大全（bhūman）』、自性主權、不二者，
彼自性之知者，更禮何？更無業之所作。

外者為 virāṭ（宇宙人）、Vaiśvānara（遍照），
內憶念為 Prajāpati（生主）；當一切融入，智者說為 avyākṛta（未顯）。

I,18.26 — 自性光明之領悟（upalabdhi），現證而無作之觀者（dṛśi）；直下為一切之內在者、見證者（sākṣī）、意識（cetā）、常住、無屬性、無二。

I,18.27 — 常時臨在其近處者，乃由我慢所造之映象（tadābha）；由此「自我」與「我所」之二現起，即「我」「我所」之執境。

I,18.28 — 以具種姓（jāti）、業（karma）等故，語聲（śabda）乃於我慢作者（ahaṃkṛt）中轉；然語聲不轉於自體之自我中，以其無故。

I,18.29 — 何處有映象（ābhāsa），語聲即住於內觀者（pratyag-dṛśi）之中；然語聲不能直證彼，畢竟如何能宣說彼？

I,18.30 — 以無有具生起等之對象可由語聲表詮；自我映象（ātmābhāsa）即我慢作者，故以「自我」之語稱之。

I,18.31 — 如火把等中之火義，以為他故非直接之義；口之映象（mukhābhāsa）為口以外者，如依鏡之模仿。

I,18.32 — 由映象故，口亦如是，依鏡之相續；我慢作者之自我顯現，被許為如口映象。

I,18.33 — 一者住於如口之位，他者等同自我；二者無別，亦復如是；所謂輪迴者（saṃsārī），乃我慢中之映象。

I,18.34 — 實物之影、由記憶（smṛti）以外之因所生之甘甜等；或為知者之一分、或為變易——其映象之所依者為至上。

I,18.35 — 我慢作者即輪迴者，獨立自主——此某派之說；我慢（ahaṃkāra）等之相續（saṃtāna）為輪迴者，非於隨順（anvaya）中別異。

I,18.36 — 如是說者乃佛教徒（saugata）；其理應予審察；輪迴者之說暫置，今當述本題。

I,18.37 — 鏡中之口映象，非二者任一之相（dharma）；若為二者之一相，則分離時另一亦應有之。

I,18.38 — 以由口之稱說故，若思彼即屬口之相；非也，以口存在時不現，依鏡之續故。

I,18.39 — 若謂為二者共有，亦非，以於二者中亦不現；不可見而有者，可由月日得見羅睺（Rāhu）。

I,18.40 — 羅睺之實有事，先由聖教量（śāstra-pramāṇa）已立；然於影宗（chāyā-pakṣa）中，依前理，其為非實應成。

I,18.41 — 此遮遣乃遮影執（chāyā-ākānti），非證其為非實；以義依他之句，不能說別義。

I,18.42 — 由服熱性物等所生甘甜等之作用，非影之所作，以不可見故；且由水自身之可見可知。

I,18.43 — 如是自我映象之所依，如口映象之所依；由教量與理量，映象之非有可得。

I,18.44 — 觀者非輪迴者，以無變易故；映象亦非，以非實故；我慢作者亦非，以無覺故——則輪迴性屬誰？

I,18.45 — 是故於無分別（aviveka）中，唯無明（avidyā）為輪迴（saṃsāra）；以常住不動之自我（kūṭastha-ātman）而常為自我持有者，如自我在自我中。

I,18.46 — 如繩中之蛇，以繩為自體，於分別前；雖非實有，以常住不動之自我故亦如是。

I,18.47 — 自我，自我映象之所依，以自證為變易故；為樂者、為苦者，即輪迴者，且常住——此某派之說。

I,18.48 — 由不證知自我映象之如實性（yāthātmya），於實相起迷惑；無聖教者（nirāgama）執我慢作者為自我。

I,18.49 — 於彼等輪迴為實輪迴，以能作者（kartṛ）與受用者（bhoktṛ）之相為性；由不證知自我映象之所依，於無分別中輪轉。

=== 21 | I,18.76-100 觀待者、似現與證人 ===

作為作者之觀待者，因「我是常住」之言，亦不應執為常住；
「僅僅是常住」之說為虛妄，於經教亦不相契。

若有可執，經教當不作分別地兩邊同說；
然若要說，則於分別我與你之後說「你即是此」。

「概念依於某處」之過失，前已說；
若「你」依於 adhyakṣa（觀待者），「我」「我如是」之觀待者又如何？

此中應說明那個關係，藉此方可指認「你」；
觀待者若無所作，則見者—所見之關係如何可成？

雖觀待者於無作性，若猶有自性相屬，
「自體之觀待者為我所有」此執於關係之執取，慧不被執。

你若以為「關係之執取是從經教而來」，實非也；
前已說之過失當以三種形態存在，「我所有」之執亦將產生。

常時，無見之 buddhihi（慧）以見者之相顯現時，
其概念亦將如是，如火中迸出之火星。

顯現及其非有，非為觀者之邊限，於凡夫亦無別；
若如是，彼之執於此情境中方合道理。

如此豈不使觀者之轉移如鐵中之火？
「如面之映」之喻，於鏡喻中已被破除。

「黑鐵似現紅色」此已以例說；
所見喻與未見喻之完全等同，畢竟於任何方面皆非。

如是，心若以識之相顯現，
如鏡中面之映，此似現之說起乃屬虛妄。

「心即是識」之說，離經教與理則；
亦將使身同陷此過失，眼等亦然。

若言「且以心為識」，彼非也，因世與出世不相會；
亦非慧為觀者，若（我之）顯現不在心中。

於慧中無「我是常住」之存在，則「你即是此」亦徒然；
若於能了別你、我之慧中，此語方為有意義。

「我所有」「此」二概念當知，「你的」定然無疑；
「我」字指後者，「我」與「我如是」皆爾。

彼等互相待而立主從關係；
能相與所相之關係，於理則當如是被取。

「我」「此」二者，亦正是慧之相分；
如有牛之富人，身亦正為作者「我」之相分。

一切常依於慧，與作者「我」及證人相即；
故一切顯現之知者，常不觸著任何。

如是一切，如以世俗智所說皆為顛倒；
於無分別慧者有（一切），於分別慧者一切皆無。

於所詮與能詮之順量（anvaya）、逆量（vyatireka）二量，
此「我」之決定，唯有理方成。

於 suṣupta（深睡）中「我」未見一物，心亦少分不見；
不遮自身之見，然遮斷概念。

經教自說：「自為光 svayam-jyotiḥ，非是見者」如是覺知之有；
其不動，與概念之滅，經教自以概念之知分別說。

句義既已如是了知，依經教與世俗共許，
經教說「你即是此」，為遣除聽者之迷。

如梵天對十車王子，僅以言語驅散其無明；
於開顯其毘濕奴性中，未提其他工夫。

ahaṃ（「我」）字於 jyotiṣ（主光）、pratyagātman（內我）中之究竟義，
正是「你是常住」之說；於彼，果為解脫。

〔18.101〕
若唯由聞（śrutamātra）尚不能決定，則此事於此必為定然成就；
由世間行事（vyavahāra）早已證成，自我（ātman）之真實存在（sadbhāva）。

〔18.102〕
為解脫飢食（aśanā）等故，於其時生起量（pramā）；
於『tat tvam asi』等根本聖言之義，三世之中無疑。

〔18.103〕
由無障礙故，且由自我之自內證（anubhava）；
彼處量必生起，於自體中無疑。

〔18.104〕
我僅是『有（sat）』？抑或另有領會？
若『我』之語（ahaṃ-śabda），則應取『有』之主要義。

〔18.105〕
若指他物，則『我有』之執取領會即是虛妄；
因此於『有』之主要執取中，於此無可遮遣之理解。

〔18.106〕
認知者（pratyayī）與認知（pratyaya）當顯現時，即是彼之義（tadarthatā）；
由於彼二者無積聚，於覺知（caitanya）中施設果。

〔18.107〕
如國王雖居都城（kūṭa-stha），勝利等果仍為應得；
由於彼非我性（anātmatva）之因故，於行動與認知。

〔18.108〕
鏡中之映現即是面之相狀；
如是認知之映現於顯現時，彼即是我。

〔18.109〕
如是領會當為『我是有』，不為異樣；
『tat tvam asi』之教誨因無門故亦無義。

〔18.110〕
若聽者有教誨，則應有義；
若於覺者（adhyakṣa）不立聽者性，則誰為之？

〔18.111〕
若主張覺者之近唯有覺（buddhi），
則無彼所作之助益，如木然，施設不成。

〔18.112〕
若於覺中有彼所作，豈非如是變化？
於顯現中何過？以有聖教等加持故。

〔18.113〕
若於顯現中有變化，則不如繩等之喻；
蛇喻亦如是說，鏡喻亦如面喻。

〔18.114〕
若非自我映現之成立，則由自我之執取別於彼；
面喻則別立，於此則互為依。

〔18.115〕
若覺者別立，則映現屬彼；
若映現屬彼，則覺者別於彼。

〔18.116〕
夢中不爾，認知對象之別立亦然；
於車喻等因空故，認知由自我執取。

〔18.117〕
由理解（avagati）所遍滿之認知，有對象之相狀；
彼形相生起時，彼被計為外在對象。

〔18.118〕
由於最希欲之業（karma），彼有彼者被役使於所作；
形相所到之處，彼即施設為根（karaṇa）。

〔18.119〕
由映現所遍滿之彼被說為『已知（jñāta）』；
於此三法能揀別者，彼即是知自我者（ātmavit）。

〔18.120〕
正、疑、邪三種認知為錯亂者；
於彼等中唯一理解，唯別異為認知所施設。

〔18.121〕
如由根本差別而有寶石（maṇi）之別，
如是於理解中；不淨、變化，一切皆依認知而立。

〔18.122〕
認知之展示、執取、成就，於此為異；
由現前（āparokṣyatā）故，彼被說為譬喻（anumāna）如燈。

〔18.123〕
豈有人以某量（pramāṇa）使無知者知？

〔18.124〕
若於此唯以語（śabda）為量而說遮遣，
因覺者不立故，唯空（śūnyatā）為過失。

〔18.125〕
若問：『你如何是有覺者之身？』
非因不立故；若覺者之異不立，如是當為否定他者。

=== 24 | 第十八品 ===

觀者（adhyakṣa）與見（dṛś）的關係，將是何種？
除觀者與所見（dṛśya）外，另無觀者-所觀者之性（draṣṭṛdṛśyatā）。

由觀者所成之見，遍於所見，或者不遍；
於常恆觀者所作之某種助益，或可有之於慧（dhī）。

此與其相似，前已說，及遍於罐（ghaṭa）等；
如光（āloka）等之遍，由顯示性故，慧亦如是。

如置於光中之罐，亦如登上覺（buddhi）；
將有慧之遍、罐之登上；於慧之遍中，當有次第。

先當有認知（pratyaya）之遍，後有我（ātman）之恩；
於全觀者而言，此次第不合宜——如時、空等之次第。

對象之執取，依於因而有；
於所取（grāhya）尚存之際，其變異者如心（citta）。

「我為觀者」之知，唯是覺之決定；
非由觀者之無別故，以其無有另一。

若由作者（kartṛ）「我如此」而經驗解脫，
則苦樂之解脫，不合於非作者。

由對身等之我執（abhimāna）所起「我是苦者」之念，必然；
如蜷曲者（kuṇḍalin）之念，由內我（pratyagātman）之我執者。

於此，無揀擇者為念所繫、為揀擇（viveka）所繫；
反之，將無有終，以量（pramāṇa）成非量故。

於燃（dāha）、割、壞中，我之為苦非由別故；
實則從無有他人因他人之燃等而成為苦者。

以無觸故、無身故，我永非可燃者；
故由虛妄（mithyā）我執所起，如喪子者之哀死。

「我於蜷曲中」，此實為揀擇者所破；
「我是苦者」之念亦爾，常由獨「我」之慧故。

若安樂已立，則為所欲；此能力常屬於我；
由虛妄我執故為苦，由此獲取之滅。

如無觸者亦見觸、無動者亦見動等，
由無揀擇（aviveka）故，心的苦亦於我中被見。

由揀擇我之慧故，苦被驅逐，如動等；
由無揀擇之自性故，心雖不欲而趨往。

彼時於動搖中見苦，於不動中非其；
故於內我中，此苦決不生起。

由於「你」（tvaṃ）與「彼」同處所故，此將如藍馬；
由與無苦者之連繫故，「你」字之義為此。

由內我之稱呼故，「彼」字之連繫如是；
「你是第十」，如是之語句當關於內我。

由不自捨己義故，二者傳達特勝義，亦證知內我——
無他義與此義相違，故。

由九覺之去除故，十圓滿之自不見，
欲知己我——人當如是。

由無明所縛之眼故，慧常為欲所奪，
不見獨存之自——如第十之不見。

「你是第十」，如是，由「汝即是彼」（tattvamasi）等語句故，
知自己為我，為全內根之見者。

「此字在前，彼字在後於語句中」，如是之規
於吠陀中實無，諸字依義相合。

於語句中所聞諸字之義憶念，
由相續（anvaya）與簡別（vyatireka）故，由此語句義之覺知。

=== SamUpad_I,18.177 ===

（接前節）意義則應分別抉擇；當（弟子透過推理）從章句義的了知中得轉依（清淨），那時便不應有疑問。

=== SamUpad_I,18.178 ===

（章句義的領會）需藉「相續（anvaya）與遮遣（vyatireka）」之法，方能記憶個詞之義；若無記憶，便無人能了解章句之義。

=== SamUpad_I,18.179 ===

由於對「tat tvam asi」等章句中「tvam（汝）」一詞之義未能如實辨析，故章句之義尚未顯示——由此便生起「我是常解脫者」之智。

=== SamUpad_I,18.180 ===

相續與遮遣之法，正是用以辨明此義，別無他途。唯有辨明「tvam」一詞之義時，（此法之難度）方如「將 bilva 果置於掌上」般的明顯可察。

=== SamUpad_I,18.181 ===

章句之義如此顯示：唯從「aham（我）」一詞之義——「我是苦者」——透過否定（苦），便得證內自我（pratyagātman）之決定義。

=== SamUpad_I,18.182 ===

既已聞法，於義證成之後仍以未聞義之心推度，此於通曉字句義者而言實不應理。

=== SamUpad_I,18.183 ===

如同「黑耳者等」之事例中，世間現量（pratyakṣa）等（推論）不能破斥（章句義）；若以此等（類比）不能破斥章句，則章句又如何得被破？

=== SamUpad_I,18.184 ===

既已認知「我是苦者」，便不生「離苦者」之智；雖有現量等之似破，由於章句不動搖，故（離苦之智）不生。

=== SamUpad_I,18.185 ===

夢中因火焚、刀割等緣故，「我是苦者」之（現行）生起；若此等（夢中之事）不能由當時之章句所破，則（夢中之我為苦此一現行亦當成立）。

=== SamUpad_I,18.186 ===

若言苦已滅，則苦之滅前亦應有（破斥）；然於顛倒中（或輪迴中），不見苦之綿延。

=== SamUpad_I,18.187 ===

「內自我之為我（ātmatva）」——此由破斥「我是苦者」而知。如同「知此（第十對第九）無矛盾」之例。

=== SamUpad_I,18.188 ===

「我是常解脫者」之智，僅由章句而生，別無他途；而章句義之智，亦以詞義之憶持為先。

=== SamUpad_I,18.189 ===

詞義確由相續與遮遣而得憶持；如是由於章句，便得證「離苦、無為（akriya）」之自我。

=== SamUpad_I,18.190 ===

由「sad eva」等章句，可得更明了之量（pramā）；「tvam asi（汝是彼）」亦應如是證於內自我之中。

=== SamUpad_I,18.191 ===

如醒覺時夢境之苦皆滅，如是由於內自我之智，苦之性（duḥkhitva）於自我中永滅。

=== SamUpad_I,18.192 ===

於「黑耳者等」事例中，量之所以生起，乃因（一事例之智）流入他義、令他義柔軟；於「tat tvam asi」等章句中，則非如此，以無矛盾故。

=== SamUpad_I,18.193 ===

於「tat tvam asi」之章句中，若義已知，則此詞之二義（sad = tat, jīva = tvam）不（需另立）；若不藉詞義之憶持為助，章句不生量（pramā）。

=== SamUpad_I,18.194 ===

「tat」一詞應成「tattva（真實性）」之同義，「asi」一詞亦然；「tat」聲表內自我之義，「tvam」聲則表「tattva（彼之真實性）」之意。

=== SamUpad_I,18.195 ===

（兩者）皆應遣除「duḥkhitva（苦性）與非內自我性（apratyagātmatva）」；如是則「neti neti（非此非此）」之義，由二者互相引入。

=== SamUpad_I,18.196 ===

如是「tat tvam asi」之義究竟時，若不說其「非量性（apramāṇatva）」，則說「需待業（kriyā）」——此說應如何理解？

=== SamUpad_I,18.197 ===

故於初中後，「kurv ity etad」（此作此）之語與（tat tvam asi）相違；不應臆設，因未聞之故，而捨聞法亦無義。

=== SamUpad_I,18.198 ===

如手之飽足由經驗而得，不由章句；章句之維持，亦如「牛糞供酪」之例（於已成就者無新增義）。

=== SamUpad_I,18.199 ===

於「anātman（無我）」之義中，章句之間接指示（pārokṣyabodhana）為諦實；於內自我之義中，則不然——如同「沙糖入口」（非他處可得，唯內證故）之喻。

=== SamUpad_I,18.200 ===

當立「自所證性（svasaṃvedyatva）」與「自為其量（svapramāṇaka）」之特例：我之「非我（aham）」之離已成就，自我之體驗亦立。

（19.1）
既已施用智慧與離染之藥，
此乃滅除 tṛṣṇā（渴愛）熱惱之因，
身不復墮於
由貪欲熱惱集聚、依身過叢所生之苦。

（19.2）
汝執「我」「我所」，
而勤求非義之事；
他人各求自利，
汝之勤求乃為他人。
汝無[真實]義利之覺知，
我亦復無所求。
故汝心唯宜 śama（寂止）。

（19.3）
我非異於至上常住[梵]，
故我恆時滿足，於我無所希求；
我恆解脫，不求 hita（利樂）。
心啊，努力（yatasva）——
以寂止為汝之至上要務。

（19.4）
已度越 ṣaḍūrmi（六塵）纏縛者，
其即是汝之 ātman（自性），
亦即此世之自性——
此依 śruti（聖教）與 pramāṇa（量）
由我所宣說。
故汝心之勤求徒勞無功。

（19.5）
汝既寂止（praśānta），
則無「能所」之見（bhedadhī）；
世間由 māyā（幻）而生迷惑。
執著乃幻所生者之因，
離執則於一切無[執著]可說。

（19.6）
於我無有迷惑；
汝之行作不能令我動搖——
覺性已覺，無有 avikriya（變易）。
於我無前念後念之別，
故汝心之勤求徒勞。

（19.7）
我是 nitya（常住），
故無 vikāra（變易）；
若合於變（yoga），
則有無常。
我是恆時 prabhāta（覺醒），
故我 advaya（無二）；
所思之二分，
乃 asat（非實），此為定論。

（19.8）
心啊！汝之自性無[實在]相——
當觀察（nirīkṣyamāṇa）時，
依 yukti（理）不應有[實在性]。
有者（sat）不可從無者（asat）生，
無者亦不可從非生者（ajanman）生。
故於汝，
此二者皆不可得。

（19.9）
draṣṭā（能觀者）、
dṛśya（所觀境）、
darśana（觀照）——
此三者皆為汝所假立之 bhrama（妄）。
所觀境不異於能觀者，
故不可說有所觀——
譬如 svapna（夢）與 vibodha（覺），
二者[其實]無異。

（19.10）
vikalpanā（思辨）亦應是 advaya（無二），
以無實在所緣（avastu）故，
如 alātacakra（燈焰之輪）。
能力無別（śaktibheda），
亦非由自[所證成]。
故 advayatva（無二性），
依 śruti 可決。

（19.11）
若汝之各別 cetanā（識）
真實互相 bhinnā（差別），
則彼等必有 kṣaya（壞滅）——
以 parimāṇa（量限）故。
bhedavat（分別者）之淪墮
乃可決定（dhruva）——
若爾，jagatkṣaya（世間壞滅）
亦將成定論，悉歸解脫。

（19.12）
於我無人（kaścit），
於彼我亦非任何人（kasyacit）——
我是 advaya（無二）。
無有真實之 kalpita（施設）。
我本來（purā）成立（prasiddhi），
非由施設。
施設而來者，
唯是 vikalpanā（思辨）之 dvaya（對偶）。

（19.13）
若 vikalpanā 於實無中生，
則亦無 nāstitā（勝義之無）；
施設由「有」與「異於有」而起，
故無[真實之]無。
施設由[汝心之]prasiddhi（[傳統]成立）而起，
故非施設彼[本來成立者]。

（19.14）
凡所觀之「有」與「異於有」，
汝皆未真實見，
故亦無 nāstitā。
vikalpanā（施設）於「有」與「異於有」——
如 vicāra（觀察）所示，
「有」實為 advaya（無二）。

（19.15）
若「有」為汝所施設
且為 nāstitā 所攝，
唯為 vicāra（觀察）之境。
由 vicārahāni（失觀察）故，
[其]狀如此——
若此非 iṣṭa（所欲），
則「有」之真實
更應受推重（nitarāṃ sad iṣyate）。

（19.16）
若謂「有」與「異於有」
二者皆如 asatsama（非有），
則因 anarthavat（無義利）故，
如 kharaśṛṅga（銼角）。
「異於有」之 anarthavatva（無義利），
以其 akāraṇa（無因）故。
由此故，
於 viparyaya（反者）亦不應別立。

=== 1 | I,19.17 ===

由於探究之因未得成就，故二者（sadasat）由 māyā（幻）所流衍。
由吠陀、傳承及正理皆如是成立於此，否則即不適成。

=== 2 | I,19.18 ===

由於分別故，吠陀所說之不二與古來所成立之不二相異；
「非此、非彼」之諸分別亦為成立究竟故於此遮遣。

=== 3 | I,19.19 ===

雖於不生、無二、不變之音中本不分別，彼分別有與無、以生為有、以生為無者，
由自心之幻所生，恆常趣入輪迴（bhava）、老、死。

=== 4 | I,19.20 ===

若無「有/無」之安住，則無「彼之別者」之生，亦無「非異」之生。
由「有」無自性、由「無」有自性故，亦無所作、能作，故亦為無生（aja）。

=== 5 | I,19.21 ===

若此能作者不為所愛之事，彼外更無別物；無所作者即無能作者。
由「有」之無別、「無」之墮有，譬如秤之兩端，確實無以決定。

=== 6 | I,19.22 ===

若非彼為所愛之「有/無」之逆轉者，云何於「有/無」之安立中為有？
此二者亦分別安住，故無任何人之生，亦無其意。

=== 7 | I,19.23 ===

然汝欲趣入於有而為止，我言：「汝之所作於我無義。」
若二者「有/無」之存在非從自、他生，則無滅、無增。

=== 8 | I,19.24 ===

常住者非無常，亦不與他合；彼此亦非所作，亦不適於彼等。
故任何人之任何所欲皆無；tattva（真實）自非名言所能及。

=== 9 | I,19.25 ===

故智者恆常平等觀，如明照者，離於「有/無」之二分別，
以正理並由吠陀觀察，得究竟 nirvāṇa（涅槃），如燈然。

=== 10 | I,19.26 ===

唯一不可由他人知者，詭辯家以別法易知；
若如是觀察，無取著者不染著，離取著之過故不迷。

=== 11 | I,19.27 ===

故迷亂之慧不以取著之斷滅為因；取著即為其因。
取著亦無因，譬如無薪之火無燃料，得究竟寂靜亦然。

=== 12 | I,19.28 ===

譬如大士於大海中攪吠陀海所取出之 amṛta（甘露），
此智亦然；古來由彼等究竟所見者，敬禮彼等師！

=== 1 | 婆羅門子自述歷程 ===

啊！你說得對，看得正確。為何說我這婆羅門子是說謊者呢？我曾為梵行者，或家住者，如今我是摩訶漢遊行者。

=== 2 | 若問：我為何說謊 ===

若他問：「尊者，我為何說了謊？」

=== 3 | 阿闍黎解釋 ===

阿闍黎便對他說：「因為你曾以『我是婆羅門子，無後』之語，將具有種姓相續與行法之身，錯認為脫離種姓相續與行法的ātman（我）。」

=== 4 | 若問：為何身有相續、我卻無 ===

若他問：「為何身體具有種姓相續與行法，而我脫離種姓相續與行法？」

=== 5 | 阿闍黎答身異我異 ===

阿闍黎便說：「聽著，朋友啊！如此身體與你相異，具有種姓相續與行法；你則脫離種姓相續與行法。」說完後令他憶念：「朋友啊，你應當憶念！你已被教示『朋友啊，此唯是sāt（存在）而已』等吠陀經典與傳承中記載的paramātman（最高我）——sarvātman（一切我）——如前所述的特相。經典與傳承亦說明其特相。」

=== 6 | 開示最高我之特相 ===

為令其憶得最高我之特相，便說：「那個名為ākāśa（空）的，既非名亦非rūpa（色），不同於名色；無身；無粗大等相；具斷滅罪惡等相；不被一切輪迴法所染污。『那是直接現觀brahman（梵）……那是你sarvāntaraḥ（內在於一切）的ātman（我）』；『未見者為見者，未聞者為聞者，未思者為思者，未識者為識者』；本體為常住之vijñāna（識）；無內無外；『vijñāna（識）為實質』；圓滿如ākāśa（空）；具無量力；為一切之ātman（我）；離飢渴等；無生滅之相；其名rūpa二者為與ātman（我）相異之世界種子，存在於ātman（我）中；以tattva（實在）與anyatva（異於實在）皆不可言說；唯自證；以存在之力，具不可思議之力，而為能展開與所展開者。」

=== 7 | 譬如浮沫 ===

此名rūpa二者未展開之時而展開時，即轉變為名為ākāśa（空）之相。此ākāśa由清淨之水所生，如水之浮沫，卻非水，亦非與水完全不同之沫；水清淨而別於沫，沫為汙之相。如是，paramātman（最高我）清淨而別於名rūpa二者，純淨、無染，不同於沫之位。此名rūpa二者未展開之時而展開時，即轉變為位於沫之位、名為ākāśa（空）之相。

=== 8 | 五大之生起 ===

此名rūpa二者再變為粗大時，展開為vāyu（風）之相；再變為agni（火）之相；再變為ap（水）之相；再變為pṛthivī（地）之相。如是依此次第，由前前入於後後，五大pṛthivī（地）等遂生起。然後pṛthivī（地）具五大之性。由pṛthivī（地）生具五種本質之稻、麥等穀物。食之則生與男女身相關聯之血與精。此二者於適當之時節，由無明所驅使、愛欲所激發、以mantra（真言）加持之，而注入胎藏中。依其自類之出生與注入而增長，於胎中第十月或第九月出生。

=== 9 | 四行期之成 ===

如是出生之嬰兒，得名與相；以jātakarman（誕生禮）等以mantra（真言）加持，復以upanayana（入學禮）行法之力而稱為brahmacārin（梵行者）。同一身體以與妻子結合之行法，稱為gṛhastha（家住者）。同一身體以入森林之行法，稱為tāpasa（苦行者）。同一身體以令作業止息之行法，稱為parivrāṭ（遊行者）。如是，此身與你相異，具有種姓相續與行法。

〔I,1.22〕
「我如何超越種別（jāti）、家系（anvaya）與儀式（saṃskāra）之差別？」此義汝應聽：

彼於名色二者為差別之作者，與名色之性相異；彼於名色中開顯，自造此身，超越儀式之性相，入此名色之中，不為他眼所見，自見；不聞而聞、不思而思、不識而識——如《梨俱吠陀》（Ṛgveda）所言：「智者（dhīra）觀察一切色，作諸名而宣說，住於此處。」

於此義，千百聖教云：

「彼創造已，復入於其中。」
「入於人中之統治者。」
「此即是入此處者。」
「此即是汝之自我（ātman）。」
「彼破此界限，藉此門而得入。」
「於一切眾生中隱覆之自我。」
「此天如是思惟：『我當使此三天明顯。』」
「於諸身中為無身者。」

等。

〔I,1.23〕
諸聖傳（smṛti）亦云：

「一切天神唯是自我。」
「九門城中居者（dehī）。」
「汝應知我亦為田主（kṣetrajña）。」
「於一切眾生平等。」
「觀察者、允准者。」
「至上之人（puruṣa）乃為另一。」

等。

故「汝超越種別、家系與儀式」之義已得成立。

〔I,1.24〕
彼若作是言：

「我實為另一——無知、有苦有樂、有繫、流轉生死者；彼天乃另一——與我相異、不流轉生死者；我以供養（balyupahāra）、奉獻（namaskāra）等事，依種姓（varṇa）與住期（āśrama）之業而敬奉之，欲度生死大海。如何可說『我即是彼』？」

〔I,1.25〕
師應言：

「可愛友！汝不應如是分別，因為差別之執著為聖教所遮止。」

「差別之執著如何為遮止？」為此而說：

「『彼為另一，我為另一』——彼實不知也。」
「於自我外視梵（Brahman）為異者，彼為梵所拒。」
「於此唯見多異者，彼從死趨於死。」

等。

〔I,1.26〕
此等聖教顯示：依差別之執著，將趣向生死流轉。

〔I,1.27〕
依無差別之證知，則顯示解脫——聖教成千：

「彼即是自我，汝即是彼」——宣說至上我之體性。
「具師之人乃知。」
「彼之時日不久。」

如是宣說後，由無差別之智顯示解脫——以守信實者遇盜而不被焚燒等之譬喻，顯示生死之不復存在；以虛妄意圖者遇盜而被焚燒等之譬喻，顯示由差別之見趣向生死流轉。

〔I,1.28〕
又以「彼於此或為虎」等語，顯示由無差別之見——「彼成全食者」——如是宣說；與此相反，由差別之見則顯示生死流轉：

「然諸以異於實之智而見、說為異王者，彼等成可滅之世間。」

如是逐節反駁。

故彼之說實為虛妄：「婆羅門青年，家世相續，流轉生死，與至上我相異。」

〔I,1.29〕
故應如是知：差別之見為聖教所遮止；業之執取以差別為所緣；聖線（yajñopavīta）等亦為業之具、以業為所成，故此等之執取與至上我無差別之證知相違，應被遮止。

蓋業與其具（如聖線等）乃為流轉生死者所制定，非為至上我、無差別見者所制定。唯依差別之見，故與彼相異。

〔I,1.30〕
若至上我之自我本身之無差別之證知「彼即是自我，汝即是彼」不阻礙當行之業——即與業具相關之業，及由業所生之種別、住期等相關之業——不應止息——

=== 32 | 第二篇 第一章 31–36 頌 ===

II.1.31：以此等決定之語，他亦不責難 bheda-pratipatti（分別知見）；對「此乃婆羅門常住之莊嚴」、「不為善污染、不為惡污染」、「此中盜者非盜者」等經句，亦不否定。

II.1.32：業及其因（祭供、聖線等器具）之相，與業之果色等之相相連——若不捨棄，則相續不斷。故求解脫者（mumukṣu）應捨棄帶器具之業（sasādhanaṃ karma），以其違反 Paramātmā（至上我）與我無別之見故。應依經教所說之相，了知「我即 Paramātmā」。

II.1.33：若彼問：「世尊！身被焚、被割時，痛現量可感；飢等所生之苦，亦我現量所有。而 Paramātmā『罪業已除（apahatapāpmā）、不老（vijara）、不死（vimṛtyu）、無憂（viśoka）、無飢（vijighatsa）、無渴（apipāsa）』，離一切輪迴（saṃsāra）之相，經教（śruti）、傳承（smṛti）中皆如是說。如何令與 Paramātmā 相異、多具 saṃsāra 諸相之我，以 Paramātmā 為自性？以輪迴者之我為 Paramātmā 自性？猶如以冷為火？我既是輪迴者，於一切現世福樂與究竟解脫之資具——業、及其器具（祭供、聖線等）——皆已得，我如何捨棄？」

II.1.34：對彼當言：「汝言身被焚、割時，痛現量為我所受——此語不正。何以故？身如被焚、割之樹——於有業之身，痛依焚、割同一所依（āśraya）而現；以世間於焚、割所行處說『焚等之痛』，不說於『受者』處故。何以驗之？問：『汝痛何在？』答：『在頭、在口、在腹』——焚等在何處，痛即說在彼處，不說在『受者』處。若痛在受者處，或痛之因為焚、割等者，則應於『受者』處說痛，以痛依於受者故；今則不然——是故痛依於焚等所依之身，非依於受者。」

II.1.35：且（受者）自不被受，如眼中之色（rūpa）不自見。故以痛依焚等同一所依而現之故，痛如焚等，亦是業性、非我性。又以痛是現象法（bhāvarūpa）故，痛與所依（身）相連，如米之與炊成飯。痛之習氣（saṃskāra）亦與痛同一所依，以與記憶（smṛti）同時而現故。痛之境、瞋（dveṣa）及其因之境，亦依於 saṃskāra 之同一所依。如經云：『色之 saṃskāra 所生之貪、瞋、怖畏，攝於慧（dhī）所依；知者（jñātā）清淨、恆常無畏。』

II.1.36：色等 saṃskāra 之依又在何處？答：在覺（buddhi）中。貪等又在何處？依經「貪（kāma）、思擇（saṅkalpa）、疑惑（vicikitsā）」等說，貪等在 buddhi 中。色等 saṃskāra 亦在 buddhi 中——依「諸色住何處？住於心（hṛdaya）」、「住於其心中之貪」、「已度」、「此人無著」、「此為彼之貪欲等過患」等百部經教；及「此（我）無變異故說」、「無始故離相」等——貪、瞋等是田（kṣetra，覺之異名）之法相，非我之法相。又依傳承：「垢在業（karmastha），不在我（ātmastha）。」

「無內無外」、「不死者遍內外」、「此即 brahma（梵）」、「由此門得達」、「prajñāna（智）之諸名」、「真、智、無盡者即 brahma」、「由彼故」、「創造彼後復入於彼」、「一位 deva（天）潛於一切眾生」、「無身者於諸身中」、「不生不死」、「夢盡、覺盡」、「應知彼即我之 ātman（自我）」、「凡是彼」 、「一切眾生」、「彼動彼不動」、「伐那見彼」、「彼即是火」、「我為 manu（摩奴），亦為日」、「入於內之眾生調御者」、「善友哉，唯有『有』[實有]」、「彼是真，彼是 ātman，彼是汝」——由此等諸《奧義書》經文 //

// SamUpad_II,1.37 //

又由「城居之有情……住祕處」、「諸天即 ātman」、「於九門城」、「於一切眾生平等」、「具足智與調伏」、「於諸分別中不分別」、「vāsudeva（毘濕奴）即一切」等，及由傳承——唯此一 ātman 即至極之 brahma，離一切輪迴（saṃsāra）之性，汝即是之——已得成立 //

// SamUpad_II,1.38 //

若有問：尊者，若「無內無外」、「不死者遍內外」、「遍滿為 prajñāna 所凝」——ātman 如鹽塊，離一切形象差別，如空唯一味，何者為所見、所聞、所證、sādhya（所修）、sādhana（修行）、sādhaka（修行者）乎？——此乃《吠陀》、傳承、世間共許之一切詁論爭端所成之對境 //

// SamUpad_II,1.39 //

師答：此所見、所聞者，乃無明（avidyā）所造。然於勝義，唯一 ātman——以無明所見故，現為種種，如暗中所見多月——「若彼處別有餘」、「若有二相生，則此見彼」、「彼從死得死」、「若見異、聞異、知異，此是微小，……此微小者即是無常」、「語言之起為變、為名」、「彼異此我異」——以此等破斥差別見、責難之義故，二相乃無明所造——由「唯一無二」、「於此處」、「何為癡？何為悲？」等說一相之經文故 //

// SamUpad_II,1.40 //

若如是者，尊者，何以《吠陀》說 sādhya、sādhana 等差別，以及生起（utpatti）與寂滅（pralaya）乎？ //

// SamUpad_II,1.41 //

答曰：未辨 sādhya、sādhana 差別與善惡得離方便之修行人，以為 ātman 乃具足無明所取之身等差別，求善離惡；對彼等欲得善、離惡者，經教令其漸次轉此無明之境，不施設 sādhya、sādhana 等差別——「輪迴乃不善之相，是故唯此」——故以生起、寂滅等一味之證成，顯示：以差別之見為輪迴根本之無明，當拔其根 //

// SamUpad_II,1.42 //

於無明拔根之時，由《吠陀》、傳承、論理：「無內無外」、「不死者遍內外」，如鹽塊，「為 prajñāna 所凝」，唯一味之 ātman 如虛空，於此即立一智，於勝義見者有之；於 sādhya、sādhana、生起、寂滅等差別中，無少分不清淨之氣味，亦得成立 //

// SamUpad_II,1.43 //

此勝義見，欲證得者，應自種姓、住處等執所成之惡友（如族子惡友等）、求世間之徒出離。於彼執（差別見）壞正見故，以一味之理破差別見而得成立，且於證成。一 ātman 不流轉之慧若經教與論理已生，則與彼相違之慧不生——如火中無冷想，身中不老死想。是故以一切作業皆為無明所作故……

=== 23 | SamUpad_II,2.49 ===

弟子言：「此無明者何者？以何為境？明者復是何、為能除無明令我證自性者？」

=== 24 | SamUpad_II,2.50 ===

師言：「你將常恆、不屬輪迴之 paramātmā（至上我）錯認為屬於輪迴之我，以『我為輪迴中者』之顛倒分別而執著，將非作者執為作者，將非受者執為受者，將存在者執為不存在者——此即是無明。」

=== 25 | SamUpad_II,2.51 ===

弟子言：「縱然我存在，亦非至上我。以作者性與受者性為相狀之輪迴乃我自性，以此親證等量（pratyakṣa）種種量（pramāṇa）而體驗故。（輪迴）非以無明為因，由於無明不能以自為境故。無明者，謂於此一法上強加另一法之體性。譬如於已知名為 śuktikā（蚌殼）者之上強加已知名為 silver（白銀）之相狀；又如於已知名為 puruṣa（人）者之上強加已知名為 sthāṇu（樹樁）之相狀；或於已知名 sthāṇu 之處執為 puruṣa。已知名者之上不加未知名，未知名者之上不執為已知名。又，無以未知名之我不於 ātman（自性）上強加 anātman（非我）相，由於自性不為未知名故。如是，自性亦不於非我之上強加我相，亦由自性不為未知名故。」

=== 26 | SamUpad_II,2.52 ===

師對彼言：「不然（na），是由於 vyabhicāra（誤濫）。吠陀（vatsa），已知名於已知名之上強加他性，此非可決定之理。以於 ātman 上見有強加故。如『我是黃牛』『我是黑者』，此乃身體體性之『我』分別對象，強加於 ātman 之『我』分別對象之上，並於身體上執『此即是我』。」

=== 27 | SamUpad_II,2.53 ===

弟子言：「然則已知名之 ātman，以其為『我』分別之對象故，即是此身；而此身亦為已知名者。若如是，則於已知名之身與 ātman 上互為強加——猶如 sthāṇu 與 puruṣa、śuktikā 與 silver 互相強加。於此依何差別，世尊（bhagavat）乃作『於已知名之上互為強加，非可決定』之語？」

=== 28 | SamUpad_II,2.54 ===

師言：「且聽（śṛṇu）。身與 ātman 雖為已知名，然非如 sthāṇu 與 puruṣa 以 vivikta（截然分別之）分別對象而為一切世間所共知。何以故？以常恆而無間斷、非截然分別之對象故。蓋此身與 ātman，非由兩個截然分別之『分別』（pratyaya）所攝取——無有人以『此身』『此 ātman』之兩個截然分別攝取故。由此之故，世間於 ātman 與非我之境中顛倒迷惑：『ātman 非如此即是非我』——『ātman 亦非此即非我也』。吾依此差別而作是言：『非可決定（如此分別）。」

=== 35 | 身我互執之辨 ===

[mUpad II,2.54]
然而，凡由 avidyā（無明）所妄加於某處之物，於該處皆見其非有。譬如螺貝中之銀、椿柱中之人、繩上之蛇、ākāśa（虛空）中之底垢等。身與 ātman（我）亦然：若依常住、無間、不可分別之認識為依而施設互相妄加，則彼二者常住非有。譬如螺貝等中由 avidyā 妄加之銀等常住畢竟非有，彼相反者於其相反之處亦然；身與 ātman 由 avidyā 互相妄加亦復如是。若如是，則身與 ātman 非有之結論隨之。此不應理，以墮 vaināśika（斷滅論）邊故。

然若反之，身由 avidyā 妄加於 ātman，則身於 ātman 非有之結論隨之。此不應理，以與 pratyakṣa（現量）等相違故。

是故身與 ātman 非由 avidyā 互相妄加於對方。

云何？猶如竹與柱，彼等常相連結。

[SamUpad II,2.55]
不然。以墮無常、為他之過故。為他與無常皆以和合性故，正猶如竹與柱。

復次，彼由他人所施設與身和合之 ātman，以和合性故，是為他。因此有別於和合之另一常住、不和合者成立。

[SamUpad II,2.56]
彼不和合者以唯身之相被妄加於身，故有非有、無常等之過。是處有「身是 nirātman（無我）」之墮 vaināśika 邊之過。

[SamUpad II,2.57]
不然。以 ātman 自性不和合，正猶如 ākāśa。若一切皆不和合即是 ātman，則一切身等不應為 nirātman。

正猶如 ākāśa 雖為一切所不和合，然一切非無 ākāśa。如是。是故不墮 vaināśika 邊之過。

[SamUpad II,2.58]
然所言「身於 ātman 若非有，則與 pratyakṣa 等相違」者，此不然。以 pratyakṣa 等於 ātman 中不得身之有故。

非猶如於坑中得棗、於乳中得酥、於芝麻中得油、於牆中得畫等可以 pratyakṣa 等得，身不可以 pratyakṣa 等於 ātman 中得故。是故無 pratyakṣa 等相違之過。

[SamUpad II,2.59]
然則於 pratyakṣa 等所不立之 ātman 中，如何施設身之妄加？於身中施設 ātman 之妄加？

[SamUpad II,2.60]
此非過。以 ātman 自性所成故。非可制立「唯於或有者施設妄加，非於常成者施設妄加」，以 ākāśa 中有底垢等妄加之例可見故。

[SamUpad II,2.61]
世尊！身與 ātman 互相妄加，是身等集聚所作，抑是 ātman 所作？

[SamUpad II,2.62]
師曰：若身等集聚所作，若 ātman 所作，於汝何預？

[SamUpad II,2.63]
弟子聞已曰：若我唯是身等集聚，則我以無知故是為他，故身與 ātman 互相妄加非我所作。

然我別於集聚，是常住之 ātman，以有知故是為自。由我此有知之 ātman 於 ātman 中施設妄加，是一切禍患之根本。

[SamUpad II,2.64]
師聞已曰：汝若知虛妄之妄加為一切禍患之根本，則勿作之。

[SamUpad II,2.65]
世尊！我實不能不作。以我為某餘者所驅使，非自在故。

[SamUpad II,2.66]
然則汝非由無知故為自。汝由彼所驅使、不自在而轉，彼是有知、是為自，汝唯是集聚。

[SamUpad II,2.67]
若我是無知，如何知苦樂之受，亦知尊所言？

[SamUpad II,2.68]
師曰：除汝之外，別有知苦樂之受、及知吾所言者否？

=== 1 | SamUpad II, 2.69 ===

唵。否則怎能說是別異（anya）呢？

弟子說：就我而言，我並非與之不二（ananya）。為何？因為我知道享受者與所享受這兩者皆為業（被認知），譬如瓶等對象。若我與之不二，那兩者我便不會知道；我既然知道，故我是別異（anya）。

況且，樂（sukha）與苦（duḥkha）的感受（vedanā）以及變易（vikriyā），乃為自事（svārtha）而得；若按您所說（自我與梵）不二，則二者之為自事便不成立。並非由旃檀（candana）與刺（kaṇṭaka）所生的苦樂是為旃檀與刺而立，瓶之被用也不是為瓶而立。因此，那些苦樂是為我——它們的覺知者——而立。我與之別異，因為我以智慧（buddhi）所攝（buddhyārūḍha）知一切義。

=== 2 | SamUpad II, 2.70 ===

師說：既然如此，你這有知者（citimant），不為他人之事而被他所役使。有知者並非依他而立，也不被他人所役使；因為不可能成立「有知者為有知者之義」（citimadarthatva），正如光與光的平等（samatva）一般。無知者（acitimant）也不為有知者之義而立；因為無知者本即無知，與自事（svārtha）不相連屬故。亦未見無知者之間相互為義而立之事；柴堆（kāṣṭha-kuḍya）中的木塊，並不互相為義而運作。

=== 3 | SamUpad II, 2.72 ===

[反對] 然而，雖然同樣有知（citimattva），主人（bhartṛ）與僕人（bhṛtya）相互為義而立之事，卻是可見的。

=== 4 | SamUpad II, 2.72（續） ===

[破斥] 不然。你所說的「有知」，乃如火的熱與光（uṣṇa-prakāśa）一般。譬喻已示明為「如光與光」。如此，你以永恆不變的覺性自性（kūṭastha-nitya-caitanya-svarūpa）——相當於火的熱與光——覺知一切皆是自智所攝（svabuddhyārūḍha）。如果你接受自我（ātman）始終無相（nirviśeṣa），那麼請回答：當從深眠中醒來，你於醒覺與夢中皆感受到苦；此苦究竟是你的自性（svabhāva），還是因緣所生（naimittika）？那錯亂（vyāmoha）究竟已離，還是未離？

=== 5 | SamUpad II, 2.73 ===

弟子聽後說：世尊（Bhagavan），承您之恩，錯亂已離，但我對自身的不變性（kūṭasthatā）尚存疑惑。如何存疑？聲等（śabda-ādi）的自性成就（svataḥ-siddhi）並不存在，因為它們是無心（acetana）的。聲等之相（ākāra）乃由因緣（pratyaya）所生；因為因緣——彼此互遮的差別相（itaretara-vyāvṛtta-viśeṣaṇa）——如青、黃等之相，不可能自性成就。由此可推：聲等之相以外因為其生因，故以外在對象之相而成立。

同樣，自我概念（ahaṃ-pratyaya）——其為諸所緣境事之依止——是積聚（saṃhata）的；既為積聚，便無覺性之理（acaitanyopapatti），亦無自事之理。既以異於自性（svarūpa）的能取所取之相而立，恰如聲等。若非積聚（asaṃhata），因覺性之本性故，則自我（ahaṃ）——諸因緣（青、黃等之相）之自事——即為覺知者。如此，我即是變易者（vikriyāvān），是否常住不變（kūṭastha），正是我的疑惑。

=== 6 | SamUpad II, 2.74 ===

師說：你的疑惑並不成立。那些因緣（pratyaya）之被「完全」覺知（niyamenāśeṣata upalabdhi），不經變易（apariṇāmitva）——這本是成立你不變的決定性理由（niścaya-hetu），你卻把它當作疑惑的理由（saṃśaya-hetu）。如果你會變易，那麼對於一切境的心之運作（cittapracāra）的覺知，便不可能存在——正如心於其自境、感官於其自境一般。而對自我（ātman）來說，並非如此：並無僅覺知部分自境之事。故你確實是不變的（kūṭastha）。

=== 7 | SamUpad II, 2.75 ===

[弟子] 說：「覺知」（upalabdhi）按語根本義（dhātvartha）即是變易（vikriyā），而覺知者（upalabdhu）的不變之自性（kūṭastha-ātmata）——這是相違的（viruddha）。

=== 8 | SamUpad II, 2.76 ===

[師] 說：不然。這是因為對語根所表之變易（dhātvartha-vikriyā），以「覺知」一詞施設（upacāra）故。那屬於智（bauddha）的分別（pratyaya），按其語根本義是變易性的（vikriyātmaka），以覺知自我之顯現（upalabhyābhāsa）為其結果之終止，故以「覺知」一詞施設（upacaryate）。正如切斷（chidi-kriyā）之業以分裂（dvaidhībhāva）之果為終止，按其語根本義施設為「切斷」——此亦如是。

（弟子言：）此譬喻不能證成常住不變之性。何以故？正如「砍」字依字根本義而施用於「砍斷」之變異終了；同樣地，「覺知」一詞雖依字根施用，但若覺知之變異屬於 buddhi-pratyaya（分別之了別），則不能證成 ātmana（自我）之常住不變。

（師答：）且聽！我已說過是「以覺知之顯現為果之終了」，你難道沒聽到嗎？我所說的是：並非 ātmana 之變異生起之終了。

=== 38 | 第二品 §2.93-103 ===

量的依待——對於自證（svataḥsiddha）的量者（pramātṛ），在決定另一所量（prameya）時，有量的依待。至於另一常住決定被依待，用以限定另一無定相之決定者，彼決定本身是常住的、不動（kūṭastha）的、以自光（svayaṃjyotiḥ）為自性的。自我之為量或為量者時，不對彼有量的依待，因為是其自性故。

譬如鐵、水等中之光或熱，因非其自性，故從火、日等外待；火、日等不待它們，因恒常是其自性故。

// SamUpad_II,2.93 //

若言：應是無常的覺知為量，不是常住的覺知為量。

// SamUpad_II,2.94 //

不爾。由於覺知中常與無常的差別不能成立。在覺知為量時，「無常覺知為量、常住覺知非量」這樣的差別，並不被覺知。

// SamUpad_II,2.95 //

若言：於常住者，無待量者；於無常者，因覺知被其他勤作所隔，應有依待。如是有差別。

// SamUpad_II,2.96 //

那麼，作為量者的我（ātman）之自證已成立，正因為離待於生命息故。

// SamUpad_II,2.97 //

若言：於無者中亦無依待，因為是常住故。

不爾。這已由覺知於自我中有體故被遣除。

// SamUpad_II,2.98 //

再者，量者之待量若不成立，誰應有現量（pramitsā）？誰有現量，誰即被承許為量者。他的現量是關於所量的，不是關於量者的。若是關於量者的，則有無窮過失（anavasthāprasaṅga）。

量者與其影像，又需另一量者，彼又需另一，如是如是。若欲（icchā）以量者為所對，即如此。並且因為量者之自我是無間的（avyavahita），所以不能成為所量。

世間所謂的所量，唯以量者的欲、念（smṛti）、勤（prayatna）、量、生而為間隔（vyavahita）者得成。覺知關於所量，不是以其他方式所見。

量者之量者，不能由他自己單獨被任何人設想為間隔，即使以欲等任何之一亦不能。

念是關於可念之事，不是關於念者。

同樣，欲唯有欲事之相，非有欲者之相。

即使念與欲以念者、欲者為所對，於此二者中仍如前有無窮過失，不可避免。

// SamUpad_II,2.99 //

若言：既然以量者為所量之覺知不生，那麼量者應是未被覺知的。

// SamUpad_II,2.100 //

不爾。因為覺知者是以覺知之境為所對，非以覺知者為所對。若以覺知者為所對，則如前有無窮過失。

覺知於自我是不動的常住自光，離待於他而成立，猶如火、日等的熱與光，前已成立。

至於意識自光（caitanyātmajyotiḥ）的覺知，若於自我中是無常的，自我不能有自果用（svārthya）；我們已說過，因如能作所作的和合（kāryakaraṇasaṃghāta）之和合故，即有為他性（pārārthya）與過失（doṣavatva）。

如何呢？意識自光若於自身無常，因被念等所隔，即是和合。

因此，那意識光於生起之前與壞滅之後，於自我中即無體；如眼等之和合故，應是為他性。

當它已生起並在自我中被見時，那時自我就不是為自果用。

自我的為自用、為他用之成立，依於彼之有體與無體故。

因此，自我離待於他、常住意識光（nityacaitanyajyoti）之自性，已成立。

// SamUpad_II,2.101 //

若如此，於量者之為量者無時，如何有量者之為量者？

// SamUpad_II,2.102 //

答言：由於量（pramā）於常與無常中無相狀差別。

覺知即是量。那覺知，無論是有念、欲等為前的無常者，或是不動的常住者，都無自相狀之差別。

如同 dhātu（動）的義，如「住」（tiṣṭhat）等，為有行等為前的果…

=== 103 | SamUpad_II,2.103 ===

由於此永恆者既非先於（形相）又無特殊形相，故（對此之）描述平等地被見到——如「人站立，山岳站立」等。同樣地，雖然 pramātṛ（量者）之自性為 nityāvagati（永恆認知），對其施以 pramātṛtva（量者性）之稱並無矛盾，這是 phalasāmānya（果之平等）。

=== 104 | SamUpad_II,2.104 ===

對此，śiṣyaḥ（弟子）說：nityāvagati（永恆認知）為自性的 ātman（自我）為 avikriya（無變異），故 kartṛtva（作者性）不能由 kāryakaraṇa（業具）所聚合而成，猶如 takṣa（木工）等不能由 vāsa（斧）等所聚合而成。對於 asaṃhatasvabhāva（自性不聚合）者，攝取 kāryakaraṇa（業具）將墮入 anavasthā（無窮過失）。而 takṣa（木工）等因與 kāryakaraṇa（業具）自性 nitya（永恆）saṃhata（聚合），故其攝取 vāsa（斧）等中將無 anavasthā（無窮過失）。

=== 105 | SamUpad_II,2.105 ===

但於此：對於 asaṃhatasvabhāva（自性不聚合）者，由於不攝取 karaṇa（工具），故 kartṛtva（作者性）不能成立。因此應攝取 karaṇa（工具），而該 upādāna（攝取）本身亦是 vikriyā（變異），故為其 kartṛtva（作者性），應攝取另一 karaṇa（工具）；其 upādāna（攝取）中又攝取另一個——如是在 pramātṛ（量者）的 svātantrya（自在性）中將不可避免地墮入 anavasthā（無窮過失）。而 kriyā（行動）本身亦不能令 ātman（自我）造作，因 anirvartita（未被作）者無 svarūpa（自性）。若謂：另一者接觸 ātman（自我）而令其造作 kriyā（行動）——這亦不成立，因對於「另一者」，其 svataḥsiddhatva（自證性）等的 viṣayatva（對象性）不能成立。我們未見 ātman（自我）之外有 acetana（非覺知）之 vastu（物）為 svapramāṇaka（自所證）。若 śabda（聲）等一切因 avagati（認知）之 phala（果）所 avasāna（達至）之 pratyaya（識）所 pramita（量知），則應為 siddha（已成立）。若 avagati（認知）存在於 ātman（自我）之外，彼亦應為 ātma（自我）自身——asaṃhata（不聚合）且 svārtha（自為目的），非 parārtha（為他者之目的）。而對 dehendriyaviṣaya（身根境）的 svārthatā（自為目的性），由於未見其依待 avagatyavasānapratyaya（認知達至之識）之 siddhi（成立），我們不能予以 avagati（認知）。

=== 106 | SamUpad_II,2.106 ===

難道說：對於 deha（身體）之 avagati（認知）中，無任何 pratyakṣa（現量）等 pratyaya（識）之另一者為所依待嗎？

=== 107 | SamUpad_II,2.107 ===

確實如此，在 jāgrat（覺醒）中應當如此。但在 mṛti（昏迷）與 suṣupti（深睡）中，deha（身體）之 siddhi（成立）亦依待 pratyakṣa（現量）等 pramāṇa（量）。諸 indriya（諸根）亦同樣如此。因為外在的 śabda（聲）等是因 dehendriyākāra（身根之形相）所 pariṇata（轉變）者，故其 siddhi（成立）亦依待 pratyakṣa（現量）等 pramāṇa（量）。而所謂 siddhi（成立）者，我們說是 pramāṇa（量）的 phala（果），即 avagati（認知）。而那 avagati（認知）是 kūṭastha（不動）、svayaṃsiddha（自證）、ātma-jyotiḥ-svarūpa（自我光明之自性）。

=== 108 | SamUpad_II,2.108 ===

對此，codakaḥ（問者）說：「avagati（認知）為 pramāṇa（量）的 phala（果），又說是 kūṭastha（不動）、nitya（永恆）、ātma-jyotiḥ-svarūpa（自我光明之自性），此是 vipratiṣiddha（互相矛盾）。」對說此話者，彼回答：並非 vipratiṣiddha（互相矛盾）。如何不矛盾？雖然 avagati（認知）為 kūṭastha（不動）且 nitya（永恆），由於 tādarthya（指向彼）之故，它在 pratyakṣa（現量）等 pratyaya（識）之 ante（終極）被 lakṣyate（指示）。若 pratyakṣa（現量）等 pratyaya（識）為 anitya（無常），avagati（認知）亦成 anitya（無常）。由於是 pramāṇa（量）的 phala（果），這是 upacāra（施設）。

=== 109 | SamUpad_II,2.109 ===

bhagavan（世尊），若是如此——kūṭastha（不動）且 nitya（永恆）的 avagati（認知），由於對 ātman（自我）pramāṇa-nirapekṣatva（不依待量），本身就是 ātma-jyotiḥ-svarūpa（自我光明之自性）且 svayaṃsiddha（自證）——則除此以外，acetana（非覺知）者由於 saṃhatyakāritva（因聚合而能作），是 parārtha（為他者之目的）。而正是由於此種以 sukha（樂）、duḥkha（苦）、moha（痴）等 pratyaya（識）為相的 avagati（認知）之 pārārthya（為他者目的之性）的 svarūpa（自性），anātman（非我）之 astitva（存在）並非以另一形相存在，故 paramārthataḥ（勝義上）唯是 nāstitva（不存在）。正如世間所見：rajju（繩）之非 sarpa（蛇）、marīci（海市蜃樓）之非 udaka（水）等，若離其 avagati（認知）則 abhāva（非有）；同樣地，jāgrat（覺醒）與 svapna（夢）之 dvaita（差別）bhāva（性）若離其 avagati（認知）亦應 abhāva（非有）。bhagavan（世尊），正是如此：由於 avagati（認知）與 ātma-jyoti（自我光明）之 nairantarya（無間斷）性，而有 kūṭastha-nityatā（不動永恆性）；由於在一切 pratyaya（識）之 bheda（差別）中 avyabhicāra（不乖違），而有 advaitabhāva（不二之存在性）。但 pratyabheda（識之差別）乖違 avagati（認知）。正如 svapna（夢）中以 nīla（青）、pīta（黃）等 ākāra（形相）bheda（差別）為相的 pratyaya（識），乖違其 avagati（認知），paramārthataḥ（勝義上）被說為 na santi（非有）；同樣地，在 jāgrat（覺醒）中以 nīla（青）、pīta（黃）等 pratyaya（識）bheda（差別）為相者，乖違那 avagati（認知），應為 asatyarūpa（非真實相）。而那 avagati（認知）無其他 avagantā（認知者），由於無另一者，故不能以自身 svarūpa（自性）自行 upādātuṃ（攝取）或 hātuṃ（捨棄）。

正是如此（tathaiva iti）。此 avidyaā（無明），以彼為緣（yannimitta）...

=== II,2.110 | 輪迴猶覺夢 ===

啊，輪迴乃覺、夢二相為性。智乃去除彼之無明。如是汝已得無畏，從今不再經歷覺夢之苦，已解脫於輪迴之苦。

=== II,3.112 | 求解脫者之教誨 ===

此為求解脫者——已消福罪、志在積集前所未有之福——之教誨，今當說：『以無明為因之過患，乃語意身造作之因；由此積聚善惡夾雜之業果。為解脫彼故，說此教。』

=== II,3.113 | 境與能知者 ===

其中，聲、觸、色、味、香諸境，由耳等可取故，於自身或他體皆無分別智。彼等唯轉變，如土塊等。復由耳等門所了知。了知彼之覺者，以為能知故，與彼非同類。聲等互相依存故，乃生、長、變、壞、滅、合、離、顯、隱、變、不變、田、種等多相；又於共相上具苦樂等多相。為彼多相之能知故，彼能知者迥異於一切聲等諸相。

=== II,3.114 | 智者之省察 ===

其中，智者為聲等所覺、所逼，當如是省察。

=== II,3.115 | 我不為境動 ===

聲乃聲音之共相，或『Ṣaḍja』等特殊德相之可愛者——讚歎等悅意，與妄、醜、辱、罵等不悅意之語。彼當觀我之自性：無所依、無變易、無動、無盡、無畏、最極微細、非所緣，終不可觸，以我無所依故。是故聲非我之損增之緣。是故於我何所作？讚、毀等悅與不悅之聲，於無分辨者以聲為自我故，悅意之聲增益之，不悅意之聲削弱之；於我具分辨者，無此事，乃至纖毫亦不能作。

觸亦以共相及其別相——寒熱柔堅熱腹痛等不悅者，及身內悅者與外來悅者——我以無觸故，無有變易損益之相作，如虛空之於拳擊等。

色亦以共相及其別相——女莊嚴等悅與不悅者——我以無色故，無有損或增之可作。

味亦以共相及其別相——甘酢鹹苦辣澀等，為愚者所攝納者——我以無味故，無有損或增之可作。

香亦以共相及其別相——花等塗飾等悅與不悅者——我以無香故，無有損或增之可作。

如聖典所言：『無聲、無觸、無色、無變、無味、常、無香者。』

=== II,3.116 | 內外依存，我無敵友 ===

復次，所謂外在之聲等，彼以身相而住，彼之攝取者以耳等相、內二根及其所緣相故，互相依存故、聚集故、一切作業皆在其中。如是於我智者，無有敵、無有友、無有中立。若有人以邪智之慢心，欲以業果相之可愛與不可愛施於我，彼徒勞無功，以我非所緣故——如聖傳所言：『此我不可顯、不可思議。』如是五大皆無變，以非所緣故——如聖傳所言：『此我不可斷、不可燒。』又有身根集聚之相，唯觀察我...

=== 41 | 算計品結語 ===

至於虔信者與顛倒者之愛憎等執著，以及從彼所生之善惡等獲取，此唯屬於彼等，而不在於我——於不老、不死、無畏者之中。經典所說：「彼不為已作未作所觸」、「業不能使其增亦不能使其減」、「無生者既外亦內」、「外在者不染世間之苦」等教，皆據《奧義書》與諸傳承之明文。又，以無我之事本非實在故，此即最勝之理。再者，一切《奧義書》語句——以自我之無二為其旨，因二元本不實在故——皆應一一詳加審觀。

——算計品終。第二部第三章終。
