=== 3 | 第三歌 ===

把 Radhā 攝入心中，他遂捨棄 Vraja 的眾美女。

GG_3.1
追隨 Rādhikā 至此至彼，Madhava 心為 Ananga（愛神）之箭所傷而破碎，
生懊悔後，遂在 Kalinda 之女（Yamunā）岸邊的叢林亭中頹然坐下。

GG_3.2
「她見我離群，環顧諸婦，
以為我犯過，遂不攔阻，驚懼而去。

嗚呼！她似含怒而去，因愛意已滅。」

GG_3.3
「她將如何？她將說何言？因長別離，

嗚呼！她似含怒而去，因愛意已滅。」

GG_3.4
「我思念她的面容，雙眉因盛怒而彎曲，
恰似紅蓮之上，有迷亂的蜜蜂飛繞。

嗚呼！她似含怒而去，因愛意已滅。」

GG_3.5
「我心中日夜與她相聚，極盡歡愛，

GG_3.6
「Tanvī！我以機巧揣度你因妒而破碎的心，
然我不知你為何而去，故無法向你求恕。」

GG_3.7

GG_3.9

「我胸中所佩非蓮花莖之環，亦非 Bhujangama（蛇）之主（Śeṣa），

GG_3.12
「以眉為弓，以側目為箭，致我命痛；
深膚的、彎曲的，可行 Mâra（殺）之功，

GG_3.13
「彼觸之樂、顫動之柔媚眼波、

GG_3.14
「眉梢為弓，眼波為箭，雙耳為箭羽 —
Smara（愛神）以此武備，
向 Ananga 之勝、流動之神（其婦），
世間已克，何需更置武？」

她在與你分離中哀苦，
Mādhava 啊，似畏懼那心所生之箭，她沉緬於對你的憶念。

她在暗處以鹿的迷醉，描繪你那無雙之箭，

她在與你分離中哀苦，
Mādhava 啊，似畏懼那心所生之箭，她沉緬於對你的憶念。

她在與你分離中哀苦，
Mādhava 啊，似畏懼那心所生之箭，她沉緬於對你的憶念。

她悲嘆、歡笑、憂愁、哭泣、顫抖、釋放那灼熱。
她在與你分離中哀苦，

saṃketī-kṛta-mañju-vañjula-latā-kuñje api yat na āgataḥ //

> 譯文：「那麼，為何（tat kim）情人（kāntaḥ）獨至遠方，抑或為他藝（kalā）之嬉戲所繫？於幽暗之林緣（vana-upānte），友伴相邀（bandhubhiḥ baddhaḥ），徘徊不去。彼心疲憊（klānta-manāḥ），即便小路踏上亦無力前進；雖已約定（saṃketī-kṛta），約於雅緻藤蔓涼亭（mañju-vañjula-latā-kuñje），竟終不赴約。」
>
> 名相：
> - andhakāriṇi（形容 vana）：幽暗、致盲之林
> - saṃketī：密約、信號、記號
> - mañju-vañjula-latā-kuñje：雅緻之藤蔓花亭

---

GG_7.11

atha āgatām mādhavam antareṇa sakhīm iyam vīkṣya viṣāda-mūkām /  
viśaṅkamānā ramitam kayāpi janārdanam dṛṣṭavat etat āha //

> 譯文：「其後（atha），一女子見（vīkṣya）另一女友（sakhīm），越過 Mādhava（Kṛṣṇa）而去；其神情哀慟無言（viṣāda-mūkām），心中充滿疑慮（viśaṅkamānā）。另一位（kayāpi）宛如親睹 Janārdana（Kṛṣṇa）者，開言如下（etat āha）。」

GG_7.12

smara-samara-ucita-viracita-veśā /  
galita-kusuma-dara-vilulita-keśā //

kāpi madhuripuṇā vilasati yuvatīḥ adhika-guṇā //

> 譯文：「有女子，衣著（veśā）為 smara（情欲）戰陣（samara）所熟悉（ucita）之裝扮（viracita）；落花（galita-kusuma）之雨露（dara，露珠）散於其髮（vilulita-keśā）。彼女飾諸多功德（adhika-guṇā），於 madhuripu（甜敵／Kṛṣṇa 與 viṣa-krīḍā 者）之前嬉戲。」
>
> 名相：
> - smara = Kāma（愛神）
> - samara：戰陣、戰鬥（情欲即戰場）
> - veśā：服飾、化裝
> - madhuripu = Kṛṣṇa（字面「甜敵」，與 viṣa 同義之戲稱）

GG_7.13

hari-parirambhaṇa-valita-vikārā /  
kuca-kalaśa-upari taralita-hārā //

kāpi madhuripuṇā vilasati yuvatīḥ adhika-guṇā //

vicalat-alaka-lalita-ānana-candrā /

kāpi madhuripuṇā vilasati yuvatīḥ adhika-guṇā //

GG_7.17

vipula-pulaka-pṛthu-vepathu-bhaṅgā /  
śvasita-nimīlita-vikasat-anaṅgā //

kāpi madhuripuṇā vilasati yuvatīḥ adhika-guṇā //

> 名相：anaṅga = kāma（愛神），「無體者」之稱

GG_7.18

kāpi madhuripuṇā vilasati yuvatīḥ adhika-guṇā //

GG_7.19

śrī-jayadeva-bhaṇita-hari-ramitam /

kāpi madhuripuṇā vilasati yuvatīḥ adhika-guṇā //

> 譯文：「Jayadeva（śrī-jayadeva）所誦（bhaṇita）並為 Hari 所悅（ramitam）之歌，願其消盡（pariśamitam）kali-yuga（末世）之罪垢（kaluṣa）！」
>
> 名相：kali-kaluṣa = 末世之垢染（Kṛṣṇa 信仰之經典效用論）

---

GG_7.20

viraha-pāṇḍu-murāri-mukha-ambuja-dyutiḥ iyam tirayan api cetanām /  
vidhuḥ atīva tanoti manobhuvaḥ sahṛdaye hṛdaye madana-vyathām //

> 譯文：「因別離（viraha）而蒼白（pāṇḍu）之 Murāri（Ṃ Kṛṣṇa，其名）」連月（vidhuḥ）蒼白的光芒（ambuja-dyutiḥ，蓮花之光 = 月光，雙關：臉如蓮花泛白），亦將照入（tirayan api）覺者之心（cetanām）；然其實（atīva tanoti）擴張（tanoti）情人（manobhuvaḥ，「生心者」）之共情者（sahṛdaye）心中（hṛdaye）愛之痛（madana-vyathām）。」
>
> 譯註：此頌為雙關——「vidhuḥ（連月）」借代為別離之女子，蒼白如月，借月光與面容之相似，作通感（synesthesia）之筆。

GG_7.21

samudita-madane ramaṇī-vadane cumbana-valita-adhare /  
mṛgamada-tilakam likhati sapulakam mṛgam iva rajanī-kare //

ramate yamunā-pulina-vane vijayī murāriḥ adhunā //

> 譯文：「情欲已動（samudita-madane），於可愛之面容（ramaṇī-vadane）——其雙脣（adhare）為親吻所轉（cumbana-valita）；如月（rajanī-kare，夜手 = 月）於大地上繪出一麋鹿記號（mṛga-sapulakam）而點上麝香點（mṛgamada-tilakam）——情緣之戰（Mādhava）之勝利者（vijayī），即 Murāri，今於 Yamunā（耶穆那河）河岸林野（pulina-vane）嬉戲（ramate）。」
>
> 名相：
> - mṛga-sapulakam（mṛga + sapulaka）= 鹿之圖案（說者隱喻：女方顏面上之 mark，如月映鹿影）
> - rajanī-kara：夜之手 = 月
> - murāriḥ：Ṃ 之敵人
> - pulina：沙岸

GG_7.22

ghana-caya-rucire racayati cikure taralita-taruṇa-ānane /  
kurabaka-kusumam capalā-suṣamam rati-pati-mṛga-kānane //

ramate yamunā-pulina-vane vijayī murāriḥ adhunā //

> 譯文：「彼以其髮（cikure）之鬱茂黑澤（ghana-caya-rucire），於少女（taruṇa-ānane，年輕面容）上繪成（racayati）kurabaka（茉莉苞）之花（kusumam），此花為蜂群（capalā-suṣamam）所愛戀（mṛga-kānane，「鹿林」意為「蜂之園」，mṛga 雙關「蜜蜂」與「鹿」）——情人之主（rati-pati）即 Murāri 之勝利者，今於 Yamunā 河岸林野嬉戲。」
>
> 名相：
> - ghana-caya：密雲之積聚 = 髮之黝黑
> - capalā：搖動之蜂，亦為少女之喻
> - suṣamam：善美
> - rati-pati-mṛga-kānane：「愛欲之主之獸園」——解作女性之雙關場景，「mṛga」兼具追求者／野獸雙意
> - kurabaka：茉莉科灌木，少女鬢花之典

GG_7.23

ghaṭayati sughane kuca-yuga-gagane mṛgamada-ruci-rūṣite /  
maṇi-saram amalam tāraka-paṭalam nakha-pada-śaśi-bhūṣite //

ramate yamunā-pulina-vane vijayī murāriḥ adhunā //

> 譯文：「彼於美麗（sughane）雙乳之地（kuca-yuga-gagane，「乳對之天」）構築（ghaṭayati）明亮（-rūṣite）於麝香光（mṛgamada-ruci）之中，無瑕（amalam）之寶石箭（maṇi-saram）連續（tāraka-paṭalam），似指甲印（nakha-pada）所飾以月印（śaśi-bhūṣite）——情人之主即 Murāri 之勝利者，今於 Yamunā 河岸林野嬉戲。」
>
> 名相：
> - tāraka-tāraka-paṭalam：星辰之列（星圖），亦指指甲之新月痕
> - śaśi：月（指甲新月之形）
> - maṇi-sara：寶石箭（kāma 之箭）

GG_7.24

jita-bisa-śakale mṛdu-bhuja-yugale kara-tala-nalinī-dale /  
marakata-valayam madhu-kara-nicayam vitarati hima-śītale //

ramate yamunā-pulina-vane vijayī murāriḥ adhunā //

> 譯文：「彼 [I] 於蓮葉（nalinī-dale，「蓮葉」喻女性之手）般柔軟之雙臂（mṛdu-bhuja-yugale）掌上（kara-tale），擊退（jita）毒蛇之世界（bisa-śakale，「毒蛇之能」為蛇界別稱）後，於涼意（hima-śītale）中佈施（vitarati）綠寶石（marakata）手鐲——形如蜜蜂群（madhu-kara-nicayam）——情人之主即 Murāri 之勝利者，今於 Yamunā 河岸林野嬉戲。」
>
> 名相：
> - bisa：蓮根，亦喻蛇毒（雙關）
> - marakata：綠寶石（翠玉）
> - madhu-kara：蜜之作者 = 蜜蜂
> - jita-bisa-śakale：解作「戰勝蛇之能」即手臂之力

GG_7.25

rati-gṛha-jaghane vipula-apaghane manasija-kanaka-āsane /  
maṇi-maya-rasanam toraṇa-hasanam vikirati kṛta-vāsane //

ramate yamunā-pulina-vane vijayī murāriḥ adhunā //

> 譯文：「彼於壯麗之腰臀（rati-gṛha-jaghane = 愛欲之屋之腰，大臀）——寬廣（vipula）而堅實（apaghane）——之上、以愛神（manasija）之金椅（kanaka-āsane）為座椅，分配（vikirati）寶石所成（maṇi-maya）之腰帶（rasanam，繩／腰飾）與笑語（toraṇa-hasanam），彼已穿衣（kṛta-vāsane）——情人之主即 Murāri 之勝利者，今於 Yamunā 河岸林野嬉戲。」
>
> 名相：
> - rati-gṛha = 愛欲之屋，指身體（多層雙關）
> - toraṇa：拱門／腰帶飾，亦雙關笑之彎月
> - manasija-kanaka-āsane：愛神之金椅

---

GG_7.26

caraṇa-kisalaye kamalā-nilaye nakha-maṇi-gaṇa-pūjite /  
bahiḥ-apavaraṇam yāvaka-bharaṇam janayati hṛdi yojite //

ramate yamunā-pulina-vane vijayī murāriḥ adhunā //

> 譯文：「彼於其蓮花（kamalā-nilaye，「居於蓮花」之 [II]）之嫩芽足（caraṇa-kisalaye，蓮足——Lakṣmī之雙關）——為指甲寶石群（nakha-maṇi-gaṇa）所禮敬（pūjite）——外著（bahiḥ-apavaraṇam）之裝飾（yāvaka-bharaṇam，大麥紋飾），生起（janayati）內心（hṛdi）之繫念（yojite）——情人之主即 Murāri 之勝利者，今於 Yamunā 河岸林野嬉戲。」
>
> 名相：
> - kamalā：蓮，亦指 Lakṣmī（運氣女神）
> - yāvaka：「大麥」（外衣之一種）
> - caraṇa-kisalaya：足之嫩芽（蓮足之成詞）

ramayati sudṛśam kāmapi subhṛśam khala-haladhara-sodare /

=== 9 | 第九章 ===

GG_9.1
哈利（hari）前來，春風吹拂 —
女伴啊，家中更有何歡？
Mādhava 啊，莫起驕矜，驕傲的人啊。

GG_9.2
比之檳榔果更為沈重、更為甘美 —
你為何使這乳房的瓶罐徒然？
Mādhava 啊，莫起驕矜，驕傲的人啊。

GG_9.3
這些話，難道還不曾屢次向你說了？
莫捨棄那位至為可悅的 hari —
Mādhava 啊，莫起驕矜，驕傲的人啊。

GG_9.4
為何愁苦，為何哭泣，消瘦的人？
你那整個少女同伴之集會都在笑你 —
Mādhava 啊，莫起驕矜，驕傲的人啊。

GG_9.5
在那沾露蓮花瓣清涼的臥榻上 —
凝視 hari，使你的雙眼不虛此生 —
Mādhava 啊，莫起驕矜，驕傲的人啊。

GG_9.6
你心中為何生起如此深重的愁苦？
請聽我的言語 — 不藏機心 —
Mādhava 啊，莫起驕矜，驕傲的人啊。

GG_9.7
讓 hari 前來，讓他說盡甜言 —
你為何把心變得如此冷酷？
Mādhava 啊，莫起驕矜，驕傲的人啊。

GG_9.8
願 Śrī Jayadeva 那至為優美之作 —
令雅人們歡喜的 hari 之傳 —
Mādhava 啊，莫起驕矜，驕傲的人啊。

GG_9.9
溫柔者啊，你卻粗暴；俯首者前，你卻僵立；
情深者啊，你卻懷恨於那轉身之人，
對那背你而去者亦生憎厭，親愛的啊 —
這是合理的：對行為相背之人，
你檀香膏之塗即是毒藥：
月亮是日之炙，太陽是雪之寒，
爐火是嬉遊之喜，嬉遊是苦痛之刑。

GG_9.10
其間，hari 走向那位美顏者 —
她為柔情所制，無限愁嘆，
無以自持，帶羞瞥視女伴之面容 —
一日將盡，他以欣喜而顫抖的言語如此說道。
